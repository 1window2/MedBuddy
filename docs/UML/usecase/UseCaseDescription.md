### Use Case Description: UC-19 처방 변경 비교 확인

| Actor Action | System Response |
| --- | --- |
|  | 1. 처방 약 분석 결과 화면과 처방 변경 비교 loading 상태를 먼저 출력한다. |

|  | 3. 추가된 약, 제외된 약, 복용 정보가 변경된 약과 유지된 약을 구분하여 비교 영역을 갱신한다. |
| 4. 사용자가 갱신된 처방 변경 비교 영역을 확인한다. |  |
