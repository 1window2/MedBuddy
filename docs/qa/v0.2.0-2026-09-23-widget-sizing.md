# 위젯 높이와 크기별 배치 검증

## 수정 범위

- 기본 높이는 300dp에서 240dp로, 최소 축소 높이는 180dp로 분리했다.
- Android 12 이상의 권장 초기 격자 크기 4 x 3은 유지했다.
- Android 12 이상에는 높이별 RemoteViews를 제공하고, 이전 버전에는 런처가 전달한 회전별 높이를 사용한다.
- 작은 위젯은 여백과 상세 줄 수를 줄인다. 진행 숫자는 유지하고 중복되는 진행 막대만 숨긴다.
- 큰 글씨와 작은 높이가 겹치면 요약 중심으로 표시한다. 전체 약 정보는 읽어주기와 일정 열기로 확인할 수 있다.
- 240dp 미만에서는 시간대 제목을 화살표 사이로 옮겨 날짜, 시간대 전환, 저장 상태, 복용 버튼이 함께 들어가도록 한다. 기본 4 x 3 배치의 상세 표시에는 영향을 주지 않는다.
- 복용 버튼, 새로고침, 시간대 및 환자 전환 화살표는 48dp 조작 영역을 유지한다.
- 복용 기록, 환자 전환, 보호자 읽기 전용 정책, 하단 메뉴와 홈 안내 위치는 변경하지 않았다.

## 검증 결과

- Android 계측 테스트 2개 통과: 메타데이터 높이와 실제 텍스트/버튼 배치를 검사했다.
- 배치 조합 180개: 높이 180/240/300/340/420dp, 너비 250/360dp, 글자 배율 1/1.3/2, 환자/보호자/비로그인, 주의 문구 유무. Android 15(API 35)와 기존 API 37 에뮬레이터에서 각각 통과했다.
- 보이는 텍스트의 세로 잘림, 부모 경계 밖 배치, 핵심 버튼의 조작 영역 축소가 없는지 검사했다.
- Flutter 관련 테스트 44개 통과: `dose_home_widget_test.dart`, `caregiver_schedule_snapshot_test.dart`.
- Pixel 7 환자·보호자 데모 앱에 최신 코드를 설치하고 기존 홈 위젯 표시를 확인했다. 복용 기록은 변경하지 않았다.

## Android 15 재현과 원인

- 별도 Pixel 8 AVD: Android 15 / API 35, Google Play x86_64 이미지 revision 9, 1080 x 2400, 420dpi, 홈 화면 4열 5행.
- 앱 빌드는 기존 Flutter 3.41.5 / Android Studio JBR을 사용했다. 팀원의 Flutter 3.47.4 / Dart 3.13.3 / Temurin 17.0.20까지 동일하게 복제한 것은 아니다.
- 같은 화면 환경에서 높이 선언만 바꾼 APK를 비교하여 팀원이 보고한 3 x 5를 재현했다. 비교 리소스는 저장소 밖의 테스트용 Gradle 오버레이로 적용했으며 일반 빌드에는 포함되지 않는다.

| 초기 높이 | 최소 축소 높이 | 요청한 칸 수 | 런처 추가 목록의 실제 칸 수 |
| --- | --- | --- | --- |
| 300dp | 300dp | 4 x 3 | 3 x 5 |
| 240dp | 240dp | 4 x 3 | 3 x 4 |
| 240dp | 180dp | 4 x 3 | 4 x 3 |

Android 15 Launcher3의 `initSpans`는 지원하는 화면 방향별 셀 크기를 계산한 뒤 가장 큰 최소 칸 수를 적용한다. `targetCellWidth/Height`가 그 최소/최대 범위 안에 있을 때만 요청 크기를 사용한다. 세로 최소 칸 수가 3보다 크면 요청한 4 x 3 전체를 버리고 `minWidth/Height`에서 다시 계산하므로 가로도 3칸으로 달라졌다. 240dp로만 낮추는 수정은 이 조건을 해결하지 못했다.

최종 수정본은 추가 목록에서 4 x 3을 확인하고 빈 재현용 홈 화면에 실제로 추가했다. 환자 별칭, 날짜, 일정, 전환 점, 저장 상태와 일정 열기 버튼이 잘림 없이 표시되었다. 기존 데모의 복용 기록과 홈 배치는 변경하지 않았다.

팀원에게는 최종 수정본을 새로 빌드·설치한 뒤 새 위젯으로 확인하도록 안내한다. 이미 저장된 위젯 배치가 자동으로 4 x 3이 된다고 보장하지 않는다. 다른 런처/격자 전체에 동일한 칸 수를 보장하는 변경도 아니다.
