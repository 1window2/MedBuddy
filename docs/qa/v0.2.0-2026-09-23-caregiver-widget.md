# Caregiver widget schedule refresh

Baseline: `ed6af26`, `beta/v0.2.0`.

The widget refreshed linked-patient schedules through `/caregiver/monitoring`.
That endpoint intentionally omits schedules when caregiver alerts are disabled,
so a successful refresh could replace visible medication information with an
empty list. Home had already moved to patient details, leaving two different
lookup contracts for the same display.

Home and widget now share `CheckCaregiverMedication.requestScheduleSnapshot`.
The widget fetches fresh links, filters active relationships belonging to the
current caregiver, and reads authorized patient details independent of alert
settings. Home supplies its current links through the same method. Returned
caregiver/patient identities are checked before creating snapshots.

Lookup failures propagate to the existing error-cache path. Actual removal of
all links still yields an empty result. Existing widget account, day, refresh
revision, read-only patient mode, and dose-action protections are unchanged.
The sequence source in `docs/UML/sequence/HomeDoseWidget.puml` reflects this
shared lookup; its rendered image needs regeneration in the diagram workflow.

Regression coverage checks repeated refresh with alerts off, removed/inactive
and foreign-account links, failed link/detail requests, and mismatched response
identities, alongside existing Home and encrypted widget-store tests. Validation
uses Flutter 3.41.5 and the committed lockfile in an isolated copy; the separate
local dependency-lockfile changes are neither modified nor committed.
All **944 Flutter tests passed**, full static analysis found **no issues**, and
strict dependency resolution and `git diff --check` passed.

Physical launcher/background checks remain deferred. When a device is available,
disable all caregiver alerts for a designated linked test patient, select patient
widget mode, refresh repeatedly, and verify the schedule remains visible. Then
unlink and refresh to verify removal. No production medication writes are needed.
