# Pharmacy map symbols — 2026-09-13

## Change

- Replace the tinted SDK default icon (previously forced into a square) with
  fixed-aspect vector artwork: green pin, white border, white pharmacy cross.
- Normal size is 28 × 40 logical pixels; selected size is 35 × 50, preserving
  aspect ratio. Selection uses the darker theme green and existing name caption.
- Render/reuse three overlay images once per map instance, not per pharmacy.
- Show a blue, white-bordered device-location dot through the native location
  overlay. Its fixed-pixel halo is decorative, not a claimed GPS accuracy radius.
- Keep the last confirmed device coordinate separate from manually selected map
  search centers. Never label the fallback search center as the user's position.
- This does not introduce background GPS tracking: the dot uses the location fix
  already obtained by the existing search/current-location flow.
