# v0.2.0 베타 실기기·접근성 회귀 체크리스트

이 문서는 자동 위젯 테스트만으로 확인할 수 없는 Android 실기기 동작을
반복 검증하기 위한 체크리스트다. v0.2.0 베타 배포 전뿐 아니라 알림, OCR,
낱알 식별, 직접 등록, 약국, 채팅, 환자·보호자 연동 코드를 변경한 뒤에도
같은 항목을 수행한다.

> 상태 (2026-08-27): Android 실기기를 확보할 때까지 실행을 보류한다.
> 아래 항목은 통과로 간주하거나 표시하지 않는다. 자동 테스트와 에뮬레이터
> 검증은 계속 진행한다. 이 보류는 v0.1.1 배포를 막지 않으며, 실기기를
> 확보하면 배포된 후보 커밋을 기준으로 검증을 재개한다.

## 자동 검증 범위

- 320px, 360px, 412px 너비에서 핵심 화면 레이아웃 확인
- 운영체제 글자 배율 160%, 200%에서 오버플로 확인
- 환경설정 허브와 복약 및 알림·화면 및 음성·실험실·계정 하위 화면의 고정 뒤로가기·저장 항목 접근성 라벨 확인
- 앱 일시중지와 재개 후 화면 선택 상태 유지 확인
- OCR 검토 표에서 기존 행 수정, 누락 약 행 추가, 분석 명령 접근 가능 여부 확인
- 일부 약 정보만 조회되지 않으면 확인된 행은 잠기고 취소선으로 구분되며, 미확인 행만 수정·재시도되는지 확인
- 미확인 행이 남은 상태에서 확인된 약만 계속 사용할 때 경고 확인을 거쳐야 하는지 확인
- 전체 약 정보 조회가 기술적으로 실패하면 연결·지연·응답 오류에 맞는 복구 경로를 표시하는지 확인
- 전체 저장 후 오늘 일정 또는 저장 목록으로 이동하는 후속 동작 확인
- 홈 카드의 다음 복약 시간과 오늘 복용 진행률 표시 확인
- 저장 목록의 복용 상태 필터와 날짜 기준·방향 정렬 확인
- 오늘 복약 일정의 작은 화면 스크롤 확인
- 일정 API 실패 후 재시도와 정상 복구 확인
- 복용 완료 실행 취소와 알림 설정·해제 결과 안내 확인
- 세로·가로 촬영 가이드의 문서 프레임 계산과 촬영 이미지 자르기 확인
- 처방전·낱알 식별 후 시작일·기간·횟수·용량·시간대 검토 확인
- 직접 복약정보 입력의 필수값·날짜·횟수·선택 이미지 검증 확인
- 다중 낱알 식별의 입력 순서, 최대 10개 제한, 동시 요청 제한, 일부 실패와 호출 제한 자동 재시도 확인
- 실험실 약국·채팅 기능의 기본 비활성 및 설정 저장 후 표시 확인
- 위치 권한·위치 서비스·빈 약국 목록·새로고침 제한과 지도 선택 상태 확인
- 채팅의 일정형 다중 약 선택·개별 해제, 역할별 추천 문구, 환자 일정 이동, 약 상세 이동, 중복 전송 방지, 읽음 처리, 재연결 확인
- 약 상세정보와 오늘 일정의 약 사진 확대·이동·축소 및 닫기 확인
- 환경설정의 알림 종류별 허용, 신규 일정 기본 시각, 잠금 화면 공개 범위, 12/24시간 표시, 글씨 크기·언어 즉시 미리보기와 화면 유지 확인
- 음성 미리보기의 정상 재생, 의도적 중지, 실제 실패 상태 구분 확인
- 건강 추천의 마지막 주의사항 카드와 하단 여백 도달 확인

자동 검증은 `flutter test test/accessibility_layout_regression_test.dart`와
기존 화면별 테스트에서 수행한다.

## 화면·입력

- [ ] 모든 화면에서 글자, 버튼, 카드가 서로 겹치지 않는다.
- [ ] 긴 약 이름과 0.5정 같은 복용량이 잘리더라도 핵심 정보는 구분된다.
- [ ] 화면 하단 고정 버튼이 시스템 내비게이션 영역과 겹치지 않는다.
- [ ] 시간 선택기의 휠 조작과 숫자 직접 입력이 모두 가능하다.
- [ ] 키보드가 열린 상태에서도 확인·취소 버튼에 접근할 수 있다.
- [ ] 가로·세로 화면 전환 후 현재 입력값과 선택값이 유지된다.
- [ ] 처방전 촬영 화면을 좌우로 회전해도 가이드와 촬영 버튼이 겹치지 않고 같은 배치를 유지한다.
- [ ] 세로·가로 촬영 결과에는 화면 가이드 안쪽 영역만 남고 바깥 배경은 포함되지 않는다.
- [ ] 저장 목록에서 복용 중·복용 종료·전체 필터가 올바른 항목을 표시한다.
- [ ] 등록일자·복용날짜 정렬과 오름차순·내림차순 전환 결과가 일치한다.
- [ ] 전체 저장 완료 후 오늘 일정과 저장 목록 이동 버튼에 접근할 수 있다.
- [ ] 복용 완료 직후 실행 취소가 가능하고 화면과 서버 상태가 함께 복원된다.
- [ ] 알림 설정·해제 완료 안내가 화면 하단에 겹치지 않고 표시된다.
- [ ] 세로·가로 회전 시 처방전 가이드와 안내 문구가 현재 방향에 맞게 재배치된다.
- [ ] 앱 카메라로 촬영한 처방전은 가이드 영역으로 잘리고 갤러리 원본은 삭제되지 않는다.
- [ ] 분석 전·저장 전 일정 검토에서 OCR/식별 기본값을 수정할 수 있고 수정값이 저장 결과에 반영된다.
- [ ] 오늘 일정과 약 상세정보에서 유효한 약 사진을 누르면 같은 확대 화면이 열리고 이동·확대 후 안전하게 닫힌다.
- [ ] 직접 등록에서 약명, 용량·단위, 시작·종료일, 시간대를 입력하고 선택 이미지를 추가하거나 생략할 수 있다.
- [ ] 다중 낱알 식별에서 한 항목이 실패해도 성공한 다른 후보와 입력 순서가 유지된다.
- [ ] 다중 낱알 식별 중 호출 제한이 발생하면 완료 항목은 유지되고 대기 안내 후 실패 항목만 자동 재시도된다.
- [ ] 환경설정 허브에서 복약 및 알림·화면 및 음성·실험실·계정 화면을 각각 열고 뒤로가기로 허브에 복귀할 수 있다.
- [ ] 하위 설정 화면 사이를 이동해도 저장 전 선택값이 유지되고, 글씨 크기와 언어를 누르는 즉시 현재 화면이 갱신되며 저장 후에도 설정 화면에 남는다.
- [ ] 환경설정 내용을 스크롤해도 뒤로가기 버튼은 같은 위치에서 계속 접근할 수 있고 계정 요약의 이메일·전화번호는 마스킹된다.
- [ ] 복약·보호자·채팅 알림을 각각 끄고 켤 수 있으며 휴대폰 알림 설정 화면으로 이동할 수 있다.
- [ ] 아침·점심·저녁·취침 전 기본 시각은 새 일정에만 반영되고 기존 일정의 확인된 시각은 바뀌지 않는다.
- [ ] 잠금 화면 공개 범위를 알림 종류만 표시하도록 바꾸면 약 이름과 채팅 본문이 시스템 알림에 노출되지 않는다.
- [ ] 기기 설정 따르기·한국어·English와 12시간제·24시간제를 바꾸면 지원 화면의 언어와 시각 표기가 일관되게 갱신된다.
- [ ] 건강 추천을 끝까지 스크롤하면 마지막 노란 주의사항 카드 테두리와 시스템 내비게이션 위 여백이 보인다.

## 앱 종료·재부팅

- [ ] 앱을 강제 종료하고 다시 열어도 사용자 설정이 유지된다.
- [ ] 복약 완료 상태와 시간대별 알림 설정이 유지된다.
- [ ] 기기를 재부팅한 뒤 예약된 복약 알림이 정상 동작한다.
- [ ] 앱 업데이트 후 기존 저장 복약정보와 일정이 유지된다.
- [ ] 직접 등록한 선택 이미지가 앱 재실행 후 유지되고 삭제된 항목의 고아 이미지는 정리된다.
- [ ] 실험실 약국·채팅 설정과 환경설정 미리보기가 재실행 후 저장값으로 복원된다.
- [ ] 채팅 화면을 닫거나 앱을 재실행한 뒤에도 서버 이력과 읽음 상태를 다시 불러온다.

## 네트워크·절전

- [ ] 오프라인에서 서버 기능이 실패 이유와 재시도 방법을 표시한다.
- [ ] 서버 예외 원문 대신 연결·지연·응답·OCR 상황에 맞는 안내를 표시한다.
- [ ] 네트워크 복구 후 재시도하면 중복 저장 없이 정상 처리된다.
- [ ] Wi-Fi와 모바일 데이터 전환 중 화면이 멈추거나 중복 요청하지 않는다.
- [ ] 배터리 절전 모드에서도 허용된 복약 알림이 가능한 범위에서 동작한다.
- [ ] 정확한 알람 권한이 꺼진 경우 설정 방법을 안내한다.
- [ ] 위치 권한 거부·영구 거부·위치 서비스 꺼짐을 구분하고 올바른 설정 이동 또는 재시도를 제공한다.
- [ ] 약국 새로고침을 연속 선택하면 추가 요청 없이 남은 대기 안내를 표시하고 제한 후 다시 동작한다.
- [ ] 약국 API가 빈 목록·지연·오류를 반환해도 기존 화면이 멈추거나 위치 좌표를 노출하지 않는다.
- [ ] 지도 타일을 불러오지 못해도 약국 필터·목록·전화·길찾기는 계속 사용할 수 있다.
- [ ] 채팅 WebSocket이 끊겨도 입력 내용과 기존 이력이 유지되고 재연결 또는 REST 새로고침으로 복구된다.
- [ ] 채팅 전송 재시도에서 같은 client message ID가 중복 메시지를 만들지 않는다.

## 환자·보호자 두 기기

- [ ] 환자 코드로 서로 다른 보호자 기기가 정상 연동된다.
- [ ] 같은 사용자 해시로 자기 자신을 보호자로 등록할 수 없다.
- [ ] 환자의 아침·점심·저녁·취침 전 완료 상태가 보호자 화면에 반영된다.
- [ ] 즉시 알림은 완료 상태가 바뀐 경우 한 번만 전달된다.
- [ ] 미복용 알림은 설정한 시간대와 확인 시각을 기준으로 한 번만 전달된다.
- [ ] 연동 해제 후 보호자가 환자 일정과 알림을 더 이상 조회하지 못한다.
- [ ] 채팅 실험실 기능이 꺼져 있으면 양쪽 모두 진입 버튼과 알림 감시가 동작하지 않는다.
- [ ] 채팅 실험실 기능이 켜져 있어도 활성 복약정보가 없으면 채팅이 비활성 상태와 이유를 안내한다.
- [ ] 양쪽 기기에서 약을 선택하지 않은 일반 메시지를 주고받고 상대 화면에 실시간 반영된다.
- [ ] 오늘 일정과 같은 시간대 화면에서 여러 활성 약을 선택·해제하면 선택 순서가 유지되고 각 사진·복용량 문맥이 메시지에 함께 표시된다.
- [ ] 환자와 보호자에게 각각의 역할에 맞는 추천 문구가 표시되고, 선택한 문구를 전송 전에 수정할 수 있다.
- [ ] 채팅의 선택 약과 이전 메시지 약 카드를 누르면 권한이 확인된 공통 상세 화면이 열린다.
- [ ] 환자가 시간대 확인 카드를 누르면 오늘 일정의 해당 시간대로 이동하고, 보호자 화면에서는 같은 카드가 읽기 전용으로 유지된다.
- [ ] 시간대 확인 요청 알림을 누르면 환자의 오늘 일정 중 해당 시간대로 이동한다.
- [ ] 시간대 복약을 모두 완료하면 완료 메시지가 한 번만 생성되며 같은 완료 요청을 재시도해도 중복되지 않는다.
- [ ] 약국 공유 메시지는 서버 약국 목록의 이름·주소·전화·좌표를 사용하며 변조한 식별자는 거부된다.
- [ ] 메시지 알림은 공백이 정리된 120자 이하 본문 미리보기를 표시하고 약명·환자명·이미지 URL을 별도로 추가하지 않으며 해당 연결 화면으로 이동한다.
- [ ] 연동 해제 직후 기존 채팅의 조회·전송·읽음·WebSocket 접근이 모두 거부된다.

## 실험실 근처 약국

- [ ] 설정에서 기능을 켜기 전에는 홈 진입점이 보이지 않고 켠 뒤에만 나타난다.
- [ ] 홍익대학교 등 알려진 테스트 좌표에서 거리순 결과와 오늘 운영시간을 확인한다.
- [ ] 앱 내 네이버 지도가 필터 위에 표시되고 네이버 지도 안내를 열 수 있다.
- [ ] 첫 진입 시 별도 시각 입력 없이 현재 영업 중인 약국만 표시되고, 전체 목록에서도 영업 중 약국과 늦게까지 운영하는 약국이 우선 배치된다.
- [ ] 단일 필터 버튼을 누르면 현재 영업 중·늦게까지 영업·주말/공휴일·전체 조건의 설명이 포함된 선택 목록이 열리고 현재 선택값이 명확히 표시된다.
- [ ] 날짜 기반 조건은 조회 날짜만 요구하고 시각 입력을 추가로 요구하지 않는다.
- [ ] 약국 카드 또는 지도 마커를 선택하면 같은 항목이 강조되고 추가 약국 API 호출 없이 지도가 해당 위치로 이동한다.
- [ ] 약국 선택 후 초기 지도 사용 안내가 사라져 선택한 위치를 가리지 않는다.
- [ ] 늦게까지 영업 조건은 공공심야 지정 약국과 등록된 심야 운영 약국을 함께 표시하고, 24시간 운영 여부는 카드 정보로 구분한다.
- [ ] 마감 임박, 다음 영업 시각, 정보 갱신 시각이 서버 응답과 일치하며 알 수 없는 값은 단정적으로 표시하지 않는다.
- [ ] 즐겨찾기가 사용자별로 기기에 저장되고 다른 로컬 사용자로 전환했을 때 섞이지 않는다.
- [ ] 지도 클라이언트 설정 누락과 표시 가능한 좌표 없음이 서로 다른 안내로 표시되며 목록은 계속 사용할 수 있다.
- [ ] 전화 버튼은 전화 앱으로 연결되고 길찾기는 설치된 지도 앱·Google 지도·주소 복사 선택지를 제공한다.
- [ ] 선택한 지도 앱과 브라우저를 모두 열 수 없으면 검증된 약국 주소를 복사하고 화면 하단에 완료 안내를 표시한다.
- [ ] 비정상 전화번호·좌표·외부 URL은 열지 않고 사용자에게 실패 안내를 표시한다.
- [ ] 공휴일·심야 운영정보가 보이더라도 방문 전 전화 확인 안내가 항상 표시된다.
