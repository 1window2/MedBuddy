# 베타 실기기·접근성 회귀 체크리스트

이 문서는 자동 위젯 테스트만으로 확인할 수 없는 Android 실기기 동작을
반복 검증하기 위한 체크리스트다. 베타 배포 전뿐 아니라 알림, OCR, 환자·보호자
연동 코드를 변경한 뒤에도 같은 항목을 수행한다.

## 자동 검증 범위

- 320px, 360px, 412px 너비에서 핵심 화면 레이아웃 확인
- 운영체제 글자 배율 160%, 200%에서 오버플로 확인
- 환경설정의 닫기·저장·비활성 언어 항목 접근성 라벨 확인
- 앱 일시중지와 재개 후 화면 선택 상태 유지 확인
- OCR 검토 표에서 기존 행 수정, 누락 약 행 추가, 분석 명령 접근 가능 여부 확인
- 일부 약 정보만 조회되지 않으면 확인된 행은 잠기고 취소선으로 구분되며, 미확인 행만 수정·재시도되는지 확인
- 미확인 행이 남은 상태에서 확인된 약만 계속 사용할 때 경고 확인을 거쳐야 하는지 확인
- 전체 약 정보 조회가 기술적으로 실패하면 연결·지연·응답 오류에 맞는 복구 경로를 표시하는지 확인
- 전체 저장 후 오늘 일정 또는 저장 목록으로 이동하는 후속 동작 확인
- 홈 카드의 다음 복약 시간과 오늘 복용 진행률 표시 확인
- 저장 목록의 복용 상태 필터와 날짜 기준·방향 정렬 확인
- 오늘 복약 일정의 작은 화면 스크롤 확인
- 일정 API 실패 후 재시도와 정상 복구 확인
- 복용 완료 실행 취소와 알림 설정·해제 결과 안내 확인

자동 검증은 `flutter test test/accessibility_layout_regression_test.dart`와
기존 화면별 테스트에서 수행한다.

## 권장 기기 조합

| 구분 | 최소 조합 |
| --- | --- |
| 작은 Android 휴대폰 | 너비 320~360dp, Android API 34 이상 |
| 일반 Android 휴대폰 | 너비 390~430dp, Android API 34 이상 |
| 환자·보호자 연동 | 서로 다른 두 에뮬레이터 또는 실기기 |
| 글자 크기 | 기본, 130%, 160%, 200% |

## 화면·입력

- [ ] 모든 화면에서 글자, 버튼, 카드가 서로 겹치지 않는다.
- [ ] 긴 약 이름과 0.5정 같은 복용량이 잘리더라도 핵심 정보는 구분된다.
- [ ] 화면 하단 고정 버튼이 시스템 내비게이션 영역과 겹치지 않는다.
- [ ] 시간 선택기의 휠 조작과 숫자 직접 입력이 모두 가능하다.
- [ ] 키보드가 열린 상태에서도 확인·취소 버튼에 접근할 수 있다.
- [ ] 가로·세로 화면 전환 후 현재 입력값과 선택값이 유지된다.
- [ ] 처방전 촬영 화면을 좌우로 회전해도 가이드와 촬영 버튼이 겹치지 않고 같은 배치를 유지한다.
- [ ] 세로·가로 촬영 결과에는 화면 가이드 안쪽 영역만 남고 바깥 배경은 포함되지 않는다.
- [ ] 저장 목록에서 복용 중·복용 종료·전체 필터가 올바른 항목을 표시한다.
- [ ] 등록일자·복용날짜 정렬과 오름차순·내림차순 전환 결과가 일치한다.
- [ ] 전체 저장 완료 후 오늘 일정과 저장 목록 이동 버튼에 접근할 수 있다.
- [ ] 복용 완료 직후 실행 취소가 가능하고 화면과 서버 상태가 함께 복원된다.
- [ ] 알림 설정·해제 완료 안내가 화면 하단에 겹치지 않고 표시된다.

## TalkBack

- [ ] 뒤로가기, 닫기, 촬영, 편집, 분석, 저장 버튼의 용도를 읽어준다.
- [ ] 초점 이동 순서가 화면의 위에서 아래 순서와 일치한다.
- [ ] 선택된 정렬 기준, 복약 완료 체크, 알림 활성 상태를 읽어준다.
- [ ] 약품 이미지가 없을 때 장식 문자가 아니라 이미지 없음 상태를 읽어준다.
- [ ] 비활성화된 English 옵션과 추후 업데이트 안내를 함께 이해할 수 있다.

## 앱 종료·재부팅

- [ ] 앱을 강제 종료하고 다시 열어도 사용자 설정이 유지된다.
- [ ] 복약 완료 상태와 시간대별 알림 설정이 유지된다.
- [ ] 기기를 재부팅한 뒤 예약된 복약 알림이 정상 동작한다.
- [ ] 앱 업데이트 후 기존 저장 복약정보와 일정이 유지된다.

## 네트워크·절전

- [ ] 오프라인에서 서버 기능이 실패 이유와 재시도 방법을 표시한다.
- [ ] 서버 예외 원문 대신 연결·지연·응답·OCR 상황에 맞는 안내를 표시한다.
- [ ] 네트워크 복구 후 재시도하면 중복 저장 없이 정상 처리된다.
- [ ] Wi-Fi와 모바일 데이터 전환 중 화면이 멈추거나 중복 요청하지 않는다.
- [ ] 배터리 절전 모드에서도 허용된 복약 알림이 가능한 범위에서 동작한다.
- [ ] 정확한 알람 권한이 꺼진 경우 설정 방법을 안내한다.

## 환자·보호자 두 기기

- [ ] 환자 코드로 서로 다른 보호자 기기가 정상 연동된다.
- [ ] 같은 사용자 해시로 자기 자신을 보호자로 등록할 수 없다.
- [ ] 환자의 아침·점심·저녁·취침 전 완료 상태가 보호자 화면에 반영된다.
- [ ] 즉시 알림은 완료 상태가 바뀐 경우 한 번만 전달된다.
- [ ] 미복용 알림은 설정한 시간대와 확인 시각을 기준으로 한 번만 전달된다.
- [ ] 연동 해제 후 보호자가 환자 일정과 알림을 더 이상 조회하지 못한다.

## 통과 기록

테스트 날짜, 앱 커밋, Android 버전, 기기 이름, 실패 항목과 재현 절차를
팀 이슈 또는 릴리스 점검 문서에 남긴다. 실제 기기에서 확인하지 않은 항목은
통과로 표시하지 않는다.
