# 0.2.0 UI 통일성 검증 (2026-09-14)

## 변경 범위

- 오늘의 복약 일정의 기존 화면 구성을 기준으로 복약함·채팅·내 정보와 보조 화면의 제목, 초록색 헤더, 버튼 스타일을 통일했다.
- 제목의 시작 위치를 맞추고 기능 설명을 간결하게 정리했다. 헤더와 채팅 목록의 과도한 여백을 줄이되 큰 글씨에서 줄바꿈과 스크롤 접근을 유지한다.
- 처방전·알약 사진의 출처 선택과 약 등록 진입을 공통 흐름으로 정리했다. 건강 추천의 빈 상태에서 등록한 뒤 추천을 갱신하며, OCR은 홈의 분석 화면으로 연결한다.
- 일정 알림은 사용 여부와 시간을 초안으로 편집하고 저장한 변경만 적용한다. 취소하거나 변경 없이 저장하면 기존 알림을 유지한다.
- 복약함의 전체 선택은 현재 조회 결과에 한정한다. 삭제 직전 대상을 재검증하고 중복 요청을 막으며, 실패한 항목의 선택은 유지한다.

## 확인 결과

- Flutter 전체 테스트 720개 통과 및 정적 분석 지적 없음.
- 제목 위치·설명 간격·버튼 터치 영역, 작은 화면과 큰 글씨, 한국어·영어 표시를 회귀 테스트로 확인했다.
- 알림 편집의 저장·취소, 복약함 필터·선택 삭제, 사진 선택·등록 복귀 흐름을 테스트했다.
- 환자·보호자 Android 에뮬레이터에 적용했다. 큰 글씨와 기본 글씨의 채팅 목록, 주요 제목 정렬, 환경설정·건강 추천·약국 소제목의 한 줄 표시를 확인했다.

## 범위와 제한

- 개발용 Android 에뮬레이터 검증이며 실기기·iOS·서명된 배포 APK 검증을 대신하지 않는다.
- 더 좁은 화면이나 더 큰 접근성 글씨에서는 문구를 자르거나 강제로 축소하지 않고 필요한 줄바꿈을 허용한다.
- 서버 API, 알림 전달 방식, 데이터 소유권과 접근 권한은 이번 UI 통일 작업에서 변경하지 않았다.
- 기기 화면 캡처, 개인 로컬 경로, 계정별 테스트 데이터와 키는 문서에 포함하지 않는다.
