# 약국 지도 정보창 검증

## 변경 범위

- 지도 마커 또는 목록에서 약국을 선택하면 해당 위치와 하단 정보창을 함께 표시한다.
- 접기·펼치기와 내용 맞춤 높이를 적용하고 전화·길찾기·즐겨찾기·목록 전환을 유지한다.
- 선택하지 않은 약국에도 이름을 표시한다. 밀집 구간은 겹침을 조정하고 선택한 이름은 유지한다.
- GPS 버튼 아래 정보 버튼과 네이버 기본 로고는 변경하지 않는다.

## 확인 결과

- Flutter 전체 테스트 653개 통과, 정적 분석 오류 없음.
- 지도·표시 관련 테스트 25개 통과. 한글·영문 큰 글씨, 화면 크기 변경,
  접기·펼치기, 뒤로가기, 선택 해제, 전화·즐겨찾기와 채팅 공유를 포함한다.
- Android 에뮬레이터 두 대에서 이름 표시, 마커·목록 선택, 정보창 접기·펼치기,
  지도 탐색과 정보창 아래 여백 제거를 확인했다.
- 실제 전화 발신은 하지 않았으며, 외부 동작은 테스트 대역으로 검증했다.

## 남은 검증

실물 기기의 다양한 화면 크기와 접근성 설정에서 최종 확인이 필요하다.
이 기록은 정식 배포, 실물 기기 검증 또는 약국 영업시간 정확성을 보증하지 않는다.
