# 0.2.0 UI 변경 검증 (2026-09-12)

## 변경 범위

- 알림함: 같은 계정의 현재 대화 상대 이름을 표시하고, 선택·전체 선택 후 알림 내역만 삭제한다. 확인 중 새로 도착한 알림과 원래 대화·복약 기록은 유지한다.
- 건강 관리 추천: 서버가 복용 약 없음으로 응답할 때 홈과 같은 약 등록·식별 메뉴를 제공한다. 통신 오류는 별도로 안내한다.
- 약국: 지도 이동·확대 후 선택 지역에서 재검색하며 필터·새로고침도 그 검색 기준을 유지한다. 위치 조회 실패 시 홍익대학교 서울캠퍼스를 기준으로 안내하고, 빈 결과에서도 지도를 유지한다.
- 복약함: 기본값은 복용 중이며, 조회 조건 버튼에서 복용 중·복용 종료·전체를 선택한다. 정렬과 선택 삭제는 기존 동작을 유지한다.

## 확인 결과

- Flutter 전체 테스트 627개 통과 및 정적 분석 오류 없음.
- 알림 별칭 갱신·계정 분리·내용 숨김, 선택 삭제와 신규 알림 보존을 회귀 테스트로 검증했다.
- 건강 추천의 빈 상태와 서버 오류 구분, 등록 메뉴 진입·취소·복귀를 검증했다.
- 약국의 GPS 실패 대체·명시적 좌표 요청·검색 지역 유지·재시도·중복 요청 방지를 검증했다.
- 복약함의 기본 조건·필터 결과·취소 시 선택 유지·조건 변경 시 선택 초기화와 작은 화면의 한국어·영어 큰 글씨를 검증했다.
- Android 환자·보호자 에뮬레이터에 최신 디버그 앱을 설치했다. 실제 지도 이동·검색·위치 복귀와 복약함 선택 창을 확인했다. GPS를 끄는 테스트 후 원래 켜진 상태로 복구했다.

## 범위와 제한

- 로컬 개발 서버와 Android 에뮬레이터 기준이며 실기기·iOS·서명된 출시 APK 검증을 대신하지 않는다.
- 알림 상대 이름 변경은 앱 알림함에 적용한다. 시스템 푸시 제목 정책은 이번 변경 범위가 아니다.
- 로컬 약국 API는 확인 당시 홍익대 반경 20km의 전체 약국 조회에서도 한 곳만 반환했다. 지도 검색 동작과 공공 약국 데이터의 지역별 완전성은 별도 검증이 필요하다.
- 기기 화면 캡처, 테스트 계정의 실제 저장 데이터, 환경 파일과 키는 이 문서에 포함하지 않는다.
