이번 갱신에서는 에뮬레이터를 조작하거나 새 화면을 촬영하지 않았습니다. 제공된 최신 설정 화면과 기존 검수 폴더의 현재 공유·기록·화면 설정 캡처만 사용하고 구현과 대조했습니다. 화면은 예시이며 실제 환자 정보나 권장 복용 횟수를 의미하지 않습니다. 유지한 이전 화면은 필요한 경우 본문에서 과거 화면의 해당 영역을 보여 주는 예시임을 설명합니다.

- `assets/notification_settings_2026-10-22.png`: 제공된 최신 복약 및 알림 화면. 원본을 변경하지 않았습니다.
- `assets/settings-order-display.png`: 화면 및 음성의 홈 화면 위젯 추가 경로.
- `assets/history-share-patient-month.png`, `assets/history-share-final-dialog.png`, `assets/history-share-recipient.png`, `assets/history-time-label-removed.png`, `assets/history-share-readonly.png`: 월별 기록·공유 기간·수신자·공유 카드·현재 읽기 전용 기록.
- 기존 스크린샷 148개는 함께 배포하는 PDF의 이미지 픽셀을 재사용합니다. 별도의 원본 이미지 묶음이나 기준 PDF를 추가하지 않습니다.
- `source/layout.json`은 단계와 이미지 배치, `source/pdf-images.json`은 PDF 안의 이미지 픽셀 해시, `source/assets.sha256.json`은 별도 캡처 7개와 기존 로고의 파일 해시입니다.

모든 필수 문서 입력은 이 폴더 안에 있습니다. 글꼴과 Python·Poppler는 외부 실행 도구이며 설치 경로를 인자로 전달합니다. 머신별 절대 경로나 이전 임시 작업 폴더에 의존하지 않습니다. 재생성 방법은 [tools/README.md](tools/README.md)를 참고하세요. 생성 중간물과 렌더는 `.build/`에만 보관하며 배포하지 않습니다.

## 2026-10-17 이력

이하 내용과 캡처 해시는 직전 216쪽·303단계 판의 출처 이력입니다. 현재 재생성에 당시의 로컬 작업 폴더나 XML 파일은 필요하지 않습니다. 당시에는 212쪽·292단계 판에서 11단계를 추가하고 실제 앱 화면 28개를 60단계에 반영했습니다.

- 복약 기록: 좌우 날짜 화살표, 중앙 날짜 달력, 상태 건수 옆 정보 버튼, 보호자 읽기 전용 표시.
- 필요시 복용: 기록 화면의 신규 입력 버튼 대신 일정의 동그라미·일괄 체크, 2회부터 횟수 확인, 기존 기록의 연필 정정.
- 환자 필요시 확인 알림: 사용자가 켜고 고른 다음 시각에 한 번만. 보호자 필요시 알림: 끄기·복용 확인 즉시 알림만.
- 보호자 일정의 공통 시간대 배치, 직접 등록·처방 교체의 공통 입력 양식, 변경 시작일과 교체 복용 시작일 구분.
- 상태 배지: 중단 빨강, 교체 파랑, 중단·교체 예정 주황, 기간 종료 회색. 실제 캡처에는 중단·교체가 표시되며 예정·종료는 코드로 확인했습니다.
- CSV의 별도 시작일·종료일과 간략 공유 안내, 홈 준비 점검 바로가기 없음, 설정 분류·소제목 유지.

### 당시 화면과 코드 근거

환자 emulator-5554, 보호자 emulator-5556의 실행 중인 데모 앱에서 PNG와 UI XML을 함께 캡처했습니다. 실제 환자 정보가 아닌 Demo 테스트 약입니다. 약 이름·횟수·기기 시각이 다른 화면은 각각 조작 위치의 예시이며 연속된 복용이나 권장 횟수가 아닙니다. 문서의 날짜·시각 설명은 앱의 한국 시간 기준입니다.
이번 촬영에서는 조회·달력·입력폼·설정창·저장 전 확인창과 Android 공유창을 열었으며 복용 기록·약 정보·알림 설정을 저장하거나 중단·교체를 적용하지 않았습니다. 중단·교체 확인창은 취소로 닫았습니다. 앱/백엔드 수정·빌드·계정 초기화·외부 AI 호출·실제 공유 전송을 하지 않았습니다. 기록된 테스트 약과 횟수는 기존 데모 데이터입니다. 추가 복용 횟수 확인은 제공된 자료를 재사용했습니다. Android 공유창은 현재 UI에서 CSV 공유를 눌러 기간 재조회 후 직접 촬영하고, 앱 선택·전송 없이 뒤로가기로 닫았습니다.
변경되지 않은 0.2.1·0.2.3 검수 화면을 유지했습니다. 이전에 확보한 처방전 수정·알약 검토 등 분리된 제품 위젯 예시도 유지하며 이번의 실제 앱 캡처로 재분류하지 않았습니다. 캡처 내용은 합성하지 않고 시스템 상태·탐색 영역만 잘랐습니다. 빨간 강조 테두리와 번호는 PDF 설명용 표시입니다.
