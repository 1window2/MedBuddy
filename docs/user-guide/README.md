# MedBuddy 사용설명서

환자와 보호자를 위한 Android 앱 사용 안내입니다. 약 등록과 복약 기록부터 환자·보호자 연결, 가족 채팅, 위젯, 병원·약국 찾기와 환경설정까지 이용 순서대로 설명합니다.

앱 버전: 0.2.0

[캡처가 포함된 사용설명서 PDF](MedBuddy_User_Guide_ko.pdf)

본문은 GitHub에서 바로 읽을 수 있습니다. 각 소섹션의 PDF 링크에서 화면을 확인하고 단계 번호 순서대로 진행하세요. 사진 안의 빨간 번호는 단계 아래 번호 목록과 대응합니다.

PDF 오른쪽 아래에는 현재 소섹션 번호와 제목이 표시됩니다. 참고는 각 대섹션 끝에 모았으며, 소섹션 번호·페이지·사진 번호 링크를 누르면 관련 화면으로 이동합니다. 사진 번호는 본문의 단계 번호입니다.

**안내:** 설명서의 약과 용량은 조작 예시입니다. 실제 복용은 처방과 복약지도에 따르세요. 완료 표시는 사용자가 남긴 기록입니다.

#### 2. 한국어 선택

‘한국어’를 선택하면 창이 닫히고 로그인·가입·이메일 인증 안내가 한국어로 표시됩니다. 선택한 언어는 기기에 저장됩니다.

### 1.2 이메일로 로그인하기

<a id="manual_page_7"></a>

#### 1. 이메일 로그인

인터넷에 연결한 뒤 가입한 이메일과 비밀번호를 입력하고 ‘로그인’을 누르세요. 이메일 인증을 마친 계정은 홈으로 이동합니다.

1. 이메일: 가입한 주소 입력
2. 비밀번호: 계정 암호 입력
3. 로그인: 입력한 계정으로

#### 2. 로그인 계정 확인

홈이 열리면 하단 ‘내 정보’를 눌러 로그인한 계정을 확인하세요. 이메일 인증 화면이 나오면 인증부터 마치세요.

### 1.3 가입하고 이메일 인증하기

[소섹션: PDF 8쪽](MedBuddy_User_Guide_ko.pdf#page=8)

<a id="manual_page_9"></a>

[화면 예시: PDF 9쪽](MedBuddy_User_Guide_ko.pdf#page=9)

#### 1. 회원가입 열기

‘MedBuddy가 처음이신가요? 회원가입’을 눌러 ‘안전한 계정 만들기’ 화면을 여세요. 환자와 보호자 모두 같은 방법으로 가입하며, 가입 중 역할을 고르는 화면은 없습니다.

#### 2. 이메일과 비밀번호 입력

직접 확인할 수 있는 이메일과 6자 이상 비밀번호를 입력하고 ‘회원가입’을 누르세요. 입력 오류가 나오면 해당 칸의 안내에 따라 고치세요.

1. 인증 메일을 받을 주소
2. 비밀번호: 6자 이상
3. 회원가입: 입력한 정보로 가입

#### 3. 인증 메일 확인

‘이메일을 인증해 주세요’가 나오면 표시된 주소의 메일함을 열어 인증 링크를 누르세요. 메일이 없으면 주소와 스팸함을 확인한 뒤 다시 보내세요.

1. 인증 안내: 메일 링크 이용
2. 수신 주소: 해당 메일함 열기
3. 메일이 없으면 다시 보내기

#### 4. 메일 인증 후 앱으로 돌아오기

메일의 인증 링크를 누른 뒤 MedBuddy로 돌아오세요. 앱이 인증 상태를 자동으로 확인하고, 인증이 완료되면 홈으로 이동합니다.

<a id="manual_page_10"></a>

[화면 예시: PDF 10쪽](MedBuddy_User_Guide_ko.pdf#page=10)

#### 5. 인증 상태 다시 확인

인증 화면이 남아 있으면 ‘인증 상태 다시 확인’을 누르세요. ‘아직 인증되지 않았어요.’가 나오면 메일의 인증 링크를 누른 뒤 앱으로 돌아오세요.

1. 미인증: 메일 링크 먼저 확인
2. 인증 후 상태 다시 확인

#### 6. 가입한 계정으로 시작

인증 후 홈이 열리면 하단 ‘내 정보’에서 가입한 계정인지 확인하고 앱을 이용하세요.

### 1.4 다른 방법으로 시작하기

[소섹션: PDF 11쪽](MedBuddy_User_Guide_ko.pdf#page=11)

<a id="manual_page_12"></a>

[화면 예시: PDF 12쪽](MedBuddy_User_Guide_ko.pdf#page=12)

#### 1. Google 로그인 시작

인터넷 연결을 확인하고 로그인 화면의 ‘Google로 계속하기’를 누르세요. MedBuddy의 이메일 로그인 칸에는 Google 비밀번호를 입력하지 마세요.

#### 2. Google 계정 선택과 인증

Google 안내가 나오면 사용할 계정을 확인하고 인증을 진행하세요. 취소하면 로그인되지 않습니다. 오류가 나면 연결을 확인하고 ‘Google로 계속하기’에서 다시 시도하세요.

#### 3. 게스트 시작

로그인 화면에서 ‘회원가입 없이 계속하기’를 눌러 게스트 이용 안내를 여세요.

#### 4. 게스트 이용 여부 선택

데이터 보관 제한을 읽고 ‘계속’을 누르면 게스트로 홈에 들어갑니다. 시작하지 않으려면 ‘취소’를 누르세요. 게스트 로그아웃 시 데이터는 영구 삭제됩니다.

1. 게스트: 임시 계정 이용
2. 기기 변경·삭제 전 보관 제한
3. 취소: 게스트 시작 안 함
4. 계속: 게스트로 홈 열기

<a id="manual_page_13"></a>

[화면 예시: PDF 13쪽](MedBuddy_User_Guide_ko.pdf#page=13)

#### 5. 게스트 계정 확인

하단 ‘내 정보’를 눌러 ‘게스트 계정’ 표시를 확인하세요. 데이터를 보존하며 정식 계정으로 전환하는 버튼은 없습니다.

### 1.5 비밀번호 다시 설정하기

[소섹션: PDF 14쪽](MedBuddy_User_Guide_ko.pdf#page=14)

<a id="manual_page_15"></a>

[화면 예시: PDF 15쪽](MedBuddy_User_Guide_ko.pdf#page=15)

#### 1. 재설정 메일 요청

이메일·비밀번호로 가입했고 해당 메일함을 열 수 있는 계정에서 사용하세요. 가입한 이메일을 입력하고 ‘비밀번호 찾기’를 누르세요. 현재 비밀번호는 필요 없습니다.

1. 이메일: 재설정할 계정 주소
2. 비밀번호 재설정 메일 요청

#### 2. 메일에서 비밀번호 변경

‘비밀번호 재설정 메일을 보냈습니다.’가 나오면 받은 메일에서 새 비밀번호를 정하고 MedBuddy로 돌아오세요. 복약 자료와 설정, Google 비밀번호는 바뀌지 않습니다.

#### 3. 새 비밀번호로 로그인

이메일·비밀번호로 가입한 계정의 메일함에서 재설정을 마친 뒤 새 비밀번호로 로그인하세요. 인증이 완료되면 홈이 열립니다.

### 1.6 홈과 주요 메뉴 익히기

[소섹션: PDF 16쪽](MedBuddy_User_Guide_ko.pdf#page=16)

<a id="manual_page_17"></a>

[화면 예시: PDF 17쪽](MedBuddy_User_Guide_ko.pdf#page=17)

#### 1. 오늘의 기록 확인

홈 위쪽에서 오늘의 복약 진행률과 선택한 시간대의 약을 확인하세요. 예시는 오늘 전체 5건 중 완료 0건이며, 아침 약은 미복용입니다. 약이 등록된 시간대만 표시됩니다.

1. 오늘 전체 진행률 0/5
2. 선택한 아침의 미복용 상태

#### 2. 네 가지 바로가기

홈의 네 가지 바로가기에서 약 등록·식별, 건강 관리 추천, 근처 운영 병원·약국, 환경설정을 여세요. 병원·약국 타일을 누르면 찾을 곳을 선택하는 창이 열립니다.

1. 약 등록·식별
2. 건강 관리 추천
3. 근처 운영 병원·약국
4. 환경설정

#### 3. 일정에서 오늘 기록하기

하단 ‘일정’을 눌러 내 계정의 오늘 약을 시간대별로 확인하고 복용 기록을 남기세요.

#### 4. 복약함에서 저장한 약 찾기

1. 알림 사용·기본 복약 시간
2. 글씨 크기·음성 속도·언어

### 2.2 인식한 내용을 확인하고 수정하기

#### 1. 인식 결과 검토

인식이 끝나면 검토 표의 약 이름과 함량을 원본 처방전과 비교하세요. 화면의 500mg 제품명도 정확히 인식됐는지 확인해야 합니다.

#### 2. 원본 사진 확인

처방 내역 위의 원본 사진에서 약 이름·함량·복용 정보를 확인하세요. 자세히 보려면 사진의 확대 아이콘을 누르세요. 초록색 표시는 인식 영역입니다.

#### 3. 약 이름과 함량 대조

표의 제품명과 함량을 원본과 대조하세요. 예시에는 ‘바이엘아스피린정500밀리그람’이 인식되어 있으며, 이름뿐 아니라 함량도 같아야 합니다.

#### 4. 복용량과 횟수 확인

표를 옆으로 밀어 고칠 칸을 누르고, 수정 창의 ‘1회 투약량’과 ‘1일 횟수’를 각각 처방과 대조하세요. 입력칸이 가리면 키보드를 닫거나 창을 내려 보세요.

<a id="manual_page_25"></a>

[화면 예시: PDF 25쪽](MedBuddy_User_Guide_ko.pdf#page=25)

#### 5. 기간과 시작일 확인

1. 총 투약일: 전체 복용 일수
2. 복용 시작일: 처방과 대조

#### 6. 약 이름과 날짜 수정

표의 약 이름이나 고칠 값을 눌러 수정 창을 여세요. 이름·함량을 원본대로 고치고 조제일자를 확인하세요. 날짜는 달력 아이콘으로 선택할 수 있습니다.

1. 약 이름: 제품명·함량 수정
2. 달력: 조제일자 선택

#### 7. 달력에서 날짜 선택

달력에서 필요한 월로 이동해 날짜를 고르세요. 위쪽에 표시된 선택 날짜를 확인하고 ‘확인’을 누르세요.

#### 8. 수정 내용 적용

확인한 수정 내용을 검토 표에 반영하려면 오른쪽 아래 ‘적용’을 누르세요. 변경하지 않고 돌아가려면 ‘취소’를 누르세요.

1. 검토 표: 이름·함량 대조
2. 검토 후 제품 조회·분석

#### 10. 누락된 약 추가

원본 처방전에 있지만 표에 없는 약은 사진 아래 ‘누락된 약 추가’를 눌러 이름과 복용 정보를 입력하세요.

1. 누락된 약의 제품명·함량
2. 저녁: 처방과 시간대 대조
3. 적용: 검토 표에 약 추가

#### 1. 분석 결과 열기

분석한 약 수와 복용 기간을 확인한 뒤 ‘결과 확인하기’를 누르세요. 예시는 약 1개, 3일이며, 아직 복약함에 저장된 상태는 아닙니다.

#### 2. 제품과 일정 대조

결과의 약 이름·함량·복용량·횟수·기간을 원본과 대조하세요. 예시는 ‘바이엘아스피린정500밀리그람’이며, 원본과 다르면 저장하지 말고 다시 확인하세요.

1. 제품명·함량: 원본과 대조
2. 복용량·횟수·기간 대조

#### 3. 전체 저장

모든 결과가 처방과 맞는지 확인한 뒤 화면 맨 아래 ‘전체 저장하기’를 눌러 검토한 약을 한꺼번에 저장하세요.

#### 4. 저장한 정보 열기

‘복약 일정 저장 완료’가 나오면 ‘저장된 정보 보기’를 눌러 목록의 약 이름과 복용 기간을 확인하세요. 일정 조회가 실패해도 즉시 재등록하지 말고 연결을 확인한 뒤 다시 조회하세요.

1. 복약 일정 저장 완료 표시
2. 저장 목록에서 등록 내용 확인

<a id="manual_page_34"></a>

[화면 예시: PDF 34쪽](MedBuddy_User_Guide_ko.pdf#page=34)

#### 5. 한 약만 저장

저장할 약의 이름과 복용 일정을 확인한 뒤 해당 카드 오른쪽 위 저장 아이콘을 누르세요. 약마다 개별로 저장할 수 있습니다.

#### 6. 개별 저장 완료 확인

저장 아이콘이 완료 체크로 바뀌고 성공 안내가 나오는지 확인하세요. 저장 표시는 앱의 처리 결과이며, 실제 복용은 처방과 복약지도에 따르세요.

1. 완료 체크: 해당 약 저장됨
2. 복약 정보 저장 성공 안내

### 2.6 약 정보 직접 입력하기

[소섹션: PDF 35쪽](MedBuddy_User_Guide_ko.pdf#page=35)

<a id="manual_page_36"></a>

[화면 예시: PDF 36쪽](MedBuddy_User_Guide_ko.pdf#page=36)

#### 1. 약 이름과 수량 입력

‘약 등록·식별’에서 ‘직접 등록’을 선택하고 약 이름과 1회 복용량의 수량을 입력하세요. 사진 없이도 등록할 수 있으며, 약 봉투나 복약 안내를 기준으로 입력하세요.

1. 약 봉투의 이름 입력
2. 수량: 1회 복용할 양

#### 2. 복용량 단위 선택

수량과 별도로 단위 목록에서 정·캡슐·포·mL·방울 중 복약 안내에 맞는 항목을 고르세요.

#### 3. 알약 사진 추가

사진을 붙이려면 ‘알약 사진’ 오른쪽의 사진 추가 아이콘을 누르세요. 사진은 선택 사항이며, 선택한 사진은 이 기기의 앱 내부에만 저장됩니다.

#### 4. 복용 기간 지정

시작일과 종료일을 각각 눌러 복용 기간을 지정하고, 두 날짜 아래에 표시되는 총 복용 일수를 확인하세요. 종료일은 시작일보다 앞설 수 없습니다.

1. 시작일: 복용 시작 날짜
2. 종료일: 시작일보다 빠르지 않게

<a id="manual_page_37"></a>

[화면 예시: PDF 37쪽](MedBuddy_User_Guide_ko.pdf#page=37)

#### 5. 종료 날짜 선택

달력에서 종료 날짜를 선택하고 오른쪽 아래 ‘확인’을 누르세요. 화면은 9월 28일을 고른 예시이며, 실제 복용 기간에 맞게 선택하세요.

1. 종료 날짜: 예시 9월 28일
2. 확인: 선택한 날짜 반영

#### 6. 복용 기간 재확인

입력 화면으로 돌아오면 시작일·종료일과 총 일수가 맞는지 확인하세요. 예시는 9월 22일부터 28일까지 총 7일입니다.

#### 7. 복용 시간대 선택

아래로 내려 아침·점심·저녁·취침 전 중 복약 안내에 맞는 시간대를 모두 누르세요. 선택한 시간대에는 초록색 체크가 표시됩니다.

#### 8. 복약 정보 저장

입력이 맞으면 ‘복약 정보 저장’을 누르세요. 요청 중에는 버튼이 ‘저장 중...’으로 바뀌므로 처리가 끝날 때까지 기다리세요.

<a id="manual_page_38"></a>

[화면 예시: PDF 38쪽](MedBuddy_User_Guide_ko.pdf#page=38)

#### 9. 복약함에서 확인

저장 후 복약함을 열어 약 이름과 복용 기간을 확인하세요. 화면은 SampleTablet이 저장된 예시입니다. 약을 삭제하면 연결된 복용 기록도 잃을 수 있습니다.

#### 10. 빠진 약 이름 입력

이름을 비운 채 저장해 빨간 안내가 나타나면 약 이름을 입력한 뒤 다시 저장하세요.

#### 11. 저장된 복용 정보 확인

복약함의 ‘가이드’를 열어 등록된 복용량·횟수·기간을 확인하세요. 예시는 1정·3회·7일입니다. ‘정보 없음’인 효능이나 복용법은 임의로 채우지 마세요.

### 2.7 한 장에 찍힌 여러 알약 찾기

[소섹션: PDF 39쪽](MedBuddy_User_Guide_ko.pdf#page=39)

<a id="manual_page_40"></a>

[화면 예시: PDF 40쪽](MedBuddy_User_Guide_ko.pdf#page=40)

#### 1. 여러 알약 식별 선택

홈 ‘약 등록·식별’의 ‘낱알약 식별’에서 ‘여러 알약 한 번에 찾기’를 선택하세요. 외부 AI가 한 사진의 알약을 번호별로 분석합니다. 후보만으로 약을 확정하지 마세요.

#### 2. 알약 사진 추가

알약을 최대 10개까지 서로 겹치지 않게 준비하고 ‘사진 추가’를 눌러 카메라나 갤러리에서 사진을 가져오세요.

#### 3. 사진 번호와 후보 대조

분석한 사진의 번호와 아래 후보 목록의 번호를 맞춰 확인하세요. 예시의 1·2번은 같은 제품의 앞뒷면이며, 서로 다른 약 두 종류를 뜻하지 않습니다.

#### 4. 사진 변경

다른 사진을 가져오려면 번호별 분석 버튼 위의 ‘사진 변경’을 누르세요.

### 2.8 알약마다 앞뒷면 사진 넣기

[소섹션: PDF 41쪽](MedBuddy_User_Guide_ko.pdf#page=41)

<a id="manual_page_42"></a>

[화면 예시: PDF 42쪽](MedBuddy_User_Guide_ko.pdf#page=42)

#### 1. 앞면과 뒷면 추가

‘낱알약 식별’의 ‘알약 하나씩 찾기’에서 ‘앞면’을 눌러 필수 사진을 가져오세요. 필요하면 같은 알약의 ‘뒷면’도 추가하세요. 한 묶음에 다른 알약을 섞지 마세요.

1. 앞면: 묶음마다 필수
2. 뒷면: 같은 알약 사진, 선택

#### 2. 추가한 사진 확인

추가된 사진이 맞는지 확인하세요. 잘못 넣었으면 사진 오른쪽 위 X를 눌러 제거하세요. 화면은 앞면에만 사진을 넣은 예시입니다.

1. 앞면 사진: 알약 확인
2. X: 잘못 넣은 앞면 제거

#### 3. 모든 앞면 사진 준비

‘알약 한 개 더 추가’를 눌러 새 묶음에도 앞면을 넣으세요. 필요 없는 묶음은 휴지통으로 삭제하세요. 앞면이 하나라도 빠지면 후보 찾기 버튼을 사용할 수 없습니다.

1. 휴지통: 알약 2 묶음 삭제
2. 새 묶음의 앞면 사진 필수
3. 모든 앞면을 넣어야 후보 찾기

#### 4. 후보 찾기 시작

모든 묶음에 앞면 사진을 넣은 뒤 ‘알약 N개 후보 찾기’를 누르세요. 화면은 앞면 한 장을 넣어 알약 1개의 후보를 찾을 수 있는 상태입니다.

1. 다른 알약의 사진 묶음 추가
2. 사진으로 알약 1개 후보 찾기

### 2.9 알약 후보를 비교하고 다시 확인하기

[소섹션: PDF 43쪽](MedBuddy_User_Guide_ko.pdf#page=43)

<a id="manual_page_44"></a>

[화면 예시: PDF 44쪽](MedBuddy_User_Guide_ko.pdf#page=44)

#### 1. 일치도 경고와 제품 비교

사진 품질·일치도 경고를 읽고 모양·색·각인을 후보의 제품 정보, 실물·포장과 직접 대조하세요. ‘추가 확인 필요’가 있으면 특히 주의하세요.

1. 일치도·사진 품질 경고
2. 각인: TYLENOL / 500

#### 2. 대조한 후보 선택

실물과 포장 정보를 대조한 후보를 누르면 초록색 테두리와 선택 표시가 생깁니다. 선택 표시는 약의 식별이 확정됐다는 뜻은 아닙니다.

#### 3. 추가 후보 펼치기

해당 번호의 후보 목록 아래에 ‘비슷한 후보 더 보기’가 있으면 눌러 추가 후보를 펼치세요. 번호마다 후보 수는 다를 수 있습니다.

#### 4. 추가 후보 비교

기존 목록 아래에 새로 나타난 후보도 제품명과 각인을 실물·포장과 대조하세요. 목록에 있다는 이유만으로 같은 약이라고 판단하지 마세요.

1. 각인: HCD / 500
2. 각인: Y분할선J / 500

<a id="manual_page_45"></a>

[화면 예시: PDF 45쪽](MedBuddy_User_Guide_ko.pdf#page=45)

#### 5. 재분석 또는 뒷면 추가

사진의 번호가 맞는지 확인한 뒤 후보 목록 위의 ‘영역 다시 분석’이나 ‘뒷면 추가’를 누르세요. 뒷면은 반드시 같은 알약을 뒤집은 사진을 사용하세요.

1. 알약 1 영역 다시 분석
2. 같은 알약 1의 뒷면 추가

#### 6. 뒷면 사진 출처 선택

안내 위의 앞면 사진을 확인하고 같은 알약의 뒷면을 카메라나 갤러리로 가져오세요. 다른 알약을 연결하지 마세요. ‘취소’를 누르면 추가하지 않습니다.

1. 같은 알약을 뒤집어 촬영
2. 사진 출처: 갤러리·카메라

### 2.10 선택한 알약 저장하기

[소섹션: PDF 46쪽](MedBuddy_User_Guide_ko.pdf#page=46)

<a id="manual_page_47"></a>

[화면 예시: PDF 47쪽](MedBuddy_User_Guide_ko.pdf#page=47)

#### 1. 복약 정보 검토 시작

후보 목록 아래 ‘선택한 후보 확인’을 눌러 복약 정보를 검토하세요. 화면은 알약 한 개의 후보를 선택한 예시입니다.

#### 2. 임시 복약 정보 수정

안내를 읽고 약 오른쪽 연필 아이콘을 눌러 복용량·횟수·기간·시간대를 고치세요. 사진만으로 실제 복용 정보를 알 수 없으므로 임시 기본값을 그대로 저장하지 마세요.

1. 임시 값: 처방·약 봉투 대조
2. 연필: 복약 정보 수정

#### 3. 이름·시작일·복용량 수정

수정 창 위쪽의 약 이름·복용 시작일·1회 복용량을 처방전이나 약 봉투와 대조해 고치세요. ‘취소’를 누르면 변경을 적용하지 않고 돌아갑니다.

#### 4. 횟수·기간·시간대 적용

하루 횟수와 기간을 입력하고 복용 시간대가 처방과 맞는지 확인한 뒤 ‘적용’을 누르세요. 화면은 하루 2회, 아침·저녁을 고른 예시입니다.

1. 하루 횟수·전체 복용 일수
2. 실제 복용할 시간대 선택
3. 적용: 수정한 일정 반영

<a id="manual_page_48"></a>

[화면 예시: PDF 48쪽](MedBuddy_User_Guide_ko.pdf#page=48)

#### 5. 변경 내용 재확인

복약 정보 확인 화면에서 약 이름과 수정한 복용 일정을 다시 확인하세요. 예시는 하루 2회, 아침·저녁으로 반영된 상태입니다.

#### 6. 복약 정보 저장 요청

정보가 처방이나 약 봉투와 맞으면 화면 맨 아래 ‘확인하고 저장하기’를 눌러 복약 정보를 저장하세요.

#### 7. 저장 완료 확인

‘저장 완료’와 ‘복약 정보를 저장했습니다.’ 안내를 확인하세요. 이는 앱의 저장 처리 결과이며 후보 식별의 정확성을 보증하지 않습니다.

1. 저장 완료 상태 표시
2. 복약 정보 저장 안내

#### 8. 여러 알약 검토 시작

번호별 후보를 확인하고 ‘선택한 알약 N개 검토 후 저장’을 누르세요. 예시처럼 두 번호에서 같은 제품을 선택하면 중복 확인 창이 나타날 수 있습니다.

<a id="manual_page_49"></a>

[화면 예시: PDF 49쪽](MedBuddy_User_Guide_ko.pdf#page=49)

#### 9. 중복 처리 방식 선택

‘각각 유지’나 ‘같은 일정만 묶기’를 선택하세요. 묶기는 복약 정보 검토 뒤 적용되며 복용량·날짜·기간 등이 다르면 별도로 유지됩니다. 돌아가려면 ‘취소’를 누르세요. 아직 저장된 것은 아닙니다.

1. 완전히 같은 일정만 묶기
2. 각각 유지 / 같은 일정만 묶기

### 3.1 홈에서 오늘 일정 확인하기

[소섹션: PDF 53쪽](MedBuddy_User_Guide_ko.pdf#page=53)

<a id="manual_page_54"></a>

[화면 예시: PDF 54쪽](MedBuddy_User_Guide_ko.pdf#page=54)

#### 1. 오늘 기록의 진행률

오늘의 복약 진행률을 확인하세요. 앞의 숫자는 완료로 기록한 건수, 뒤의 숫자는 오늘 전체 건수입니다. 예시는 0/5이며 같은 약도 시간대가 다르면 별도 기록입니다.

#### 2. 시간대와 미복용 확인

시간대 요약에서 완료 여부, 알림 시각, 약 이름을 확인하세요. 예시는 저녁 미복용이며 테스트 저녁약 외 1개가 표시됩니다. 등록된 아침·점심·저녁을 나타내는 점 세 개 중 세 번째 점이 채워집니다.

#### 3. 아침에서 시작

아침 요약을 확인한 뒤 요약 영역을 왼쪽으로 밀어 점심으로 이동하세요. 예시는 아침 약 2건이 미복용이며 첫 번째 점이 채워져 있습니다. 오늘 전체 진행률은 0/5입니다.

#### 4. 점심 기록 확인

점심의 약 이름과 미복용 상태를 확인하세요. 예시는 점심 약 1건이며 세 점 중 두 번째 점이 채워집니다. 전체 진행률은 0/5로 유지되고 오른쪽으로 밀면 아침으로 돌아갑니다.

<a id="manual_page_55"></a>

[화면 예시: PDF 55쪽](MedBuddy_User_Guide_ko.pdf#page=55)

#### 5. 저녁 기록 확인

다시 왼쪽으로 밀어 저녁을 확인하세요. 예시는 저녁 약 2건이 미복용이며 세 번째 점이 채워집니다. 약이 등록되지 않은 취침 전은 표시되지 않아 더 왼쪽으로 밀어도 저녁에 머뭅니다.

### 3.2 홈에서 완료와 취소 기록하기

[소섹션: PDF 56쪽](MedBuddy_User_Guide_ko.pdf#page=56)

<a id="manual_page_57"></a>

[화면 예시: PDF 57쪽](MedBuddy_User_Guide_ko.pdf#page=57)

#### 1. 현재 시간대 기록

아침의 약 이름과 시간대를 확인한 뒤 실제로 모두 복용했을 때 ‘복용했어요’를 누르세요. 예시에서는 아침 약 2건이 함께 완료로 기록되며 추가 확인창은 나타나지 않습니다. 일부만 복용했다면 전체 일정에서 개별 체크하세요.

#### 2. 완료 후 다음 일정

아침 약 2건이 완료되어 진행률이 2/5로 바뀌고, 뒤쪽의 다음 미완료 시간대인 점심으로 자동 이동합니다. 예시는 점심이 미복용이며 두 번째 점이 채워져 있습니다. 아침의 완료 상태를 다시 보려면 요약 영역을 오른쪽으로 밀어 돌아가세요.

1. 아침 2건 완료, 전체 진행률 2/5
2. 다음 미완료 시간대인 점심으로 자동 이동

<a id="manual_page_58"></a>

[화면 예시: PDF 58쪽](MedBuddy_User_Guide_ko.pdf#page=58)

#### 3. 완료한 시간대 취소

점심 요약을 오른쪽으로 밀어 아침으로 돌아오세요. ‘아침 · 복용 완료’와 전체 진행률 2/5를 확인한 뒤 잘못 남긴 기록만 ‘복용 취소’로 되돌리세요. 예시에서는 아침 약 2건이 함께 취소됩니다.

#### 4. 취소 후 상태

아침 약 2건이 미복용으로 돌아와 진행률이 0/5가 되고 ‘복용했어요’ 버튼이 다시 보입니다. 취소 후에는 아침 시간대에 그대로 머물며 다른 시간대의 기록은 바뀌지 않습니다. 약 하나만 취소하려면 전체 일정의 해당 체크를 사용하세요.

1. 취소 후 전체 진행률 0/5
2. 아침 미복용, 첫 번째 점 유지
3. 다시 표시된 복용했어요 버튼

### 3.3 전체 일정에서 약별로 기록하기

[소섹션: PDF 59쪽](MedBuddy_User_Guide_ko.pdf#page=59)

<a id="manual_page_60"></a>

[화면 예시: PDF 60쪽](MedBuddy_User_Guide_ko.pdf#page=60)

#### 1. 내 전체 일정 열기

하단 ‘일정’을 눌러 내 계정에 등록된 오늘의 약을 시간대별로 확인하세요. 연결된 환자의 일정은 보호자 홈이나 연동 목록에서 따로 여세요.

#### 2. 기록·상세정보·알림 구분

내 ‘일정’에서 약 이름·1회 복용량을 처방과 대조하세요. 왼쪽 원은 복용 기록, 약 이름은 상세정보, 종은 알림 설정입니다. 환자 일정은 보호자 홈이나 연동 목록에서 여세요.

1. 원: 기록 / 약 이름: 상세
2. 종: 시간대 알림 설정

#### 3. 복용한 약만 기록

실제로 복용한 약 왼쪽의 빈 원을 누르세요. 선택한 약의 해당 시간대만 완료되며, 같은 시간대의 다른 약이나 다른 시간대 기록은 바뀌지 않습니다.

#### 4. 완료 상태와 실행 취소

체크 표시와 약 이름의 취소선으로 완료 상태를 확인하세요. 잘못 눌렀다면 완료 직후 아래에 잠깐 나타나는 ‘실행 취소’를 누르세요.

1. 완료 체크와 이름의 취소선
2. 실행 취소: 방금 기록 되돌림

<a id="manual_page_61"></a>

[화면 예시: PDF 61쪽](MedBuddy_User_Guide_ko.pdf#page=61)

#### 5. 약 하나의 기록 취소

취소할 약의 체크 표시를 다시 누르면 해당 약의 그 시간대 기록만 해제됩니다. ‘실행 취소’ 안내가 사라진 뒤에도 사용할 수 있습니다.

#### 6. 취소된 약 확인

체크가 빈 원으로, 약 이름이 취소선 없는 글씨로 돌아오고 진행률이 줄었는지 확인하세요. 실제로 복용하지 않았는데 완료로 남은 기록이 없는지도 살펴보세요.

#### 7. 아래쪽 일정 확인

일정 목록을 위로 밀어 저녁·취침 전 등 아래쪽 시간대를 보세요. 진행률과 하단 메뉴는 유지되고 목록만 움직입니다. 약이 예상과 다르면 복약함의 복용 기간과 등록 시간대를 확인하세요.

#### 8. 전체 일정의 빈 시간대 확인

전체 일정을 위로 밀어 ‘복용할 약이 없습니다’가 보이면 복약함의 기간·시간대를 확인하세요. 빈 일정만으로 약이 삭제된 것은 아닙니다. 홈에서는 약이 없는 시간대 페이지를 표시하지 않습니다.

#### 1. 시간대 전체 완료

#### 1. 시간대 알림 설정 열기

#### 2. 알림 사용 켜기

‘알림 사용’을 켜면 알림 시간 버튼을 사용할 수 있습니다. 꺼져 있으면 시간을 누를 수 없습니다. 알림을 받으려면 휴대폰 알림 권한과 환경설정의 ‘내 복약 알림’도 켜세요.

#### 3. 알림 시간 선택

오늘의 복약 일정에서 연 시간대 알림 설정창의 ‘알림 시간’을 누르세요. 해당 시간대의 시와 분을 고르는 창이 열립니다.

#### 4. 시간 선택 확인

휠을 움직여 시·분을 고르거나 가운데 숫자를 눌러 직접 입력한 뒤 오른쪽 위 ‘확인’을 누르세요. 시는 0~23, 분은 0~59이며, 설정창에서 별도로 저장해야 합니다.

1. 시·분 휠 또는 직접 입력
2. 확인: 시각 선택, 저장 별도

1. 복약 안내에 맞는 시각 확인
2. 저장: 알림 여부·시각 반영

### 3.6 연결이 끊겼을 때 기록 확인하기

#### 1. 서버 전송 대기 확인

인터넷이 끊기면 복용 기록이 기기에 먼저 남고 ‘전송 대기’가 표시될 수 있습니다. 보호자에게 아직 전달되지 않았을 수 있으니 약을 다시 먹거나 기록을 반복하지 말고 전송 상태를 확인하세요.

#### 2. 전송 대기 기록 열기

전송 대기 안내를 눌러 약 이름·기록 날짜·시간대·복용 또는 취소 여부를 확인하세요. 기기에 저장된 것과 서버 저장 완료는 다릅니다. 전송 전에 앱 데이터를 지우거나 재설치하지 마세요.

#### 3. 기존 대기 기록 재전송

인터넷 연결 후 앱으로 돌아오면 대기 기록 전송을 다시 시도합니다. 필요하면 ‘다시 전송’을 누르고 처리가 끝날 때까지 기다리세요. 기록을 반복 입력하지 마세요. 날짜가 바뀌어도 원래 날짜로 전송됩니다.

#### 4. 서버 저장 완료 확인

‘서버에 모두 저장했습니다.’가 나오면 대기 기록이 처리된 상태입니다. 보호자 화면도 새로고침해 최신 상태를 확인하세요. ‘전송 확인 필요’가 계속되면 기록 내용을 확인하고 함부로 지우지 마세요.

### 4.4 환자의 홈과 전체 일정 확인하기

[소섹션: PDF 77쪽](MedBuddy_User_Guide_ko.pdf#page=77)

<a id="manual_page_78"></a>

#### 1. 환자 선택과 새로고침

이름 옆 화살표로 확인할 환자를 고르고 새로고침하세요. 예시의 환자 TEST는 오늘 전체 0/5이며 아침 두 건이 미복용입니다. 첫 환자의 이전 화살표는 회색입니다. 완료·미복용은 앱의 기록으로, 실제 복용을 자동 확인한 결과는 아닙니다.

1. 환자 이름과 전환 화살표
2. 선택한 환자 기록 새로고침
3. 오늘 전체 진행률 0/5

#### 2. 점심으로 넘기기

진행률 아래의 시간대 요약을 왼쪽으로 미세요. 점심·미복용과 테스트 점심약이 표시되고, 등록된 세 시간대 중 두 번째 점이 채워집니다. 오늘 전체 진행률은 0/5로 유지됩니다.

<a id="manual_page_79"></a>

[화면 예시: PDF 79쪽](MedBuddy_User_Guide_ko.pdf#page=79)

#### 3. 저녁 확인

점심 요약을 다시 왼쪽으로 미세요. 저녁·미복용과 테스트 저녁약 외 1개가 표시되고, 세 점 중 세 번째 점이 채워집니다. 예시의 저녁 두 건은 미복용이며 오늘 전체 진행률은 0/5입니다.

#### 4. 마지막 등록 시간대 확인

저녁에서 한 번 더 왼쪽으로 밀어도 마지막 시간대인 저녁에 머무릅니다. 이 예시의 홈에는 약이 등록된 아침·점심·저녁만 표시되어 점이 세 개이며, 약이 없는 취침 전은 나타나지 않습니다. 기록이 예상과 다르면 환자 이름과 전체 일정을 함께 확인하세요.

#### 5. 환자의 전체 일정 열기

원하는 환자가 선택되었는지 이름을 확인한 뒤 홈 카드의 ‘일정 보기’를 누르세요. 선택한 환자의 오늘 일정이 열립니다. 보호자는 읽기 전용 일정에서 환자의 복용 완료를 대신 체크하거나 취소할 수 없습니다.

#### 6. 읽기 전용 일정 확인

위쪽 환자 이름과 진행률을 확인하고 아침·점심·저녁·취침 전 약 목록을 살펴보세요. 예시의 환자 TEST는 0/5이며, 카드의 알림 문구는 보호자가 받는 알림을 뜻합니다.

1. 일정을 조회할 환자
2. 오늘 완료 기록 0/5
3. 아침 약·보호자 알림

<a id="manual_page_80"></a>

[화면 예시: PDF 80쪽](MedBuddy_User_Guide_ko.pdf#page=80)

#### 7. 현재 기록 다시 확인

환자에게 새 소식을 받았다면 상세 일정의 업데이트 문구 오른쪽 새로고침을 누르세요. 조회 후 업데이트 문구와 진행률을 확인하되, 바뀐 기록이 없으면 수치는 그대로입니다.

#### 8. 취침 전까지 내려 보기

약 목록을 위로 밀어 아래 시간대의 기록도 살펴보세요. 예시의 환자 TEST는 취침 전에 등록된 약이 없습니다.

#### 9. 약 이름과 복용법

환자 일정의 약 항목을 눌러 상세를 열고 이름·효능과 1회 복용량·횟수·기간을 읽으세요. 사진은 앞 일정과 다른 ‘환자2 테스트 아침약’ 예시입니다. 화면만 보고 처방된 복용법을 바꾸지 마세요.

1. 환자2 테스트 아침약
2. 복용량·횟수·기간

#### 10. 안내와 주의사항

환자 일정의 약 항목을 눌러 연 상세 화면을 위로 밀어 안내와 주의사항을 읽으세요. 자료가 없는 항목은 ‘정보 없음’으로 표시됩니다. 사진은 실제 복용 지시가 아닌 테스트 자료입니다.

1. 테스트용 복용 가이드
2. 테스트용 주의사항
3. 가이드 정보 없음

### 4.5 가족의 표시 이름 바꾸기

#### 6. 보낸 내용 확인

보낸 메시지에서 약 이름과 ‘지금은 못 먹어요’를 확인하세요. 이 응답만으로 복용 완료가 기록되거나 기존 복용 기록이 취소되지는 않습니다.

1. 함께 보낸 약 2개
2. 복용하기 어려운 상황 전달

#### 7. 불편함 응답 찾기

약을 선택하고 빠른 답장을 옆으로 넘겨 ‘먹고 나서 불편해요’를 누르세요. 불편함 메시지와 안전 안내를 보내며 복용 완료 기록은 바뀌지 않습니다.

#### 8. 메시지와 안전 안내 확인

안전 안내를 읽고 병원을 찾아보려면 메시지 아래 ‘병원 찾기’를 누르세요. 검색은 진료 예약이나 긴급 연락을 대신하지 않습니다.

### 5.6 메시지 삭제하고 대화 정리하기

#### 1. 지울 메시지 선택

채팅 위쪽 휴지통을 눌러 선택 모드를 열고 지울 메시지 왼쪽 체크상자를 누르세요. 사진은 아직 0개 선택인 상태이며, 메시지를 고르기 전에는 삭제 아이콘이 비활성입니다.

1. 선택한 메시지 0개
2. 지울 메시지 선택 칸

#### 2. 선택 후 삭제 열기

체크한 메시지와 위쪽 선택 개수를 확인하고 휴지통을 누르세요. 곧바로 지워지지 않고 삭제 범위를 고르는 확인 창이 열립니다.

1. 선택한 메시지 1개
2. 현재 선택한 메시지
3. 삭제 범위 선택 창

#### 3. 삭제 범위 확인

내가 보낸 지 24시간 이내인 메시지의 ‘모두에게서 삭제’를 선택하고 ‘메시지 삭제’를 누르면 양쪽 대화에서 본문이 삭제됩니다. 기본값은 ‘나에게서만 삭제’이며, 그만두려면 ‘취소’를 누르세요.

1. 양쪽 대화의 본문 삭제
2. 선택한 삭제 방식 적용

#### 4. 삭제 안내 확인

원래 본문 대신 ‘삭제된 메시지입니다.’가 남는지 확인하세요. 이미 전달된 알림 미리보기는 회수되지 않으며, 연결된 약과 복용 기록은 지워지지 않습니다.

1. 선택된 삭제 안내 항목

1. 내 대화에서만 삭제
2. 선택 항목 숨기기 실행

#### 7. 내 화면의 삭제 결과

지운 안내가 사라지고 다른 대화는 남아 있는지 확인하세요. 예시에서는 ‘삭제된 메시지입니다.’ 안내만 사라지고 아침 복약 확인 요청은 그대로 남아 있습니다.

#### 8. 대화 목록으로 돌아가기

삭제한 뒤 남은 대화를 확인하고 왼쪽 위 뒤로가기를 누르세요. 채팅 목록으로 돌아가 상대 이름·최근 메시지·안 읽은 개수를 다시 확인할 수 있습니다.

### 5.7 보호자 복약 알림 설정하기

[소섹션: PDF 105쪽](MedBuddy_User_Guide_ko.pdf#page=105)

<a id="manual_page_106"></a>

[화면 예시: PDF 106쪽](MedBuddy_User_Guide_ko.pdf#page=106)

#### 1. 시간대의 종 아이콘

‘환경설정 → 복약 및 알림’에서 보호자 알림을 켜고 저장한 뒤 휴대전화 알림도 허용하세요. 환자 상세 일정에서 원하는 시간대의 종을 누르면 보호자 알림 설정 창이 열립니다. 카드의 알림은 보호자용입니다.

#### 2. 알림 방식 선택

‘끄기’, ‘복용 확인 즉시 알림’, ‘정해진 시각까지 미복용 시 알림’ 중 하나를 고르세요. 즉시 알림은 해당 시간대의 모든 약이 완료로 기록될 때 알리는 방식이며 실제 복용을 검증하지 않습니다.

#### 3. 확인 시각 열기

‘정해진 시각까지 미복용 시 알림’을 고르고 ‘확인 시각’을 누르면 시·분 선택 창이 열립니다. 이 시각은 보호자의 확인 기준이며 환자의 복약 알림 시각과 다르게 정할 수 있습니다.

1. 미완료 기록 확인 알림
2. 보호자의 확인 기준 시각

#### 4. 시각 확인

시와 분을 맞추고 오른쪽 위 체크 아이콘을 누르면 선택한 시각으로 원래 설정 창에 돌아갑니다. 아직 저장된 것은 아니므로 마지막에 ‘저장하기’를 눌러야 합니다.

1. 확인할 시·분 선택
2. 시각 선택 후 설정 창으로

<a id="manual_page_107"></a>

[화면 예시: PDF 107쪽](MedBuddy_User_Guide_ko.pdf#page=107)

#### 5. 저장하기

원래 설정 창에서 시간대·알림 방식·확인 시각을 살펴보고 ‘저장하기’를 누르세요. 저장되면 창이 닫히고 환자 일정으로 돌아갑니다. 환자의 복약 알림 시각은 바뀌지 않습니다.

1. 저장할 알림 확인 시각
2. 보호자 알림 설정 저장

#### 6. 저장 안내 확인

아래쪽 저장 안내와 시간대 카드의 알림 표시를 확인하세요. 설정에 따라 ‘미복용 알림’과 시각, ‘복용 완료 시 알림’, ‘보호자 알림 꺼짐’으로 표시됩니다. 다른 시간대는 따로 설정하세요.

1. 미복용 알림 21:00
2. 아침 알림 설정 저장 완료

#### 7. 10분 후 다시 알림

보호자 계정에서 Android 알림 목록의 MedBuddy 미복용 알림을 펼치세요. 아래 두 버튼이 있는 알림에서 ‘10분 후 다시 알림’을 누르면 앱으로 돌아가 재알림을 요청하며 복용 기록은 바꾸지 않습니다.

#### 8. 재알림 접수 확인

화면 아래 ‘재알림을 접수했습니다. 10분 후 미복약 여부를 다시 확인합니다.’를 확인하세요. 요청 접수 안내일 뿐이며, 그 사이 완료 기록·연결·알림 설정이 바뀌면 재알림이 없을 수 있습니다.

<a id="manual_page_108"></a>

[화면 예시: PDF 108쪽](MedBuddy_User_Guide_ko.pdf#page=108)

#### 9. 채팅으로 알림

Android의 미복용 알림을 펼쳐 ‘채팅으로 알림’을 누르면 작성 창 없이 환자의 대화에 확인 요청을 보냅니다. ‘10분 후 다시 알림’과는 별개 동작이며 환자의 복용 완료 기록은 바뀌지 않습니다.

#### 10. 전송 안내 확인

화면 아래 ‘복약 일정 확인 요청을 보냈습니다.’가 나타나는지 확인하세요. 전송 안내만으로 환자가 요청을 읽었거나 약을 복용했다고 판단하지 마세요.

#### 11. 환자 대화에서 요청 확인

환자 계정에서 보호자와의 대화를 열어 새 요청을 확인하세요. 아침 일정 카드와 ‘아침 복약 일정을 확인해 주세요.’ 요청이 표시됩니다. 요청만으로 실제 복용을 확인한 것은 아닙니다.

### 5.8 알림함 확인하고 정리하기

[소섹션: PDF 109쪽](MedBuddy_User_Guide_ko.pdf#page=109)

<a id="manual_page_110"></a>

[화면 예시: PDF 110쪽](MedBuddy_User_Guide_ko.pdf#page=110)

#### 1. 알림함 열기

홈 오른쪽 위 종 아이콘을 누르면 이 기기에 기록된 알림함이 열립니다. 안 읽은 알림이 있으면 아이콘 옆에 개수가 표시됩니다.

#### 2. 내용과 시각 읽기

목록에서 환자 이름·알림 내용·날짜와 시각을 읽으세요. 아직 열지 않은 알림은 ‘안 읽음’으로 구분됩니다.

#### 3. 알림 내용 누르기

채팅 알림 본문을 누르면 해당 대화의 최신 메시지가 보입니다. 내 복약 알림은 해당 시간대 일정, 보호자 복약 알림은 해당 환자 일정으로 이동합니다.

#### 4. 최신 메시지와 읽은 위치

대화가 열리면 최신 메시지부터 확인하세요. ‘여기까지 읽음’ 아래는 입장 전 안 읽은 대화입니다. 보낸 말풍선 왼쪽 아래 ‘1’은 상대가 아직 읽지 않았다는 뜻입니다.

1. 이번 진입 전 읽은 경계
2. 처음 열면 최신 메시지로
3. 상대가 아직 읽지 않은 보낸 메시지

<a id="manual_page_111"></a>

[화면 예시: PDF 111쪽](MedBuddy_User_Guide_ko.pdf#page=111)

#### 5. 모두 읽음 누르기

오른쪽 위 겹친 체크 모양 ‘모두 읽음’을 누르면 현재 알림 목록을 한 번에 읽음 처리합니다. 알림 자체가 지워지는 것은 아닙니다.

#### 6. 읽음 처리 결과

목록과 위쪽 아이콘을 살펴보세요. ‘안 읽음’ 표시가 사라지고 ‘모두 읽음’ 아이콘이 회색으로 바뀌면 읽음 처리가 반영된 상태입니다.

1. 회색으로 바뀐 모두 읽음
2. 안 읽음 표시만 제거

#### 7. 더보기에서 삭제

지울 알림 오른쪽 점 세 개를 누른 뒤 ‘삭제’를 누르면 삭제 확인 창이 열립니다. 이 단계에서는 아직 알림이 지워지지 않습니다.

#### 8. 삭제 범위 확인

확인 창의 ‘채팅 내용과 복약 기록은 삭제되지 않아요.’를 읽으세요. 이 기능은 해당 알림만 지우며, 지우지 않으려면 ‘취소’를 눌러 목록에 남길 수 있습니다.

1. 채팅·복약 기록 유지
2. 알림을 남기고 취소
3. 알림 한 건 삭제 실행

<a id="manual_page_112"></a>

#### 9. 삭제 확정

지울 알림의 내용과 날짜를 확인하고 확인 창에서 ‘삭제’를 누르면 해당 알림 한 건이 지워집니다. 되살리는 버튼은 없으며 관련 채팅과 복약 기록은 그대로 유지됩니다.

#### 10. 목록에서 결과 확인

지운 항목이 목록에서 사라졌는지 확인하세요. 예시에서는 00:13 알림이 없어지고 00:09 알림이 맨 위에 표시됩니다.

#### 11. 선택 모드 확인

#### 13. 확인창에서 취소

알림 선택 후 아래 삭제 버튼을 누르면 확인 창이 열립니다. 지우지 않으려면 ‘취소’를 누르세요. 알림은 지워지지 않고 이전에 선택한 상태로 돌아갑니다.

### 6.1 내 복약 위젯 추가하고 사용하기

#### 2. 홈 화면 추가 확정

추가 창에서 ‘홈 화면에 추가’를 누르세요. 사진의 ‘Add to home screen’이 추가 버튼이며 ‘Cancel’은 취소합니다. 미리보기의 내용 대신 실제 일정은 추가한 뒤 표시됩니다.

#### 3. 추가된 복약 위젯

홈 화면에 추가된 위젯에서 날짜·진행률과 현재 시간대의 약·기록 버튼을 확인하세요. 예시의 진행률은 0/5입니다. 공간이 부족해 추가하지 못했다면 홈 화면에 빈자리를 먼저 확보하세요.

#### 4. 시간대 선택

위젯의 화살표나 점을 누르면 선택된 점·시간대와 해당 약의 미복용·완료 기록이 표시됩니다. 사진은 아침 두 건을 완료로 기록한 2/5 예시이며, 점을 누르는 동작은 복용 기록을 바꾸지 않습니다.

<a id="manual_page_122"></a>

[화면 예시: PDF 122쪽](MedBuddy_User_Guide_ko.pdf#page=122)

#### 5. 다른 시간대의 약 확인

선택한 시간대의 약과 기록 상태를 확인하세요. 예시의 점심은 미복용으로 표시되며 전체 진행률은 2/5입니다. 약이 있는 시간대만 표시되고 작은 위젯은 목록 일부가 생략될 수 있습니다.

#### 6. 시간대 전체 기록

현재 시간대의 약을 실제로 모두 복용했다면 ‘복용했어요’를 누르세요. 예시는 아침 두 건을 기기에 기록해 2/5가 된 뒤 서버로 전송합니다. 다음 미완료 시간대인 점심으로 바뀌므로 이름을 다시 확인하세요.

<a id="manual_page_123"></a>

[화면 예시: PDF 123쪽](MedBuddy_User_Guide_ko.pdf#page=123)

#### 7. 같은 아침 기록 취소

잘못 남긴 아침 기록을 취소하려면 아침 시간대로 돌아와 ‘복용 취소’를 누르세요. 완료한 시간대는 버튼이 ‘복용 취소’로 바뀌며, 사진은 취소 전 아침 두 건이 완료로 기록된 2/5 상태입니다.

#### 8. 취소 기록과 전송 상태

취소한 뒤 미복용 표시와 줄어든 진행률을 확인하세요. 예시는 아침 두 건의 기록을 취소해 0/5가 되었으며, 기기에는 저장됐지만 서버 전송은 1건 대기 중입니다.

1. 취소 후 진행률 0/5
2. 다시 미복용으로 표시
3. 기기 저장·전송 1건 대기

<a id="manual_page_124"></a>

[화면 예시: PDF 124쪽](MedBuddy_User_Guide_ko.pdf#page=124)

#### 9. 기기에 남은 대기 기록

‘기기 저장 완료 · 전송 대기 1건’이 보이면 아직 서버에 보내지 못한 기록이 있다는 뜻입니다. 같은 기록을 다시 입력하지 말고 인터넷 연결을 확인하세요.

#### 10. 서버 저장 완료

연결이 돌아오면 앱에서 전송 대기를 확인하고 위젯으로 돌아오세요. ‘서버 저장 완료’는 이 기기에 전송 대기가 없다는 표시이며 취소 후 0/5는 유지됩니다. 보호자 화면은 별도로 새로고침하세요.

#### 2. 찾을 곳 선택

‘근처 병원’은 병원·의원의 진료 정보를, ‘근처 약국’은 약국의 영업 정보를 찾습니다. 필요한 항목을 누르세요.

1. 병원·의원 검색
2. 약국 검색

#### 3. 병원 지도 확인

병원 지도에서 위치와 이름을 확인하세요. 처음 위치 권한을 물으면 사용 중 허용하세요. 위치를 확인하지 못했다는 안내가 있으면 검색 기준 지역부터 확인하세요.

#### 4. 약국 지도 확인

약국도 같은 방식으로 지도와 목록을 이용합니다. 지도를 옮기면 현재 보는 지역을 다시 검색할 수 있습니다. 검색 결과가 주변 모든 기관을 뜻하지는 않습니다.

### 8.2 진료과목으로 병원 찾기

#### 1. 진료과목 열기

병원 화면 왼쪽의 진료과목 버튼을 누르세요. 처음에는 ‘전체’로 표시됩니다. 오른쪽의 ‘조회 조건’과는 별도 선택입니다.

#### 2. 과목 목록 확인

목록에서 필요한 진료과목을 찾으세요. ‘전체’를 선택하면 과목 제한 없이 병원을 조회합니다.

#### 4. 과목 선택 후 결과 확인

원하는 과목 이름을 누르면 창이 닫히고 해당 과목으로 다시 조회됩니다. 선택한 과목은 왼쪽 버튼에 표시됩니다.

#### 1. 조회 조건 열기

오른쪽 ‘조회 조건’을 누르세요. 날짜와 진료 상태를 한 창에서 선택하므로 지도 위에 날짜 줄이 따로 늘어나지 않습니다.

#### 2. 날짜와 진료 상태 구분

위쪽은 조회할 날짜, 아래쪽은 진료 상태입니다. ‘현재 진료 중’은 현재 기준입니다. 다른 날짜를 보려면 다른 진료 상태를 먼저 고르세요.

1. 조회할 날짜
2. 진료 상태 선택

#### 3. 저녁 진료 선택

‘저녁 진료’는 선택한 날짜에 오후 6시 이후 진료시간이 있는 병원을 찾습니다. 응급실이나 대학병원만 뜻하는 조건은 아닙니다.

#### 4. 주말·공휴일 또는 전체 선택

주말·공휴일 진료를 찾으면 방문할 주말이나 공휴일 날짜도 고르세요. 진료시간 조건 없이 찾으려면 ‘전체 병원’을 선택하세요.

1. 방문 날짜도 확인
2. 시간 조건 없이 조회

#### 5. 날짜 선택 열기

날짜 버튼을 누르면 달력이 열립니다. 날짜는 연·월·일만 표시됩니다. ‘현재 진료 중’에서는 별도 날짜를 선택할 수 없습니다.

#### 6. 방문일 고르기

달력에서 방문할 날짜를 고른 뒤 확인 버튼을 누르세요. 달력이 닫히면 조회 조건 창으로 돌아옵니다. 아직 검색에는 적용되지 않은 상태입니다.

#### 7. 조건 적용

날짜와 진료 상태를 다시 확인하고 아래 ‘적용’을 누르세요. 지도와 목록이 선택한 조건으로 갱신됩니다.

#### 8. 적용한 조건 다시 확인

결과를 보고 ‘조회 조건’을 다시 열면 현재 적용된 날짜와 진료 상태를 확인할 수 있습니다. 실제 진료 여부는 방문 전에 전화로 확인하세요.

### 10.3 알약 후보가 없거나 분석에 실패했을 때

[소섹션: PDF 212쪽](MedBuddy_User_Guide_ko.pdf#page=212)

<a id="manual_page_213"></a>

[화면 예시: PDF 213쪽](MedBuddy_User_Guide_ko.pdf#page=213)

#### 1. 해당 알약 다시 확인

후보가 없을 때 ‘이 알약 다시 비교’가 보이면 누르세요. 번호가 남은 결과를 확신하기 어렵다면 ‘영역 다시 분석’을 이용하세요. 사진은 재분석 버튼 위치를 보여 주는 참고 화면입니다.

#### 2. 사진 재분석 또는 변경

전체 분석 실패 시 ‘이 사진 다시 분석’이 보이면 누르세요. 사진이 흐리거나 읽히지 않으면 ‘사진 변경’으로 바꾸세요. 사진은 변경 버튼 위치를 보여 줍니다.

### 10.4 알림이 오지 않을 때

[소섹션: PDF 214쪽](MedBuddy_User_Guide_ko.pdf#page=214)

<a id="manual_page_215"></a>

[화면 예시: PDF 215쪽](MedBuddy_User_Guide_ko.pdf#page=215)

#### 1. 받을 알림 켜기

일정이 보여도 알림 준비가 끝난 것은 아닙니다. 환경설정의 ‘복약 및 알림’에서 내 복약·보호자·채팅 알림 중 필요한 항목을 각각 켜고 저장하세요. 일정 화면의 시간대별 알림도 켜졌는지 확인하세요.

1. 내 복약 알림 수신
2. 보호자 알림 수신
3. 채팅 알림 수신

#### 2. 휴대전화 권한 확인

‘휴대폰 알림 설정’에서 MedBuddy 알림이 허용됐는지 확인하세요. 항목 이름·위치는 기기마다 다르며 잠금 화면·방해 금지·배터리 제한도 알림 표시에 영향을 줄 수 있습니다.

### 10.5 기록이나 위젯이 늦게 바뀔 때

[소섹션: PDF 216쪽](MedBuddy_User_Guide_ko.pdf#page=216)

<a id="manual_page_217"></a>

[화면 예시: PDF 217쪽](MedBuddy_User_Guide_ko.pdf#page=217)

#### 1. 대기 기록 확인

완료를 반복해 누르지 말고 전송 대기 안내를 눌러 기기에만 저장된 기록을 확인하세요. 인터넷 연결을 복구한 뒤 오른쪽 ‘다시 전송’을 누르세요. 같은 기록을 다시 입력할 필요는 없습니다.

1. 기기에 저장된 대기 기록
2. 연결 복구 후 다시 전송

#### 2. 보호자 위젯 새로고침

보호자는 위젯의 환자 이름부터 확인하고 새로고침을 누르세요. 변화가 없으면 ‘일정 열기’로 앱을 열어 같은 환자의 일정을 비교하세요. 위젯에는 환자가 기록한 복약 상태가 표시됩니다.

1. 같은 환자인지 확인
2. 환자 기록 다시 조회
3. 환자가 기록한 복약 상태

### 10.6 병원·약국 결과를 다시 확인할 때

[소섹션: PDF 218쪽](MedBuddy_User_Guide_ko.pdf#page=218)

<a id="manual_page_219"></a>

[화면 예시: PDF 219쪽](MedBuddy_User_Guide_ko.pdf#page=219)

#### 1. 약국 결과가 없을 때

결과가 없어도 주변 약국이 모두 문을 닫았다는 뜻은 아닙니다. ‘조회 조건’에서 날짜·영업 상태를 확인하고 바꾼 뒤 ‘적용’을 누르세요.

#### 2. 병원 결과가 없을 때

진료과목을 ‘전체’로 바꾸거나 날짜·진료 상태를 확인하세요. 주말·공휴일 조건이면 실제 방문할 주말·공휴일 날짜를 고른 뒤 적용하세요.

1. 진료과목 변경
2. 날짜·진료 상태 확인

#### 3. 다시 조회하기

새로고침으로 최신 정보를 다시 요청하세요. 네트워크 오류가 표시되면 연결을 확인하고 다시 시도하세요. 표시된 일부 결과가 주변 모든 병원을 뜻하지는 않습니다.

#### 4. 운영 정보가 불확실할 때

‘전체 병원’ 또는 ‘전체 약국’에서 주소·연락처를 확인하고 전화로 실제 진료·영업 여부를 확인하세요. 시간 정보가 없으면 열려 있다고 단정하지 마세요.
