앱 버전: 0.2.0 · 문서 기준일: 2026-09-27

**안내:** 설명서의 약과 용량은 조작 예시입니다. 실제 복용은 처방과 복약지도에 따르세요. 완료 표시는 사용자가 남긴 기록입니다.

## 1 시작하기

### 1.1 처음 사용할 언어 선택하기

[화면 예시: PDF 5쪽](MedBuddy_User_Guide_ko.pdf#page=5)

#### 1. 언어 선택 열기

처음 실행하면 한국어로 시작합니다. 로그인 전에 언어를 바꾸려면 오른쪽 위 지구본을 눌러 ‘언어 / Language’ 선택 창을 여세요.

#### 2. 한국어 선택

‘한국어’를 선택하면 창이 닫히고 로그인·가입·이메일 인증 안내가 한국어로 표시됩니다. 선택한 언어는 기기에 저장됩니다.

**참고**

영어를 쓰려면 ‘English’를 선택하세요. 선택한 언어는 기기에 저장됩니다. 선택하지 않고 창만 닫으면 이전 언어를 유지합니다.

### 1.2 이메일로 로그인하기

[화면 예시: PDF 6쪽](MedBuddy_User_Guide_ko.pdf#page=6)

#### 1. 이메일 로그인

인터넷에 연결한 뒤 가입한 이메일과 비밀번호를 입력하고 ‘로그인’을 누르세요. 이메일 인증을 마친 계정은 홈으로 이동합니다.

1. 이메일: 가입한 주소 입력
2. 비밀번호: 계정 암호 입력
3. 로그인: 입력한 계정으로

#### 2. 로그인 계정 확인

홈이 열리면 하단 ‘내 정보’를 눌러 로그인한 계정을 확인하세요. 이메일 인증 화면이 나오면 인증부터 마치세요.

**참고**

언어를 바꾸려면 오른쪽 위 지구본을 누르세요. 로그인 오류는 입력을 고쳐 다시 시도하고, 연결 오류는 ‘보안 세션 다시 연결’을 누르세요. 비밀번호가 기억나지 않으면 ‘비밀번호 찾기’를 이용합니다.

### 1.3 가입하고 이메일 인증하기

[화면 예시: PDF 7~8쪽](MedBuddy_User_Guide_ko.pdf#page=7)

#### 1. 회원가입 열기

‘MedBuddy가 처음이신가요? 회원가입’을 눌러 ‘안전한 계정 만들기’ 화면을 여세요. 환자와 보호자 모두 같은 방법으로 가입하며, 가입 중 역할을 고르는 화면은 없습니다.

#### 2. 이메일과 비밀번호 입력

직접 확인할 수 있는 이메일과 6자 이상 비밀번호를 입력하고 ‘회원가입’을 누르세요. 입력 오류가 나오면 해당 칸의 안내에 따라 고치세요.

1. 인증 메일을 받을 주소
2. 비밀번호: 6자 이상
3. 회원가입: 입력한 정보로 가입

#### 3. 인증 메일 확인

‘이메일을 인증해 주세요’가 나오면 표시된 주소의 메일함을 열어 인증 링크를 누르세요. 메일이 없으면 주소와 스팸함을 확인한 뒤 다시 보내세요.

1. 인증 안내: 메일 링크 이용
2. 수신 주소: 해당 메일함 열기
3. 메일이 없으면 다시 보내기

#### 4. 메일 인증 후 앱으로 돌아오기

메일의 인증 링크를 누른 뒤 MedBuddy로 돌아오세요. 앱이 인증 상태를 자동으로 확인하고, 인증이 완료되면 홈으로 이동합니다.

#### 5. 인증 상태 다시 확인

인증 화면이 남아 있으면 ‘인증 상태 다시 확인’을 누르세요. ‘아직 인증되지 않았어요.’가 나오면 메일의 인증 링크를 누른 뒤 앱으로 돌아오세요.

1. 미인증: 메일 링크 먼저 확인
2. 인증 후 상태 다시 확인

#### 6. 가입한 계정으로 시작

인증 후 홈이 열리면 하단 ‘내 정보’에서 가입한 계정인지 확인하고 앱을 이용하세요.

**참고**

비밀번호는 눈 모양 버튼으로 확인한 뒤 다시 가려 주세요. 이미 가입한 이메일은 로그인이나 비밀번호 찾기를 이용하세요. 환자와 보호자의 가입 절차는 같습니다. 메일이 없으면 주소와 스팸함을 확인한 뒤 인증 메일을 다시 보내세요. 다른 계정으로 로그인하려면 왼쪽 위 뒤로가기를 누르세요. 계정은 삭제되지 않습니다. 메일의 링크로 인증한 뒤 앱에 돌아오면 자동으로 로그인합니다. 자동으로 넘어가지 않을 때만 ‘인증 상태 다시 확인’을 누르세요. 사진은 인증을 마친 예시 계정의 홈입니다. 인증 화면이 계속 보이면 메일 링크를 확인한 뒤 앱으로 돌아오세요.

### 1.4 다른 방법으로 시작하기

[화면 예시: PDF 9~10쪽](MedBuddy_User_Guide_ko.pdf#page=9)

#### 1. Google 로그인 시작

인터넷 연결을 확인하고 로그인 화면의 ‘Google로 계속하기’를 누르세요. MedBuddy의 이메일 로그인 칸에는 Google 비밀번호를 입력하지 마세요.

#### 2. Google 계정 선택과 인증

Google 안내가 나오면 사용할 계정을 확인하고 인증을 진행하세요. 취소하면 로그인되지 않습니다. 오류가 나면 연결을 확인하고 ‘Google로 계속하기’에서 다시 시도하세요.

#### 3. 게스트 시작

로그인 화면에서 ‘회원가입 없이 계속하기’를 눌러 게스트 이용 안내를 여세요.

#### 4. 게스트 이용 여부 선택

데이터 보관 제한을 읽고 ‘계속’을 누르면 게스트로 홈에 들어갑니다. 시작하지 않으려면 ‘취소’를 누르세요. 게스트 로그아웃 시 데이터는 영구 삭제됩니다.

1. 게스트: 임시 계정 이용
2. 기기 변경·삭제 전 보관 제한
3. 취소: 게스트 시작 안 함
4. 계속: 게스트로 홈 열기

#### 5. 게스트 계정 확인

하단 ‘내 정보’를 눌러 ‘게스트 계정’ 표시를 확인하세요. 데이터를 보존하며 정식 계정으로 전환하는 버튼은 없습니다.

**참고**

사진은 MedBuddy의 로그인 진입 화면입니다. 이후 안내는 기기와 계정 상태에 따라 다를 수 있습니다. 게스트 로그아웃은 데이터를 영구 삭제합니다. 기기를 바꾸거나 앱 데이터를 지우기 전에 주의하세요. 계정 메뉴에 데이터를 보존하며 정식 계정으로 바꾸는 버튼은 없습니다.

### 1.5 비밀번호 다시 설정하기

[화면 예시: PDF 11쪽](MedBuddy_User_Guide_ko.pdf#page=11)

#### 1. 재설정 메일 요청

이메일·비밀번호로 가입했고 해당 메일함을 열 수 있는 계정에서 사용하세요. 가입한 이메일을 입력하고 ‘비밀번호 찾기’를 누르세요. 현재 비밀번호는 필요 없습니다.

1. 이메일: 재설정할 계정 주소
2. 비밀번호 재설정 메일 요청

#### 2. 메일에서 비밀번호 변경

‘비밀번호 재설정 메일을 보냈습니다.’가 나오면 받은 메일에서 새 비밀번호를 정하고 MedBuddy로 돌아오세요. 복약 자료와 설정, Google 비밀번호는 바뀌지 않습니다.

#### 3. 새 비밀번호로 로그인

이메일·비밀번호로 가입한 계정의 메일함에서 재설정을 마친 뒤 새 비밀번호로 로그인하세요. 인증이 완료되면 홈이 열립니다.

**참고**

‘먼저 이메일 주소를 입력해 주세요.’가 나오면 이메일부터 적으세요. 메일이 없으면 주소·스팸함·인터넷 연결을 확인하세요. 비밀번호 재설정은 복약 자료나 설정을 초기화하지 않으며 Google 계정 비밀번호도 바꾸지 않습니다. 비밀번호 재설정 사진은 앱의 메일 요청 위치를 보여 주며, 메일 내용이나 발송 완료 화면은 아닙니다.

### 1.6 홈과 주요 메뉴 익히기

[화면 예시: PDF 12~13쪽](MedBuddy_User_Guide_ko.pdf#page=12)

#### 1. 오늘의 기록 확인

홈 위쪽에서 오늘의 복약 진행률과 선택한 시간대의 약을 확인하세요. 예시는 오늘 전체 5건 중 완료 0건이며, 아침 약은 미복용입니다. 약이 등록된 시간대만 표시됩니다.

1. 오늘 전체 진행률 0/5
2. 선택한 아침의 미복용 상태

#### 2. 네 가지 바로가기

홈의 네 가지 바로가기 중 필요한 기능을 누르세요. 약 등록·식별, 건강 관리 추천, 근처 운영 약국, 환경설정을 열 수 있습니다.

1. 약 등록·식별
2. 건강 관리 추천
3. 근처 운영 약국
4. 환경설정

#### 3. 일정에서 오늘 기록하기

하단 ‘일정’을 눌러 내 계정의 오늘 약을 시간대별로 확인하고 복용 기록을 남기세요.

#### 4. 복약함에서 저장한 약 찾기

하단 ‘복약함’을 눌러 저장된 약을 검색하고 약 이름·복용 기간·상세정보를 확인하거나 정리하세요.

#### 5. 채팅에서 가족과 대화하기

하단 ‘채팅’을 눌러 연결된 가족과 대화하세요. 환자·보호자 연결이 있어야 채팅 탭이 표시되며, 없으면 ‘내 정보’에서 먼저 연결하세요.

#### 6. 내 정보에서 계정과 연결 관리

하단 ‘내 정보’를 눌러 계정과 환자·보호자 연결을 확인하세요. 연결 전 하단 메뉴는 4개이며, 연결 후에는 복약함과 내 정보 사이에 채팅이 추가되어 5개가 됩니다.

#### 7. 계정과 가족 연결

‘내 정보’에서 로그인한 계정을 확인하고 ‘환자/보호자 연동’을 눌러 가족 연결 화면을 여세요. 게스트로 이용 중이면 ‘게스트 계정’으로 표시됩니다.

1. 복약 정보가 연결된 계정
2. 가족 연결과 환자 복약 상태

#### 8. 환경설정 메뉴 선택

‘내 정보’로 돌아와 ‘환경설정’을 누른 뒤 ‘복약 및 알림’, ‘화면 및 음성’, ‘계정’ 중 필요한 메뉴를 여세요.

1. 알림 사용·기본 복약 시간
2. 글씨 크기·음성 속도·언어
3. 로그인·보안·계정 데이터

**참고**

홈에 내 일정과 환자 일정 중 무엇을 띄울지는 환경설정에서 바꿉니다. 환자·보호자는 연결 관계에 따른 구분이며, 보호자도 본인 약을 등록해 관리할 수 있습니다. 요약에는 약이 등록된 시간대만 표시됩니다. 점은 현재 시간대의 위치를 보여 주며, 좌우로 밀어 다른 시간대를 봅니다. 채팅이 없으면 내 정보에서 환자·보호자 연동을 먼저 진행하세요. 다른 화면에서 왼쪽 위 뒤로가기 화살표를 누르면 이전 화면으로 돌아갑니다. 설정값을 바꾼 경우에는 저장 여부를 묻는 창이 나올 수 있습니다. ‘내 정보’에는 내 이메일이나 이름을 직접 고치는 입력칸이 없습니다. 가족의 ‘표시 이름’은 내 화면에서 상대를 알아보기 위한 별칭입니다. 이전 화면으로 돌아갈 때는 위쪽 뒤로가기 화살표를 누르세요.

## 2 약 등록과 식별

### 2.1 처방전 사진 가져오기

[화면 예시: PDF 14쪽](MedBuddy_User_Guide_ko.pdf#page=14)

#### 1. 처방전 분석 선택

홈의 ‘약 등록·식별’에서 ‘처방전 분석’을 눌러 처방전 사진을 가져올 방법을 선택하세요.

#### 2. 사진 출처 선택

새 처방전을 찍으려면 ‘카메라로 촬영’, 저장된 사진을 가져오려면 ‘갤러리에서 선택’을 누르세요. 사진 선택만으로 약이 저장되지는 않습니다.

1. 카메라: 새 처방전 촬영
2. 갤러리: 저장된 사진 선택

#### 3. 갤러리 열기

사진 출처에서 ‘갤러리에서 선택’을 눌러 기기의 사진 선택기를 여세요. 선택기의 이름과 배치는 기기마다 다를 수 있습니다.

#### 4. 처방전 사진 선택

사진 선택기에서 사용할 처방전 사진 한 장을 고르세요. 화면의 Downloads 폴더에 있는 사진은 사용법을 보여 주는 가상 처방전입니다.

**참고**

사진을 고르는 것만으로 약이 저장되지는 않습니다. 사진 선택기의 이름과 배치는 기기마다 다를 수 있습니다.

### 2.2 인식한 내용을 확인하고 수정하기

[화면 예시: PDF 15~18쪽](MedBuddy_User_Guide_ko.pdf#page=15)

#### 1. 인식 결과 검토

인식이 끝나면 검토 표의 약 이름과 함량을 원본 처방전과 비교하세요. 화면의 500mg 제품명도 정확히 인식됐는지 확인해야 합니다.

#### 2. 원본 사진 확인

처방 내역 위의 원본 사진에서 약 이름·함량·복용 정보를 확인하세요. 자세히 보려면 사진의 확대 아이콘을 누르세요. 초록색 표시는 인식 영역입니다.

#### 3. 약 이름과 함량 대조

표의 제품명과 함량을 원본과 대조하세요. 예시에는 ‘바이엘아스피린정500밀리그람’이 인식되어 있으며, 이름뿐 아니라 함량도 같아야 합니다.

#### 4. 복용량과 횟수 확인

표를 옆으로 밀어 고칠 칸을 누르고, 수정 창의 ‘1회 투약량’과 ‘1일 횟수’를 각각 처방과 대조하세요. 입력칸이 가리면 키보드를 닫거나 창을 내려 보세요.

#### 5. 기간과 시작일 확인

표를 옆으로 밀어 총 투약일과 복용 시작일을 처방과 대조하세요. 화면의 3일, 2026년 9월 21일은 예시 값입니다.

1. 총 투약일: 전체 복용 일수
2. 복용 시작일: 처방과 대조

#### 6. 약 이름과 날짜 수정

표의 약 이름이나 고칠 값을 눌러 수정 창을 여세요. 이름·함량을 원본대로 고치고 조제일자를 확인하세요. 날짜는 달력 아이콘으로 선택할 수 있습니다.

1. 약 이름: 제품명·함량 수정
2. 달력: 조제일자 선택

#### 7. 달력에서 날짜 선택

달력에서 필요한 월로 이동해 날짜를 고르세요. 위쪽에 표시된 선택 날짜를 확인하고 ‘확인’을 누르세요.

#### 8. 수정 내용 적용

확인한 수정 내용을 검토 표에 반영하려면 오른쪽 아래 ‘적용’을 누르세요. 변경하지 않고 돌아가려면 ‘취소’를 누르세요.

#### 9. 검토 후 분석

약 이름·함량·복용량·횟수·기간·시간대를 처방과 대조한 뒤 ‘검토 후 분석하기’를 누르세요. 검토한 약의 제품 정보 조회와 분석을 시작합니다.

1. 검토 표: 이름·함량 대조
2. 검토 후 제품 조회·분석

#### 10. 누락된 약 추가

원본 처방전에 있지만 표에 없는 약은 사진 아래 ‘누락된 약 추가’를 눌러 이름과 복용 정보를 입력하세요.

#### 11. 복용 정보 입력과 적용

약 이름·날짜·복용량·1일 횟수(1~4회)·기간을 입력하세요. 횟수를 바꾸면 시간대가 자동 선택되므로 처방과 대조하고 ‘적용’을 누르세요. 선택한 시간대에는 체크가 표시됩니다.

1. 누락된 약의 제품명·함량
2. 저녁: 처방과 시간대 대조
3. 적용: 검토 표에 약 추가

#### 12. 추가한 행 검토

기존 행 아래에 추가된 약의 이름과 복용 정보를 확인한 뒤 ‘검토 후 분석하기’를 누르세요. 같은 제품이 여러 행이면 중복인지 다른 일정인지 대조하세요. 추가만으로 저장되지는 않습니다.

#### 13. 분석 결과 열기

분석이 끝나면 추가한 행이 포함됐는지 약 수를 확인하고 ‘결과 확인하기’를 누르세요. 예시에는 2개 일정이 분석되었습니다.

1. 추가한 행을 포함한 약 수
2. 분석된 약과 복용 정보 열기

**참고**

사진 선택기의 이름과 배치는 기기마다 다를 수 있습니다. 사진 속 초록색은 인식 영역입니다. 이름뿐 아니라 함량도 원본과 대조하세요. 실제 복약 시간대도 처방과 맞춰 확인하세요. 입력칸이 가려지면 키보드를 닫거나 창을 내려 보세요. 설명서의 가상 일정은 입력 예시입니다. 실제 처방 내용을 기준으로 수정하세요. 횟수를 바꾸면 그 개수에 맞는 시간대가 자동 선택되고, 시간대를 바꾸면 횟수도 함께 바뀝니다. 같은 횟수를 다시 입력하거나 복용량만 고치면 기존 시간대 선택은 유지됩니다. 이름·함량·복용량·횟수·기간·시간대를 처방과 대조한 뒤 분석하세요. 미리 채워진 값도 원본과 대조하세요. 빈 이름 안내가 나오면 이름을 입력하세요. 1일 횟수가 비어 있거나 1~4회 범위를 벗어나면 안내에 따라 입력을 확인하고 다시 적용하세요. 같은 제품이 여러 행에 있으면 중복 입력인지, 서로 다른 일정인지 원본과 대조하세요. 추가만으로 저장되지는 않습니다.

### 2.3 미확인 약 다시 조회하기

[화면 예시: PDF 19쪽](MedBuddy_User_Guide_ko.pdf#page=19)

#### 1. 미확인 약 이름 점검

‘검토 필요’로 표시된 행의 약 이름과 함량을 원본과 대조하세요. 예시에는 다시 확인할 약 3개가 표시됩니다.

#### 2. 미확인 약 다시 조회

잘못된 이름을 눌러 고친 뒤 화면 맨 아래 ‘미확인 약 다시 조회’를 누르세요. 다시 조회해도 확인되지 않으면 이름을 재검토하세요.

#### 3. 제외할 약 확인

‘확인된 약만으로 계속’을 누른 뒤 제외될 약의 수를 확인하세요. 미확인 약은 분석 결과와 일정에 포함되지 않습니다. 이름을 고치려면 ‘취소’를 누르세요.

1. 미확인 3개: 결과·일정 제외
2. 취소: 약 이름 수정으로

#### 4. 제외하고 계속

필요한 약을 놓치지 않았고 제외해도 되는지 확인한 경우에만 ‘계속’을 누르세요. 제외한 약은 분석 결과와 복약 일정에 들어가지 않습니다.

**참고**

다시 조회해도 확인되지 않으면 이름을 재검토하세요. 재조회가 성공을 보장하지는 않습니다. 제외된 약은 분석 결과와 복약 일정에 들어가지 않습니다. 필요한 약을 놓치지 않도록 주의하세요.

### 2.4 이전 처방과 비교하기

[화면 예시: PDF 20쪽](MedBuddy_User_Guide_ko.pdf#page=20)

#### 1. 이전 처방과 비교

분석 결과에 ‘처방 변화 레이더’가 보이면 비교 기준 날짜와 ‘추가’, ‘미확인’ 약을 확인하세요. 복용 시작·중단 지시가 아니므로 실제 변경 여부는 처방전이나 의료진에게 확인하세요.

1. 비교 날짜·추가·미확인 개수
2. 약별 추가·미확인 내역

#### 2. 복약 일정 변경 확인

‘복약 일정 변경’ 아래에서 이전과 달라진 복용 정보를 확인하세요. 예시의 총 투약일은 3일에서 5일로 바뀌었으며, 이를 임의 변경 지시로 받아들이지 마세요.

**참고**

비교는 복용 시작·중단 지시가 아닙니다. 관련 이전 처방이 없거나 일부 약을 제외하면 비교가 제공되지 않을 수 있습니다.

### 2.5 분석한 약 저장하기

[화면 예시: PDF 21~22쪽](MedBuddy_User_Guide_ko.pdf#page=21)

#### 1. 분석 결과 열기

분석한 약 수와 복용 기간을 확인한 뒤 ‘결과 확인하기’를 누르세요. 예시는 약 1개, 3일이며, 아직 복약함에 저장된 상태는 아닙니다.

#### 2. 제품과 일정 대조

결과의 약 이름·함량·복용량·횟수·기간을 원본과 대조하세요. 예시는 ‘바이엘아스피린정500밀리그람’이며, 원본과 다르면 저장하지 말고 다시 확인하세요.

1. 제품명·함량: 원본과 대조
2. 복용량·횟수·기간 대조

#### 3. 전체 저장

모든 결과가 처방과 맞는지 확인한 뒤 화면 맨 아래 ‘전체 저장하기’를 눌러 검토한 약을 한꺼번에 저장하세요.

#### 4. 저장한 정보 열기

‘복약 일정 저장 완료’가 나오면 ‘저장된 정보 보기’를 눌러 목록의 약 이름과 복용 기간을 확인하세요. 일정 조회가 실패해도 즉시 재등록하지 말고 연결을 확인한 뒤 다시 조회하세요.

1. 복약 일정 저장 완료 표시
2. 저장 목록에서 등록 내용 확인

#### 5. 한 약만 저장

저장할 약의 이름과 복용 일정을 확인한 뒤 해당 카드 오른쪽 위 저장 아이콘을 누르세요. 약마다 개별로 저장할 수 있습니다.

#### 6. 개별 저장 완료 확인

저장 아이콘이 완료 체크로 바뀌고 성공 안내가 나오는지 확인하세요. 저장 표시는 앱의 처리 결과이며, 실제 복용은 처방과 복약지도에 따르세요.

1. 완료 체크: 해당 약 저장됨
2. 복약 정보 저장 성공 안내

**참고**

약 이름이나 함량이 원본과 다르면 저장하지 말고 다시 확인하세요. 완료 후 복약함에서 약 이름과 복용 기간을 한 번 더 확인하세요. 저장 완료 뒤 일정 조회에 실패했다면 곧바로 같은 약을 다시 등록하지 말고, 연결을 확인한 뒤 일정 화면을 다시 열어 확인하세요. 조회 실패가 약이 저장되지 않았다는 뜻은 아닙니다. 저장 표시는 앱의 처리 결과입니다. 실제 복용은 처방과 복약지도에 따르세요.

### 2.6 약 정보 직접 입력하기

[화면 예시: PDF 23~25쪽](MedBuddy_User_Guide_ko.pdf#page=23)

#### 1. 약 이름과 수량 입력

‘약 등록·식별’에서 ‘직접 등록’을 선택하고 약 이름과 1회 복용량의 수량을 입력하세요. 사진 없이도 등록할 수 있으며, 약 봉투나 복약 안내를 기준으로 입력하세요.

1. 약 봉투의 이름 입력
2. 수량: 1회 복용할 양

#### 2. 복용량 단위 선택

수량과 별도로 단위 목록에서 정·캡슐·포·mL·방울 중 복약 안내에 맞는 항목을 고르세요.

#### 3. 알약 사진 추가

사진을 붙이려면 ‘알약 사진’ 오른쪽의 사진 추가 아이콘을 누르세요. 사진은 선택 사항이며, 선택한 사진은 이 기기의 앱 내부에만 저장됩니다.

#### 4. 복용 기간 지정

시작일과 종료일을 각각 눌러 복용 기간을 지정하고, 두 날짜 아래에 표시되는 총 복용 일수를 확인하세요. 종료일은 시작일보다 앞설 수 없습니다.

1. 시작일: 복용 시작 날짜
2. 종료일: 시작일보다 빠르지 않게

#### 5. 종료 날짜 선택

달력에서 종료 날짜를 선택하고 오른쪽 아래 ‘확인’을 누르세요. 화면은 9월 28일을 고른 예시이며, 실제 복용 기간에 맞게 선택하세요.

1. 종료 날짜: 예시 9월 28일
2. 확인: 선택한 날짜 반영

#### 6. 복용 기간 재확인

입력 화면으로 돌아오면 시작일·종료일과 총 일수가 맞는지 확인하세요. 예시는 9월 22일부터 28일까지 총 7일입니다.

#### 7. 복용 시간대 선택

아래로 내려 아침·점심·저녁·취침 전 중 복약 안내에 맞는 시간대를 모두 누르세요. 선택한 시간대에는 초록색 체크가 표시됩니다.

#### 8. 복약 정보 저장

입력이 맞으면 ‘복약 정보 저장’을 누르세요. 요청 중에는 버튼이 ‘저장 중...’으로 바뀌므로 처리가 끝날 때까지 기다리세요.

#### 9. 복약함에서 확인

저장 후 복약함을 열어 약 이름과 복용 기간을 확인하세요. 화면은 SampleTablet이 저장된 예시입니다. 약을 삭제하면 연결된 복용 기록도 잃을 수 있습니다.

#### 10. 빠진 약 이름 입력

이름을 비운 채 저장해 빨간 안내가 나타나면 약 이름을 입력한 뒤 다시 저장하세요.

#### 11. 저장된 복용 정보 확인

복약함의 ‘가이드’를 열어 등록된 복용량·횟수·기간을 확인하세요. 예시는 1정·3회·7일입니다. ‘정보 없음’인 효능이나 복용법은 임의로 채우지 마세요.

**참고**

약 봉투나 복약 안내에 적힌 내용을 기준으로 입력하세요. 사진 추가 버튼은 선택용입니다. 사진이 없는 예시에서는 미리보기가 나타나지 않습니다. 이 예시는 종료일 선택입니다. 종료일은 시작일보다 앞설 수 없습니다. 시간대는 복약 안내에 맞춰 고르세요. 저장된 약을 삭제하면 연결된 복용 기록도 잃을 수 있습니다. ‘정보 없음’은 해당 안내가 제공되지 않았다는 뜻입니다. 임의로 효능이나 복용법을 채우지 마세요.

### 2.7 한 장에 찍힌 여러 알약 찾기

[화면 예시: PDF 26쪽](MedBuddy_User_Guide_ko.pdf#page=26)

#### 1. 여러 알약 식별 선택

홈 ‘약 등록·식별’의 ‘낱알약 식별’에서 ‘여러 알약 한 번에 찾기’를 선택하세요. 외부 AI가 한 사진의 알약을 번호별로 분석합니다. 후보만으로 약을 확정하지 마세요.

#### 2. 알약 사진 추가

알약을 최대 10개까지 서로 겹치지 않게 준비하고 ‘사진 추가’를 눌러 카메라나 갤러리에서 사진을 가져오세요.

#### 3. 사진 번호와 후보 대조

분석한 사진의 번호와 아래 후보 목록의 번호를 맞춰 확인하세요. 예시의 1·2번은 같은 제품의 앞뒷면이며, 서로 다른 약 두 종류를 뜻하지 않습니다.

#### 4. 사진 변경

다른 사진을 가져오려면 번호별 분석 버튼 위의 ‘사진 변경’을 누르세요.

**참고**

사진은 외부 AI로 분석됩니다. 후보만으로 약을 확정하지 말고 포장 정보와 대조하세요. 이 촬영 예시는 같은 제품의 앞뒷면이 담긴 사진입니다. 서로 다른 약 두 종류를 식별한 사례가 아닙니다.

### 2.8 알약마다 앞뒷면 사진 넣기

[화면 예시: PDF 27쪽](MedBuddy_User_Guide_ko.pdf#page=27)

#### 1. 앞면과 뒷면 추가

‘낱알약 식별’의 ‘알약 하나씩 찾기’에서 ‘앞면’을 눌러 필수 사진을 가져오세요. 필요하면 같은 알약의 ‘뒷면’도 추가하세요. 한 묶음에 다른 알약을 섞지 마세요.

1. 앞면: 묶음마다 필수
2. 뒷면: 같은 알약 사진, 선택

#### 2. 추가한 사진 확인

추가된 사진이 맞는지 확인하세요. 잘못 넣었으면 사진 오른쪽 위 X를 눌러 제거하세요. 화면은 앞면에만 사진을 넣은 예시입니다.

1. 앞면 사진: 알약 확인
2. X: 잘못 넣은 앞면 제거

#### 3. 모든 앞면 사진 준비

‘알약 한 개 더 추가’를 눌러 새 묶음에도 앞면을 넣으세요. 필요 없는 묶음은 휴지통으로 삭제하세요. 앞면이 하나라도 빠지면 후보 찾기 버튼을 사용할 수 없습니다.

1. 휴지통: 알약 2 묶음 삭제
2. 새 묶음의 앞면 사진 필수
3. 모든 앞면을 넣어야 후보 찾기

#### 4. 후보 찾기 시작

모든 묶음에 앞면 사진을 넣은 뒤 ‘알약 N개 후보 찾기’를 누르세요. 화면은 앞면 한 장을 넣어 알약 1개의 후보를 찾을 수 있는 상태입니다.

1. 다른 알약의 사진 묶음 추가
2. 사진으로 알약 1개 후보 찾기

**참고**

한 묶음에는 같은 알약의 앞면과 뒷면을 넣으세요. 앞면은 필수이고 뒷면은 선택 사항입니다. 필요 없는 묶음은 해당 묶음 오른쪽 위 휴지통으로 삭제할 수 있습니다.

### 2.9 알약 후보를 비교하고 다시 확인하기

[화면 예시: PDF 28~29쪽](MedBuddy_User_Guide_ko.pdf#page=28)

#### 1. 일치도 경고와 제품 비교

사진 품질·일치도 경고를 읽고 모양·색·각인을 후보의 제품 정보, 실물·포장과 직접 대조하세요. ‘추가 확인 필요’가 있으면 특히 주의하세요.

1. 일치도·사진 품질 경고
2. 각인: TYLENOL / 500

#### 2. 대조한 후보 선택

실물과 포장 정보를 대조한 후보를 누르면 초록색 테두리와 선택 표시가 생깁니다. 선택 표시는 약의 식별이 확정됐다는 뜻은 아닙니다.

#### 3. 추가 후보 펼치기

해당 번호의 후보 목록 아래에 ‘비슷한 후보 더 보기’가 있으면 눌러 추가 후보를 펼치세요. 번호마다 후보 수는 다를 수 있습니다.

#### 4. 추가 후보 비교

기존 목록 아래에 새로 나타난 후보도 제품명과 각인을 실물·포장과 대조하세요. 목록에 있다는 이유만으로 같은 약이라고 판단하지 마세요.

1. 각인: HCD / 500
2. 각인: Y분할선J / 500

#### 5. 재분석 또는 뒷면 추가

사진의 번호가 맞는지 확인한 뒤 후보 목록 위의 ‘영역 다시 분석’이나 ‘뒷면 추가’를 누르세요. 뒷면은 반드시 같은 알약을 뒤집은 사진을 사용하세요.

1. 알약 1 영역 다시 분석
2. 같은 알약 1의 뒷면 추가

#### 6. 뒷면 사진 출처 선택

안내 위의 앞면 사진을 확인하고 같은 알약의 뒷면을 카메라나 갤러리로 가져오세요. 다른 알약을 연결하지 마세요. ‘취소’를 누르면 추가하지 않습니다.

1. 같은 알약을 뒤집어 촬영
2. 사진 출처: 갤러리·카메라

**참고**

‘추가 확인 필요’나 낮은 일치도 안내가 있으면 특히 주의하세요. 후보 선택이 약의 확정을 뜻하지는 않습니다. 아래 목록은 추가 후보를 펼친 예시입니다. 목록에 있다는 이유만으로 같은 약이라고 판단하지 마세요. 뒷면에는 반드시 같은 알약을 뒤집은 사진을 넣으세요. 이 예시는 사진 출처를 고르기 전 화면입니다.

### 2.10 선택한 알약 저장하기

[화면 예시: PDF 30~32쪽](MedBuddy_User_Guide_ko.pdf#page=30)

#### 1. 복약 정보 검토 시작

후보 목록 아래 ‘선택한 후보 확인’을 눌러 복약 정보를 검토하세요. 화면은 알약 한 개의 후보를 선택한 예시입니다.

#### 2. 임시 복약 정보 수정

안내를 읽고 약 오른쪽 연필 아이콘을 눌러 복용량·횟수·기간·시간대를 고치세요. 사진만으로 실제 복용 정보를 알 수 없으므로 임시 기본값을 그대로 저장하지 마세요.

1. 임시 값: 처방·약 봉투 대조
2. 연필: 복약 정보 수정

#### 3. 이름·시작일·복용량 수정

수정 창 위쪽의 약 이름·복용 시작일·1회 복용량을 처방전이나 약 봉투와 대조해 고치세요. ‘취소’를 누르면 변경을 적용하지 않고 돌아갑니다.

#### 4. 횟수·기간·시간대 적용

하루 횟수와 기간을 입력하고 복용 시간대가 처방과 맞는지 확인한 뒤 ‘적용’을 누르세요. 화면은 하루 2회, 아침·저녁을 고른 예시입니다.

1. 하루 횟수·전체 복용 일수
2. 실제 복용할 시간대 선택
3. 적용: 수정한 일정 반영

#### 5. 변경 내용 재확인

복약 정보 확인 화면에서 약 이름과 수정한 복용 일정을 다시 확인하세요. 예시는 하루 2회, 아침·저녁으로 반영된 상태입니다.

#### 6. 복약 정보 저장 요청

정보가 처방이나 약 봉투와 맞으면 화면 맨 아래 ‘확인하고 저장하기’를 눌러 복약 정보를 저장하세요.

#### 7. 저장 완료 확인

‘저장 완료’와 ‘복약 정보를 저장했습니다.’ 안내를 확인하세요. 이는 앱의 저장 처리 결과이며 후보 식별의 정확성을 보증하지 않습니다.

1. 저장 완료 상태 표시
2. 복약 정보 저장 안내

#### 8. 여러 알약 검토 시작

번호별 후보를 확인하고 ‘선택한 알약 N개 검토 후 저장’을 누르세요. 예시처럼 두 번호에서 같은 제품을 선택하면 중복 확인 창이 나타날 수 있습니다.

#### 9. 중복 처리 방식 선택

‘각각 유지’나 ‘같은 일정만 묶기’를 선택하세요. 묶기는 복약 정보 검토 뒤 적용되며 복용량·날짜·기간 등이 다르면 별도로 유지됩니다. 돌아가려면 ‘취소’를 누르세요. 아직 저장된 것은 아닙니다.

1. 완전히 같은 일정만 묶기
2. 각각 유지 / 같은 일정만 묶기

**참고**

사진만으로 복용량과 기간을 알 수 없습니다. 임시 기본값을 그대로 저장하지 마세요. 수정 창의 ‘취소’는 변경을 적용하지 않고 돌아갑니다. 완료 화면은 앱의 저장 처리 결과입니다. 후보 식별의 정확성을 보증하지 않습니다. 같은 일정만 묶기는 복약 정보 검토 뒤 적용됩니다. 이 창이 나타난 것만으로 병합이나 저장이 끝난 것은 아닙니다.

## 3 오늘의 복약 기록

### 3.1 홈에서 오늘 일정 확인하기

[화면 예시: PDF 33~34쪽](MedBuddy_User_Guide_ko.pdf#page=33)

#### 1. 오늘 기록의 진행률

오늘의 복약 진행률을 확인하세요. 앞의 숫자는 완료로 기록한 건수, 뒤의 숫자는 오늘 전체 건수입니다. 예시는 0/5이며 같은 약도 시간대가 다르면 별도 기록입니다.

#### 2. 시간대와 미복용 확인

시간대 요약에서 완료 여부, 알림 시각, 약 이름을 확인하세요. 예시는 저녁 미복용이며 테스트 저녁약 외 1개가 표시됩니다. 등록된 아침·점심·저녁을 나타내는 점 세 개 중 세 번째 점이 채워집니다.

#### 3. 아침에서 시작

아침 요약을 확인한 뒤 요약 영역을 왼쪽으로 밀어 점심으로 이동하세요. 예시는 아침 약 2건이 미복용이며 첫 번째 점이 채워져 있습니다. 오늘 전체 진행률은 0/5입니다.

#### 4. 점심 기록 확인

점심의 약 이름과 미복용 상태를 확인하세요. 예시는 점심 약 1건이며 세 점 중 두 번째 점이 채워집니다. 전체 진행률은 0/5로 유지되고 오른쪽으로 밀면 아침으로 돌아갑니다.

#### 5. 저녁 기록 확인

다시 왼쪽으로 밀어 저녁을 확인하세요. 예시는 저녁 약 2건이 미복용이며 세 번째 점이 채워집니다. 약이 등록되지 않은 취침 전은 표시되지 않아 더 왼쪽으로 밀어도 저녁에 머뭅니다.

**참고**

완료 표시는 사용자가 남긴 기록이며 실제 복용을 자동으로 확인한 결과가 아닙니다. 사진의 아침 18:55 등은 촬영용 설정입니다. 실제 시각은 처방·복약 안내에 맞춰 확인하세요. 홈의 점은 등록된 시간대의 위치 표시이며 누르는 버튼이 아닙니다. 약이 없는 시간대는 표시하지 않습니다. 환자 전환과는 다르며, 보호자 홈에서는 환자 이름 양옆 화살표로 환자를 바꿉니다.

### 3.2 홈에서 완료와 취소 기록하기

[화면 예시: PDF 35~36쪽](MedBuddy_User_Guide_ko.pdf#page=35)

#### 1. 현재 시간대 기록

아침의 약 이름과 시간대를 확인한 뒤 실제로 모두 복용했을 때 ‘복용했어요’를 누르세요. 예시에서는 아침 약 2건이 함께 완료로 기록되며 추가 확인창은 나타나지 않습니다. 일부만 복용했다면 전체 일정에서 개별 체크하세요.

#### 2. 완료 후 다음 일정

아침 약 2건이 완료되어 진행률이 2/5로 바뀌고, 뒤쪽의 다음 미완료 시간대인 점심으로 자동 이동합니다. 예시는 점심이 미복용이며 두 번째 점이 채워져 있습니다. 아침의 완료 상태를 다시 보려면 요약 영역을 오른쪽으로 밀어 돌아가세요.

1. 아침 2건 완료, 전체 진행률 2/5
2. 다음 미완료 시간대인 점심으로 자동 이동

#### 3. 완료한 시간대 취소

점심 요약을 오른쪽으로 밀어 아침으로 돌아오세요. ‘아침 · 복용 완료’와 전체 진행률 2/5를 확인한 뒤 잘못 남긴 기록만 ‘복용 취소’로 되돌리세요. 예시에서는 아침 약 2건이 함께 취소됩니다.

#### 4. 취소 후 상태

아침 약 2건이 미복용으로 돌아와 진행률이 0/5가 되고 ‘복용했어요’ 버튼이 다시 보입니다. 취소 후에는 아침 시간대에 그대로 머물며 다른 시간대의 기록은 바뀌지 않습니다. 약 하나만 취소하려면 전체 일정의 해당 체크를 사용하세요.

1. 취소 후 전체 진행률 0/5
2. 아침 미복용, 첫 번째 점 유지
3. 다시 표시된 복용했어요 버튼

**참고**

예정 시간보다 늦거나 2시간 넘게 일찍 기록하면 처방·복약지도를 확인하라는 안내가 함께 나올 수 있습니다. 이 안내는 복용 시각을 변경하라는 지시가 아닙니다. 전송 대기는 「연결이 끊겼을 때 기록 확인하기」 항목을 참고하세요.

### 3.3 전체 일정에서 약별로 기록하기

[화면 예시: PDF 37~38쪽](MedBuddy_User_Guide_ko.pdf#page=37)

#### 1. 내 전체 일정 열기

하단 ‘일정’을 눌러 내 계정에 등록된 오늘의 약을 시간대별로 확인하세요. 연결된 환자의 일정은 보호자 홈이나 연동 목록에서 따로 여세요.

#### 2. 기록·상세정보·알림 구분

내 ‘일정’에서 약 이름·1회 복용량을 처방과 대조하세요. 왼쪽 원은 복용 기록, 약 이름은 상세정보, 종은 알림 설정입니다. 환자 일정은 보호자 홈이나 연동 목록에서 여세요.

1. 원: 기록 / 약 이름: 상세
2. 종: 시간대 알림 설정

#### 3. 복용한 약만 기록

실제로 복용한 약 왼쪽의 빈 원을 누르세요. 선택한 약의 해당 시간대만 완료되며, 같은 시간대의 다른 약이나 다른 시간대 기록은 바뀌지 않습니다.

#### 4. 완료 상태와 실행 취소

체크 표시와 약 이름의 취소선으로 완료 상태를 확인하세요. 잘못 눌렀다면 완료 직후 아래에 잠깐 나타나는 ‘실행 취소’를 누르세요.

1. 완료 체크와 이름의 취소선
2. 실행 취소: 방금 기록 되돌림

#### 5. 약 하나의 기록 취소

취소할 약의 체크 표시를 다시 누르면 해당 약의 그 시간대 기록만 해제됩니다. ‘실행 취소’ 안내가 사라진 뒤에도 사용할 수 있습니다.

#### 6. 취소된 약 확인

체크가 빈 원으로, 약 이름이 취소선 없는 글씨로 돌아오고 진행률이 줄었는지 확인하세요. 실제로 복용하지 않았는데 완료로 남은 기록이 없는지도 살펴보세요.

#### 7. 아래쪽 일정 확인

일정 목록을 위로 밀어 저녁·취침 전 등 아래쪽 시간대를 보세요. 진행률과 하단 메뉴는 유지되고 목록만 움직입니다. 약이 예상과 다르면 복약함의 복용 기간과 등록 시간대를 확인하세요.

#### 8. 전체 일정의 빈 시간대 확인

전체 일정을 위로 밀어 ‘복용할 약이 없습니다’가 보이면 복약함의 기간·시간대를 확인하세요. 빈 일정만으로 약이 삭제된 것은 아닙니다. 홈에서는 약이 없는 시간대 페이지를 표시하지 않습니다.

**참고**

복용량과 복용 시간은 처방이나 복약 안내에 맞춰 확인하세요. 화면의 예시 약과 용량을 실제 복용 기준으로 사용하지 마세요. 약이 예상과 다르게 보이면 복약함의 복용기간과 등록 시간대를 먼저 확인하세요. 기간이 지난 약은 오늘 일정에 나오지 않습니다.

### 3.4 시간대 전체 기록하기

[화면 예시: PDF 39쪽](MedBuddy_User_Guide_ko.pdf#page=39)

#### 1. 시간대 전체 완료

아침 약을 모두 실제로 복용했다면 제목 오른쪽의 겹친 체크를 누르세요. 아침의 모든 약이 완료로 기록되며 점심·저녁 기록은 바뀌지 않습니다. 일부만 복용했다면 개별 체크하세요.

#### 2. 전체 완료와 해제

같은 시간대의 모든 약에 체크가 생겼는지 확인하세요. 겹친 체크는 ‘전부 해제’로 바뀌며, 다시 누르면 해당 시간대에서 개별로 남긴 기록까지 함께 해제됩니다.

1. 시간대의 모든 약 완료 체크
2. 전부 해제: 개별 기록도 취소

**참고**

아직 복용하지 않은 약이 섞여 있으면 전체 완료 대신 개별 체크를 사용하세요.

### 3.5 일정별 알림 시간 설정하기

[화면 예시: PDF 40~41쪽](MedBuddy_User_Guide_ko.pdf#page=40)

#### 1. 시간대 알림 설정 열기

오늘의 복약 일정에서 원하는 시간대 제목의 종을 누르세요. ‘아침 알림 설정’처럼 선택한 시간대의 설정창이 열립니다.

#### 2. 알림 사용 켜기

‘알림 사용’을 켜면 알림 시간 버튼을 사용할 수 있습니다. 꺼져 있으면 시간을 누를 수 없습니다. 알림을 받으려면 휴대폰 알림 권한과 환경설정의 ‘내 복약 알림’도 켜세요.

#### 3. 알림 시간 선택

오늘의 복약 일정에서 연 시간대 알림 설정창의 ‘알림 시간’을 누르세요. 해당 시간대의 시와 분을 고르는 창이 열립니다.

#### 4. 시간 선택 확인

휠을 움직여 시·분을 고르거나 가운데 숫자를 눌러 직접 입력한 뒤 오른쪽 위 ‘확인’을 누르세요. 시는 0~23, 분은 0~59이며, 설정창에서 별도로 저장해야 합니다.

1. 시·분 휠 또는 직접 입력
2. 확인: 시각 선택, 저장 별도

#### 5. 알림 설정 저장

설정창에서 바뀐 시각을 확인하고 ‘저장’을 눌러 시간대 알림에 반영하세요. ‘취소’를 누르면 이 창의 변경을 반영하지 않고 닫습니다.

1. 복약 안내에 맞는 시각 확인
2. 저장: 알림 여부·시각 반영

#### 6. 저장된 알림 확인

시간 선택의 ‘확인’ 뒤 설정창에서 ‘저장’까지 누르고 시간대 제목 아래 시각·종 상태를 확인하세요. 아침 18:55는 촬영용 예시이며 실제로는 처방·복약 안내에 맞게 설정하세요.

**참고**

휴대폰 알림 권한과 환경설정의 내 복약 알림도 켜져 있어야 알림을 받을 수 있습니다. 환경설정의 기본 복약 시간은 아직 시간대별 알림을 따로 저장하지 않은 시간대에 사용됩니다. 이미 저장한 알림의 시각을 바꾸려면 해당 시간대의 종 아이콘에서 변경하고 저장하세요.

### 3.6 연결이 끊겼을 때 기록 확인하기

[화면 예시: PDF 42쪽](MedBuddy_User_Guide_ko.pdf#page=42)

#### 1. 서버 전송 대기 확인

인터넷이 끊기면 복용 기록이 기기에 먼저 남고 ‘전송 대기’가 표시될 수 있습니다. 보호자에게 아직 전달되지 않았을 수 있으니 약을 다시 먹거나 기록을 반복하지 말고 전송 상태를 확인하세요.

#### 2. 전송 대기 기록 열기

전송 대기 안내를 눌러 약 이름·기록 날짜·시간대·복용 또는 취소 여부를 확인하세요. 기기에 저장된 것과 서버 저장 완료는 다릅니다. 전송 전에 앱 데이터를 지우거나 재설치하지 마세요.

#### 3. 기존 대기 기록 재전송

인터넷 연결 후 앱으로 돌아오면 대기 기록 전송을 다시 시도합니다. 필요하면 ‘다시 전송’을 누르고 처리가 끝날 때까지 기다리세요. 기록을 반복 입력하지 마세요. 날짜가 바뀌어도 원래 날짜로 전송됩니다.

#### 4. 서버 저장 완료 확인

‘서버에 모두 저장했습니다.’가 나오면 대기 기록이 처리된 상태입니다. 보호자 화면도 새로고침해 최신 상태를 확인하세요. ‘전송 확인 필요’가 계속되면 기록 내용을 확인하고 함부로 지우지 마세요.

**참고**

이 목록은 전체 복용 이력이 아니라 아직 서버에 전달되지 않은 기록을 확인하는 곳입니다. 앱 데이터 삭제나 재설치를 먼저 하지 마세요. 날짜가 바뀐 기록은 원래 날짜에 전송됩니다. 전송 확인 필요가 계속 보이면 해당 기록 내용을 확인하고, 저장되지 않은 기록을 지우기 전에 의미를 확인하세요.

## 4 환자와 보호자 연결

### 4.1 환자가 연동 코드 만들기

[화면 예시: PDF 43쪽](MedBuddy_User_Guide_ko.pdf#page=43)

#### 1. 환자 코드 생성

환자 본인 계정의 ‘내 정보 → 환자/보호자 연동’에서 ‘환자 코드 생성’을 누르면 8자리 코드가 만들어집니다. 코드 생성만으로 보호자와 연결되지는 않으며 보호자는 별도 계정을 사용합니다.

#### 2. 코드 복사와 유효시간

코드를 눌러 복사하고 ‘남은 시간’을 확인해 보호자에게만 전달하세요. 보호자는 자신의 별도 계정에 코드를 입력합니다.

1. 보호자에게 전달할 코드
2. 코드 사용 남은 시간

#### 3. 코드 창 닫기

보호자가 별도 계정에서 등록한 뒤, 환자 계정의 ‘내 정보 → 환자/보호자 연동’에서 연 코드 창의 X를 누르세요. 연동 목록을 다시 불러오면 상대가 나타나는지 확인하세요.

**참고**

코드는 15분 동안 한 번 사용할 수 있습니다. 만료되거나 이미 사용했다면 새 코드를 만드세요. 창을 닫거나 새 코드를 만들었다고 이전 코드가 즉시 폐기되는 것은 아닙니다.

### 4.2 보호자가 환자 등록하기

[화면 예시: PDF 44쪽](MedBuddy_User_Guide_ko.pdf#page=44)

#### 1. 환자 코드 입력

보호자 계정의 ‘내 정보 → 환자/보호자 연동 → 환자 관리 등록’을 열고 ‘환자 코드’에 환자에게 받은 유효한 8자리 코드를 입력하세요. 소문자는 대문자로 바뀌며 ABCD1234는 예시입니다.

#### 2. 코드 등록

입력한 코드를 확인하고 ‘등록하기’를 누른 뒤 완료될 때까지 기다리세요. 제출하기 전에는 X 모양 닫기로 취소할 수 있습니다.

1. 전달받은 8자리 코드
2. 환자 연동 등록 요청

#### 3. 연동 완료

완료 안내와 목록에 추가된 환자 이름을 확인하세요. 다른 환자도 유효한 코드를 받아 보호자 계정의 ‘내 정보 → 환자/보호자 연동 → 환자 관리 등록’에서 등록할 수 있습니다.

1. 환자 연동 완료 안내
2. 새로 연결된 환자 이름

**참고**

자기 계정에서 만든 코드를 같은 계정에 등록할 수는 없습니다. 8자리 오류는 입력을 고치고, 만료·사용 완료·잘못된 코드 안내는 환자에게 새 코드를 받아 다시 시도하세요. 긴 ‘환자 해시’는 등록용 코드가 아닙니다.

### 4.3 연결된 가족 확인하기

[화면 예시: PDF 45쪽](MedBuddy_User_Guide_ko.pdf#page=45)

#### 1. 환자 복약 정보

‘내 정보 → 환자/보호자 연동’에서 환자 이름 옆 약 모양 ‘환자 복약 정보 확인’을 누르면 해당 환자의 복약 화면이 열립니다. 이 버튼은 보호자에게만 보입니다.

1. 복약 정보를 볼 환자
2. 환자 복약 화면 열기

#### 2. 가족과 복약 대화

목록으로 돌아와 상대 옆 말풍선 모양 ‘복약 대화’를 누르면 대화가 열립니다. 환자도 보호자 옆 말풍선으로 대화할 수 있습니다.

**참고**

‘저장된 연동정보가 없습니다.’가 나오면 먼저 연결하세요. 복약 대화를 열 수 없다는 안내가 나오면 현재 복용 약과 연결 상태를 확인합니다. 목록을 불러오지 못했을 때는 뒤로 나왔다가 다시 열어 보세요.

### 4.4 환자의 홈과 전체 일정 확인하기

[화면 예시: PDF 46~48쪽](MedBuddy_User_Guide_ko.pdf#page=46)

#### 1. 환자 선택과 새로고침

이름 옆 화살표로 확인할 환자를 고르고 새로고침하세요. 예시의 환자 TEST는 오늘 전체 0/5이며 아침 두 건이 미복용입니다. 첫 환자의 이전 화살표는 회색입니다. 완료·미복용은 앱의 기록으로, 실제 복용을 자동 확인한 결과는 아닙니다.

1. 환자 이름과 전환 화살표
2. 선택한 환자 기록 새로고침
3. 오늘 전체 진행률 0/5

#### 2. 점심으로 넘기기

진행률 아래의 시간대 요약을 왼쪽으로 미세요. 점심·미복용과 테스트 점심약이 표시되고, 등록된 세 시간대 중 두 번째 점이 채워집니다. 오늘 전체 진행률은 0/5로 유지됩니다.

#### 3. 저녁 확인

점심 요약을 다시 왼쪽으로 미세요. 저녁·미복용과 테스트 저녁약 외 1개가 표시되고, 세 점 중 세 번째 점이 채워집니다. 예시의 저녁 두 건은 미복용이며 오늘 전체 진행률은 0/5입니다.

#### 4. 마지막 등록 시간대 확인

저녁에서 한 번 더 왼쪽으로 밀어도 마지막 시간대인 저녁에 머무릅니다. 이 예시의 홈에는 약이 등록된 아침·점심·저녁만 표시되어 점이 세 개이며, 약이 없는 취침 전은 나타나지 않습니다. 기록이 예상과 다르면 환자 이름과 전체 일정을 함께 확인하세요.

#### 5. 환자의 전체 일정 열기

원하는 환자가 선택되었는지 이름을 확인한 뒤 홈 카드의 ‘일정 보기’를 누르세요. 선택한 환자의 오늘 일정이 열립니다. 보호자는 읽기 전용 일정에서 환자의 복용 완료를 대신 체크하거나 취소할 수 없습니다.

#### 6. 읽기 전용 일정 확인

위쪽 환자 이름과 진행률을 확인하고 아침·점심·저녁·취침 전 약 목록을 살펴보세요. 예시의 환자 TEST는 0/5이며, 카드의 알림 문구는 보호자가 받는 알림을 뜻합니다.

1. 일정을 조회할 환자
2. 오늘 완료 기록 0/5
3. 아침 약·보호자 알림

#### 7. 현재 기록 다시 확인

환자에게 새 소식을 받았다면 상세 일정의 업데이트 문구 오른쪽 새로고침을 누르세요. 조회 후 업데이트 문구와 진행률을 확인하되, 바뀐 기록이 없으면 수치는 그대로입니다.

#### 8. 취침 전까지 내려 보기

약 목록을 위로 밀어 아래 시간대의 기록도 살펴보세요. 예시의 환자 TEST는 취침 전에 등록된 약이 없습니다.

#### 9. 약 이름과 복용법

환자 일정의 약 항목을 눌러 상세를 열고 이름·효능과 1회 복용량·횟수·기간을 읽으세요. 사진은 앞 일정과 다른 ‘환자2 테스트 아침약’ 예시입니다. 화면만 보고 처방된 복용법을 바꾸지 마세요.

1. 환자2 테스트 아침약
2. 복용량·횟수·기간

#### 10. 안내와 주의사항

환자 일정의 약 항목을 눌러 연 상세 화면을 위로 밀어 안내와 주의사항을 읽으세요. 자료가 없는 항목은 ‘정보 없음’으로 표시됩니다. 사진은 실제 복용 지시가 아닌 테스트 자료입니다.

1. 테스트용 복용 가이드
2. 테스트용 주의사항
3. 가이드 정보 없음

**참고**

완료·미복용은 앱에 남긴 기록이며 실제 복용을 자동 확인한 결과는 아닙니다. 보호자 홈은 환자의 알림 시각을 추정해 표시하지 않습니다. 점은 약이 등록된 시간대의 위치를 보여 주며, 시간대는 좌우로 밀어 바꿉니다. 홈에는 약이 등록된 시간대만 표시됩니다. 취침 전 약을 등록하면 그 시간대도 나타납니다. 기록이 예상과 다르면 환자 이름과 상세 일정을 함께 확인하세요. 보호자는 이 화면에서 환자의 복용 완료를 대신 체크하거나 취소할 수 없습니다. 뒤로가기를 누르면 이전 화면으로 돌아갑니다. 불러오지 못했다는 안내가 나오면 연결을 확인한 뒤 새로고침하세요. 보호자 알림 설정의 종 아이콘은 환자의 완료 기록을 바꾸는 버튼이 아닙니다. 뒤로가기를 누르면 환자 일정으로 돌아갑니다. 화면의 안내만으로 처방된 복용법을 바꾸지 마세요.

### 4.5 가족의 표시 이름 바꾸기

[화면 예시: PDF 49쪽](MedBuddy_User_Guide_ko.pdf#page=49)

#### 1. 표시 이름 입력

연동 목록에서 상대 옆 연필을 누르고 표시 이름을 20자 이내로 적으세요. 사진은 환자가 ‘보호자 표시 이름’을 바꾸는 예이며, 비워 저장하면 기본 이름으로 돌아갑니다.

#### 2. 이름 저장

입력한 이름을 확인하고 ‘저장’을 누르면 입력 창이 닫힙니다. 이름을 바꾸지 않으려면 ‘취소’를 누르세요.

1. 입력한 표시 이름 저장
2. 이름 변경 없이 닫기

#### 3. 목록에 반영된 이름

내 계정의 연동 목록에 새 이름이 표시되는지 확인하고 다시 고치려면 옆의 연필을 누르세요. 사진은 환자가 보호자 이름을 바꾼 예이며 상대의 로그인 이름은 바뀌지 않습니다.

1. 내 계정의 상대 별칭
2. 상대 표시 이름 수정

**참고**

보호자가 환자 옆 연필을 누르면 ‘환자 표시 이름’ 창이 열리며, 그 이름은 보호자 계정에 동기화됩니다. 상대의 로그인 이름이나 다른 가족이 정한 별칭은 바뀌지 않습니다. 저장 실패 때는 연결 상태를 확인하고 다시 저장하세요.

### 4.6 연동 해제하기

[화면 예시: PDF 50쪽](MedBuddy_User_Guide_ko.pdf#page=50)

#### 1. 해제할 상대 확인

해제할 상대 이름을 확인하고 ‘연동 관리’를 누르면 아래에 연동 정보가 펼쳐집니다. 다시 누르면 접힙니다.

1. 연동을 해제할 상대
2. 연동 정보 펼치기·접기

#### 2. 연동 해제 실행

연결을 끝내려면 ‘연동 해제’를 누르세요. 추가 확인 창 없이 해제를 요청하며, 해당 관계의 대화와 보호자 알림 설정도 삭제됩니다. 다시 연결해도 대화는 복구되지 않습니다.

#### 3. 해제 완료

해제 완료 안내와 상대가 사라진 목록을 확인하세요. 사진은 이미 해제가 끝난 상태이며, 다시 연결하려면 새 코드가 필요합니다. 환자 계정과 전체 복약 자료는 삭제되지 않습니다.

**참고**

환자의 계정이나 전체 복약 자료는 삭제하지 않습니다. 해제로 지워진 대화는 다시 연결해도 돌아오지 않으며 실행 취소 버튼도 없습니다. 오류가 나면 목록을 다시 열어 실제 연결 상태를 확인하세요.

## 5 가족 채팅과 알림

### 5.1 가족과 대화 열기

[화면 예시: PDF 51쪽](MedBuddy_User_Guide_ko.pdf#page=51)

#### 1. 환자 선택

환자·보호자 연결 후 나타나는 하단 ‘채팅’을 누르고 이름과 마지막 메시지를 살펴 환자를 고르세요. 환자별 대화가 따로 열리며 대화가 없으면 ‘아직 대화가 없어요’로 표시됩니다.

1. 환자 TEST의 최근 대화
2. 아직 대화가 없는 환자

#### 2. 받은 기록 읽기

환자 이름과 아침·저녁 카드의 약·일괄 완료 건수를 읽으세요. 처음 열면 최근 메시지로 이동하며 이전 대화를 읽는 중에는 새 메시지가 와도 위치가 유지됩니다. 기록은 실제 복용을 자동 검증한 결과가 아닙니다.

1. 현재 대화 중인 환자
2. 아침 완료 기록 2/2
3. 저녁 완료 기록 2/2

**참고**

일괄 완료 메시지와 환자의 ‘먹었어요’ 빠른 답장은 서로 다른 메시지입니다. 어느 쪽도 실제 복용을 자동 검증하는 것은 아닙니다. 새 메시지는 대화방이 화면에 열려 있을 때 읽음 처리됩니다.

### 5.2 대화할 약 선택하기

[화면 예시: PDF 52~53쪽](MedBuddy_User_Guide_ko.pdf#page=52)

#### 1. 약 목록에서 선택

입력칸 왼쪽 약 모양 아이콘으로 목록을 열고 함께 이야기할 약의 선택 원을 누르세요. 사진은 선택 전 상태로, 0개 선택일 때는 ‘선택 완료’를 누를 수 없습니다.

1. 대화에 넣을 약 선택
2. 선택 전 비활성 버튼

#### 2. 선택한 개수 확인

약을 고른 뒤 체크 표시와 아래쪽 개수를 확인하세요. 한 약을 고르면 ‘1개 선택’으로 바뀌고 ‘선택 완료’를 누를 수 있습니다.

1. 현재 선택한 약 표시
2. 선택한 약 총 1개
3. 선택한 약을 채팅에 첨부

#### 3. 전체 선택

위쪽 ‘전체 선택’을 누르고 체크 표시와 개수를 확인하세요. 예시는 약 5개가 선택되며 다시 누르면 해제됩니다. 일반 메시지에는 서로 다른 약을 최대 10개까지 넣을 수 있습니다.

1. 전체 약 선택·해제
2. 선택한 약 총 5개
3. 약 첨부 완료·전송 전

#### 4. 채팅에 약 카드 붙이기

약 목록의 ‘전체 선택’ 후 ‘선택 완료’를 누르면 입력칸 위에 약 카드와 빠른 답장이 나타납니다. 아직 전송되지 않았으므로 필요 없는 약은 카드의 X로 빼세요.

1. 메시지에 첨부할 약
2. 선택 목록에서 약 제외

#### 5. 약 카드 누르기

입력칸 위 약 카드의 이름이나 오른쪽 꺾쇠를 누르면 약 상세가 열립니다. X를 누르면 상세를 여는 대신 약 선택이 해제됩니다.

#### 6. 상세 확인 후 돌아오기

메시지를 보내기 전 상세 화면에서 약 이름·복용량·복용법이 맞는지 확인하고 뒤로가기를 누르세요. 채팅으로 돌아와 메시지 작성을 이어갈 수 있습니다.

1. 대화에 첨부할 약 이름
2. 등록된 복용량·횟수·기간

**참고**

선택을 바꾸려면 같은 원을 다시 누르세요. 약을 확정하지 않으려면 뒤로가기를 누르세요. 필요 없는 약은 카드의 X로 빼세요. 일반 메시지에는 서로 다른 약을 최대 10개까지 함께 넣을 수 있습니다. ‘전체 선택’이 무제한 첨부를 뜻하지는 않습니다. 약 선택 화면의 시간대와 일반 채팅에 붙는 약 카드는 표시 내용이 다를 수 있습니다. 시간대까지 지정해 확인을 요청하려면 시계 모양 ‘복약 확인 요청’을 사용하세요.

### 5.3 메시지와 복약 확인 요청 보내기

[화면 예시: PDF 54~55쪽](MedBuddy_User_Guide_ko.pdf#page=54)

#### 1. 질문 고르기

대화할 약을 고르고 보호자용 빠른 답장 ‘복용하셨나요?’를 누르면 약 이름이 들어간 질문이 확인 창 없이 바로 전송됩니다. 질문을 보내도 환자의 복용 완료 기록은 바뀌지 않습니다.

#### 2. 전송된 질문 확인

대화 오른쪽 말풍선에서 약 카드와 질문을 확인하세요. 예시에는 선택한 약 5개와 ‘복용하셨나요?’ 질문이 함께 남아 있습니다.

1. 질문과 함께 보낸 약
2. 약 이름이 포함된 질문

#### 3. 전송 전 내용 확인

입력칸에 500자 이내로 글을 쓰고 전송 전에 고칠 부분을 지우거나 덧붙이세요. 작성 중인 글은 입력칸에만 남으며 아직 상대에게 전송되지 않습니다.

1. 전송 전 메시지 편집
2. 작성한 메시지 전송

#### 4. 보내기와 결과 확인

보내기 화살표를 한 번 누르세요. 전송 중에는 다시 누를 수 없습니다. 성공하면 오른쪽에 글과 시각이 표시되고 입력칸이 비워지며 최신 메시지로 이동합니다. 보낸 글은 수정할 수 없습니다.

1. 전송한 메시지와 시각
2. 전송 후 비워진 입력칸

#### 5. 오늘의 시간대 선택

보호자 계정의 대화에서 입력칸 왼쪽 시계 모양 ‘복약 확인 요청’을 누르세요. ‘오늘의 복약 시간대’의 약·진행률을 읽고 시간대를 누르면 요청이 즉시 전송됩니다. 보내지 않으려면 위쪽 가로 막대 모양 닫기를 누르세요.

1. 시간대별 확인 요청
2. 요청 없이 창 닫기

#### 6. 보낸 요청 확인

대화의 시간대 카드와 ‘아침 복약을 확인해주세요.’를 확인하세요. 사진은 SampleTablet 추가 후 별도 촬영한 0/3 예시입니다. 앞 사진의 0/2에서 요청 전송으로 약이 늘어난 것이 아닙니다.

**참고**

‘지금 복용 가능하세요?’, ‘남은 약이 충분한가요?’도 질문을 보내는 기능입니다. 보호자의 질문은 환자의 복용 완료 기록을 바꾸지 않습니다. 한 메시지는 최대 500자입니다. 이미 보낸 본문을 수정하는 기능은 없으므로 필요한 내용을 새 메시지로 정정하세요. 전송 실패 안내가 나오면 연결과 남아 있는 입력 내용을 확인한 뒤 다시 보내세요. 요청을 보내도 환자의 복용 기록은 바뀌지 않습니다. 시간대 창을 연 뒤 일정이 수정되면 전송된 카드의 약 목록이나 수량이 달라질 수 있으니 전송 결과도 확인하세요.

### 5.4 복용 상태와 불편함 알리기

[화면 예시: PDF 56~57쪽](MedBuddy_User_Guide_ko.pdf#page=56)

#### 1. 시간대와 약 확인

환자 계정에서 복약 확인 요청 알림을 누르면 해당 보호자와 대화가 열립니다. 아래 약 모양 버튼으로 목록을 열고 약을 고르세요. 같은 약이 여러 시간대에 있으면 기록할 시간대에서 선택하세요.

#### 2. 선택 완료

선택한 약과 개수를 확인하고 ‘선택 완료’를 누르면 대화창 아래에 약 카드와 응답 버튼이 나타납니다. 약을 선택한 것만으로 복용 완료가 기록되지는 않습니다.

1. 기록할 시간대의 약
2. 약 카드·응답 버튼 표시

#### 3. 먹었어요 누르기

선택한 약을 실제로 복용했다면 ‘먹었어요’를 누르세요. 선택한 날짜·시간대의 복용 기록을 저장하고 보호자에게 메시지를 보냅니다. 앱이 실제 복용을 자동 확인하는 것은 아닙니다.

1. 실제로 복용한 약 확인
2. 복용 기록 저장·전송

#### 4. 전송된 기록 확인

대화에서 약 이름·시간대와 ‘복용을 기록했습니다’ 문구를 확인하세요. 사진은 별도 촬영 예시로 아침 4건 중 1건이 완료로 기록된 상태입니다. 잘못 기록했다면 오늘 일정에서 취소하세요.

1. 아침 완료 기록 1/4
2. 기록한 날짜·시간대·약

#### 5. 상황에 맞는 응답 선택

약을 선택하고 ‘지금은 못 먹어요’를 누르면 해당 약과 함께 현재 복용하기 어렵다는 메시지를 보냅니다.

1. 복용이 어려운 대상 약
2. 복용 어려움 알리기

#### 6. 보낸 내용 확인

보낸 메시지에서 약 이름과 ‘지금은 못 먹어요’를 확인하세요. 이 응답만으로 복용 완료가 기록되거나 기존 복용 기록이 취소되지는 않습니다.

#### 7. 불편함 응답 찾기

약을 선택하고 응답 줄을 왼쪽으로 밀어 ‘먹고 나서 불편해요’를 누르세요. 약 이름과 불편함을 알리는 메시지가 전송되며 복용 완료 기록은 자동으로 바뀌지 않습니다.

1. 불편함을 알릴 대상 약
2. 복용 후 불편함 알리기

#### 8. 메시지와 안전 안내 확인

보낸 내용과 안전 안내를 읽고 필요한 설명을 덧붙이세요. 채팅은 진단·긴급 연락을 대신하지 않습니다. 증상이 심하거나 호흡 곤란·의식 변화가 있으면 즉시 119에 연락하고, 복용법 변경 전 의료진·약사와 상담하세요.

**참고**

여러 약을 고를 수 있습니다. 전체 선택은 목록에 표시된 선택 가능한 항목을 함께 고릅니다. 완료 전에 선택 목록을 확인하세요. 알림을 여는 것만으로 복용 완료가 기록되지는 않습니다. 대화의 복용 기록은 실제로 약을 삼켰는지 자동 확인한 결과가 아닙니다. 잘못 기록했다면 오늘의 복약 일정에서 해당 약의 복용 상태를 취소하세요. 필요하면 이어서 메시지 입력란에 이유나 요청을 적어 보내세요. 복용 시각이나 양을 바꿔야 한다면 처방 또는 전문가의 안내를 확인하세요. 채팅은 의료 상담이나 긴급 연락을 대신하지 않습니다. 이 응답을 보내도 복용 완료 기록은 자동으로 바뀌지 않습니다.

### 5.5 약 부족을 알리고 약국 정보 공유하기

[화면 예시: PDF 58~60쪽](MedBuddy_User_Guide_ko.pdf#page=58)

#### 1. 약 부족 응답 보내기

대상 약을 선택하고 응답 줄을 왼쪽으로 밀어 ‘약이 부족해요’를 누르세요. 부족하다는 메시지를 먼저 보낸 뒤 약국 찾기 화면이 열립니다.

1. 부족하다고 알릴 약
2. 부족 알림 후 약국 찾기

#### 2. 주변 약국 보기

지도 표시나 ‘약국 목록 보기’를 눌러 약국 위치와 운영 정보를 살펴보세요. 뒤로 가더라도 이미 보낸 약 부족 메시지는 대화에 남습니다.

#### 3. 목록에서 약국 선택

목록에서 이름·주소·운영 정보를 읽고 약국 이름 영역을 누르세요. 지도가 해당 약국으로 이동하고 상세 정보와 공유 버튼이 표시됩니다.

#### 4. 상세 정보 확인

약국 이름과 주소를 확인하고 필요하면 ‘전화’를 눌러 운영 여부를 물어보세요. 휴대전화의 전화 화면이 열리며, 앱이 통화 여부나 약 재고를 자동 확인하지는 않습니다.

1. 약국 이름·주소·운영 정보
2. 약국 전화 화면 열기

#### 5. 채팅에 공유 누르기

실제로 통화해 운영 여부를 확인한 경우에만 전화 확인을 체크하고 ‘채팅에 공유’를 누르세요. 전화하지 않았다면 체크하지 않고도 공유할 수 있습니다. 사진은 체크하지 않은 예시입니다.

1. 실제 통화 확인 시 체크
2. 약국 정보를 대화에 공유

#### 6. 공유된 약국 카드 확인

대화에 나타난 약국 이름·주소와 운영 안내를 읽으세요. 상대도 카드에서 전화나 길찾기를 열 수 있습니다. 운영시간 정보가 없거나 방문하려면 실제 운영 여부를 전화로 확인하세요.

#### 7. 전화 버튼 누르기

약국 카드의 ‘전화’를 누르면 약국 전화번호가 입력된 휴대전화 전화 화면이 열립니다. 이 동작만으로 통화가 연결되지는 않습니다.

#### 8. 번호 확인 후 통화

전화번호가 해당 약국의 번호인지 확인한 뒤 통화 버튼을 누르세요. 사진은 번호 확인까지만 진행한 예시이며 실제로 발신하지 않았습니다.

1. 통화할 약국 전화번호
2. Call: 통화 시작

#### 9. 길찾기 버튼 누르기

약국 카드의 ‘길찾기’를 누르면 외부 지도 화면에서 약국 위치를 볼 수 있습니다.

#### 10. 지도에서 경로 확인

지도에서 목적지 이름과 위치를 확인한 뒤 경로 안내를 이용하세요. 사진은 Google 지도의 약국 위치 화면이며 ‘Directions’를 누르면 경로를 확인할 수 있습니다.

1. 선택한 약국의 위치
2. Directions: 경로 요청

**참고**

메시지의 남은 복용 기간은 등록된 복용 종료일을 기준으로 계산합니다. 실제로 남아 있는 알약 수나 약국 재고를 뜻하지 않습니다. 약국 운영시간은 변경될 수 있습니다. 공유된 정보만으로 방문을 결정하지 말고 실제 운영 여부와 필요한 약의 취급 여부를 확인하세요. 이미 보낸 약 부족 메시지의 ‘근처 운영 약국 찾기’를 누르면 나중에도 다시 약국을 찾아 공유할 수 있습니다. 공유에 실패하면 연결을 확인하고 약국을 다시 검색해 선택한 뒤 대화에 카드가 나타나는지 확인하세요. 전화 앱에서 뒤로 가면 채팅으로 돌아갈 수 있습니다. 휴대전화에 따라 전화 앱 안의 이전 화면을 한 번 더 거칠 수 있습니다. 이 예시는 목적지 화면이 열린 상태입니다. 연결 실패 안내가 나오면 인터넷을 확인한 뒤 경로를 다시 요청하세요. 지도 앱에서 뒤로 가면 채팅으로 돌아옵니다. 지도 앱의 내부 화면이 먼저 닫히면 뒤로 가기를 한 번 더 누르세요.

### 5.6 메시지 삭제하고 대화 정리하기

[화면 예시: PDF 61~62쪽](MedBuddy_User_Guide_ko.pdf#page=61)

#### 1. 지울 메시지 선택

채팅 위쪽 휴지통을 눌러 선택 모드를 열고 지울 메시지 왼쪽 체크상자를 누르세요. 사진은 아직 0개 선택인 상태이며, 메시지를 고르기 전에는 삭제 아이콘이 비활성입니다.

1. 선택한 메시지 0개
2. 지울 메시지 선택 칸

#### 2. 선택 후 삭제 열기

체크한 메시지와 위쪽 선택 개수를 확인하고 휴지통을 누르세요. 곧바로 지워지지 않고 삭제 범위를 고르는 확인 창이 열립니다.

1. 선택한 메시지 1개
2. 현재 선택한 메시지
3. 삭제 범위 선택 창

#### 3. 삭제 범위 확인

내가 보낸 지 24시간 이내인 메시지의 ‘모두에게서 삭제’를 선택하고 ‘메시지 삭제’를 누르면 양쪽 대화에서 본문이 삭제됩니다. 기본값은 ‘나에게서만 삭제’이며, 그만두려면 ‘취소’를 누르세요.

1. 양쪽 대화의 본문 삭제
2. 선택한 삭제 범위 적용

#### 4. 삭제 안내 확인

원래 본문 대신 ‘삭제된 메시지입니다.’가 남는지 확인하세요. 이미 전달된 알림 미리보기는 회수되지 않으며, 연결된 약과 복용 기록은 지워지지 않습니다.

#### 5. 숨길 항목 선택

삭제 모드에서 숨길 항목 왼쪽의 체크상자를 고르고 휴지통을 누르세요. 사진은 이미 삭제된 메시지의 안내를 골라 삭제 범위를 정하는 예시입니다.

1. 선택된 삭제 안내 항목
2. 선택 항목 삭제 확인

#### 6. 나에게서만 삭제

‘나에게서만 삭제’를 확인하고 ‘메시지 삭제’를 누르면 내 대화에서만 항목이 사라집니다. 상대방 대화는 유지되며 내 화면에 되살리는 버튼은 없습니다. ‘취소’를 누르면 그대로 남습니다.

1. 내 대화에서만 삭제
2. 선택 항목 숨기기 실행

#### 7. 내 화면의 삭제 결과

지운 안내가 사라지고 다른 대화는 남아 있는지 확인하세요. 예시에서는 ‘삭제된 메시지입니다.’ 안내만 사라지고 아침 복약 확인 요청은 그대로 남아 있습니다.

#### 8. 대화 목록으로 돌아가기

대화 화면 왼쪽 위 뒤로가기를 누르면 채팅 목록으로 돌아갑니다. 목록에서 환자 이름과 최근 메시지를 다시 확인하세요.

**참고**

메시지 선택 모드에는 ‘전체 선택’이 없습니다. 왼쪽 위 X로 선택을 취소할 수 있습니다. 메시지 가운데가 아니라 왼쪽 체크상자를 눌러 고르세요. 기본 선택은 ‘나에게서만 삭제’이므로 범위를 확인하세요. 이미 전달된 알림 미리보기는 회수되지 않으며, 메시지를 지워도 연결된 약이나 복용 기록은 지워지지 않습니다. 삭제한 항목을 내 대화에 되살리는 버튼은 없습니다. 모두에게서 삭제할 수 없는 항목은 이 창에 ‘나에게서만 삭제’만 표시됩니다. ‘실시간 연결됨’은 연결 상태이고 상대가 읽었다는 뜻은 아닙니다. 읽음 확인이 오면 내가 보낸 메시지에 ‘읽음’이 붙으며, 대화를 다시 불러와도 확인된 읽음 표시는 유지됩니다. 약 선택·상세 화면이나 다른 앱을 보는 동안에는 새 메시지가 읽음 처리되지 않습니다. 표시가 없다고 곧바로 미전달로 단정하지 마세요.

### 5.7 보호자 복약 알림 설정하기

[화면 예시: PDF 63~65쪽](MedBuddy_User_Guide_ko.pdf#page=63)

#### 1. 시간대의 종 아이콘

‘환경설정 → 복약 및 알림’에서 보호자 알림을 켜고 저장한 뒤 휴대전화 알림도 허용하세요. 환자 상세 일정에서 원하는 시간대의 종을 누르면 보호자 알림 설정 창이 열립니다. 카드의 알림은 보호자용입니다.

#### 2. 알림 방식 선택

‘끄기’, ‘복용 확인 즉시 알림’, ‘정해진 시각까지 미복용 시 알림’ 중 하나를 고르세요. 즉시 알림은 해당 시간대의 모든 약이 완료로 기록될 때 알리는 방식이며 실제 복용을 검증하지 않습니다.

#### 3. 확인 시각 열기

‘정해진 시각까지 미복용 시 알림’을 고르고 ‘확인 시각’을 누르면 시·분 선택 창이 열립니다. 이 시각은 보호자의 확인 기준이며 환자의 복약 알림 시각과 다르게 정할 수 있습니다.

1. 미완료 기록 확인 알림
2. 보호자의 확인 기준 시각

#### 4. 시각 확인

시와 분을 맞추고 오른쪽 위 체크 아이콘을 누르면 선택한 시각으로 원래 설정 창에 돌아갑니다. 아직 저장된 것은 아니므로 마지막에 ‘저장하기’를 눌러야 합니다.

1. 확인할 시·분 선택
2. 시각 선택 후 설정 창으로

#### 5. 저장하기

원래 설정 창에서 시간대·알림 방식·확인 시각을 살펴보고 ‘저장하기’를 누르세요. 저장되면 창이 닫히고 환자 일정으로 돌아갑니다. 환자의 복약 알림 시각은 바뀌지 않습니다.

1. 저장할 알림 확인 시각
2. 보호자 알림 설정 저장

#### 6. 저장 안내 확인

아래쪽 저장 안내와 시간대 카드의 알림 표시를 확인하세요. 설정에 따라 ‘미복용 알림’과 시각, ‘복용 완료 시 알림’, ‘보호자 알림 꺼짐’으로 표시됩니다. 다른 시간대는 따로 설정하세요.

1. 미복용 알림 21:00
2. 아침 알림 설정 저장 완료

#### 7. 10분 후 다시 알림

보호자 계정에서 Android 알림 목록의 MedBuddy 미복용 알림을 펼치세요. 아래 두 버튼이 있는 알림에서 ‘10분 후 다시 알림’을 누르면 앱으로 돌아가 재알림을 요청하며 복용 기록은 바꾸지 않습니다.

#### 8. 재알림 접수 확인

화면 아래 ‘재알림을 접수했습니다. 10분 후 미복약 여부를 다시 확인합니다.’를 확인하세요. 요청 접수 안내일 뿐이며, 그 사이 완료 기록·연결·알림 설정이 바뀌면 재알림이 없을 수 있습니다.

#### 9. 채팅으로 알림

Android의 미복용 알림을 펼쳐 ‘채팅으로 알림’을 누르면 작성 창 없이 환자의 대화에 확인 요청을 보냅니다. ‘10분 후 다시 알림’과는 별개 동작이며 환자의 복용 완료 기록은 바뀌지 않습니다.

#### 10. 전송 안내 확인

화면 아래 ‘복약 일정 확인 요청을 보냈습니다.’가 나타나는지 확인하세요. 전송 안내만으로 환자가 요청을 읽었거나 약을 복용했다고 판단하지 마세요.

#### 11. 환자 대화에서 요청 확인

환자 계정에서 보호자와의 대화를 열어 새 요청을 확인하세요. 예시에는 아침 일정 카드와 ‘아침 복약 일정을 확인해 주세요.’가 05:34에 표시됩니다. 실제 복용을 확인한 화면은 아닙니다.

**참고**

이 설정은 보호자가 받는 알림입니다. 환자 자신의 복약 알림 시각이나 완료 기록을 바꾸지 않습니다. 아침·점심·저녁·취침 전은 시간대 구분이며, 보호자 알림 시각이 환자의 복용 시각을 뜻하지는 않습니다. X 또는 뒤로가기로 닫으면 변경을 저장하지 않습니다. 설정창은 ‘테스트 환자 2’의 별도 촬영 예시입니다. 설정할 환자의 이름을 확인하세요. 시간 선택창에서 확인한 것만으로 알림 설정이 저장되지는 않습니다. 마지막으로 원래 창의 ‘저장하기’까지 눌러야 합니다. ‘미복용’은 아직 완료로 기록되지 않았다는 뜻입니다. 저장하지 못했다는 안내가 나오면 연결을 확인하고 같은 시간대의 종 아이콘을 다시 열어 설정값을 확인하세요. ‘알림 설정 확인 필요’나 ‘알림 시각 확인 필요’는 환자 복용 시각이 아닙니다. 저장 안내 사진은 ‘환자 TEST’의 별도 예시입니다. 앞 설정창의 환자와 다릅니다. 이 안내는 요청이 접수되었다는 뜻이며, 10분 뒤 재알림이 이미 표시되었다는 뜻은 아닙니다. 그 사이 완료 기록이나 연결·알림 설정이 바뀌면 다시 알림이 나타나지 않을 수 있습니다. 확인 요청은 환자의 약을 복용 완료로 체크하지 않습니다. 전송 안내나 환자 대화에 표시된 사진만으로 실제 환자가 메시지를 읽었거나 약을 복용했다고 판단하지 마세요.

### 5.8 알림함 확인하고 정리하기

[화면 예시: PDF 66~69쪽](MedBuddy_User_Guide_ko.pdf#page=66)

#### 1. 알림함 열기

홈 오른쪽 위 종 아이콘을 누르면 이 기기에 기록된 알림함이 열립니다. 안 읽은 알림이 있으면 아이콘 옆에 개수가 표시됩니다.

#### 2. 내용과 시각 읽기

목록에서 환자 이름·알림 내용·날짜와 시각을 읽으세요. 아직 열지 않은 알림은 ‘안 읽음’으로 구분됩니다.

#### 3. 알림 내용 누르기

알림 본문을 누르면 해당 항목이 읽음으로 바뀌고 환자 상세 일정이 열립니다. 알림을 읽는 것만으로 복용 완료가 기록되거나 채팅 답장이 전송되지는 않습니다.

#### 4. 돌아와 읽음 확인

뒤로가기로 알림함에 돌아와 읽음 상태를 확인하세요. 방금 연 첫 알림의 ‘안 읽음’은 사라지고, 아직 열지 않은 다음 알림에는 그대로 남아 있습니다.

1. 읽음 처리된 첫 알림
2. 아직 읽지 않은 알림

#### 5. 모두 읽음 누르기

오른쪽 위 겹친 체크 모양 ‘모두 읽음’을 누르면 현재 알림 목록을 한 번에 읽음 처리합니다. 알림 자체가 지워지는 것은 아닙니다.

#### 6. 읽음 처리 결과

목록과 위쪽 아이콘을 살펴보세요. ‘안 읽음’ 표시가 사라지고 ‘모두 읽음’ 아이콘이 회색으로 바뀌면 읽음 처리가 반영된 상태입니다.

1. 회색으로 바뀐 모두 읽음
2. 안 읽음 표시만 제거

#### 7. 더보기에서 삭제

지울 알림 오른쪽 점 세 개를 누른 뒤 ‘삭제’를 누르면 삭제 확인 창이 열립니다. 이 단계에서는 아직 알림이 지워지지 않습니다.

#### 8. 삭제 범위 확인

확인 창의 ‘채팅 내용과 복약 기록은 삭제되지 않아요.’를 읽으세요. 이 기능은 해당 알림만 지우며, 지우지 않으려면 ‘취소’를 눌러 목록에 남길 수 있습니다.

1. 채팅·복약 기록 유지
2. 알림을 남기고 취소
3. 알림 한 건 삭제 실행

#### 9. 삭제 확정

지울 알림의 내용과 날짜를 확인하고 확인 창에서 ‘삭제’를 누르면 해당 알림 한 건이 지워집니다. 되살리는 버튼은 없으며 관련 채팅과 복약 기록은 그대로 유지됩니다.

#### 10. 목록에서 결과 확인

지운 항목이 목록에서 사라졌는지 확인하세요. 예시에서는 00:13 알림이 없어지고 00:09 알림이 맨 위에 표시됩니다.

#### 11. 선택 모드 확인

알림함 오른쪽 위 ‘알림 선택’으로 선택 모드를 열고 원하는 체크박스나 ‘전체 선택’을 누르세요. 사진은 선택 전이라 삭제 버튼이 비활성이며, 선택만으로 알림이 삭제되지는 않습니다.

1. 모든 알림 선택·해제
2. 선택 전 비활성 버튼

#### 12. 전체 선택 결과 확인

위쪽 선택 개수와 아래쪽 삭제 버튼의 개수가 같은지 확인하세요. 예시에서는 19개가 선택되어 ‘알림 19개 삭제’ 버튼이 활성화됩니다.

1. 선택한 알림 총 19개
2. 19개 삭제 확인 창

#### 13. 확인창에서 취소

알림 선택 후 아래 삭제 버튼을 누르면 확인 창이 열립니다. 지우지 않으려면 ‘취소’를 누르세요. 알림은 지워지지 않고 이전에 선택한 상태로 돌아갑니다.

#### 14. 선택 모드 끝내기

선택 화면 왼쪽 위 X 모양 ‘선택 취소’를 누르면 체크박스가 사라지고 일반 알림 목록으로 돌아갑니다.

**참고**

알림함은 다른 기기의 모든 알림을 모으는 보관함이 아닙니다. 최근 90일 중 최대 500개를 보여 줍니다. 받은 알림이 없으면 ‘아직 알림이 없어요’가 표시됩니다. 알림을 읽는 것은 복용 완료를 기록하거나 채팅 답장을 보내는 동작이 아닙니다. 오래된 연결의 알림이 열리지 않으면 현재 연결과 로그인 계정을 확인하세요. 알림이 지워지는 것은 아닙니다. 변경 실패 안내가 나오면 목록 상태를 확인한 뒤 다시 시도하세요. 취소하면 같은 알림이 목록에 남습니다. 알림함에는 읽음·미읽음으로 따로 거르는 필터가 없습니다. 삭제한 알림을 되살리는 버튼은 없습니다. 관련 채팅과 복약 기록은 그대로 유지됩니다. 전체 선택을 다시 누르면 선택을 해제할 수 있습니다. 선택만으로 알림이 삭제되지는 않습니다. 여러 개를 실제로 지우려면 확인창에서 ‘삭제’를 누릅니다. 목록을 불러오지 못하면 ‘다시 시도’를 누르고, 최신 목록은 아래로 당겨 확인하세요.

## 6 위젯 사용하기

### 6.1 내 복약 위젯 추가하고 사용하기

[화면 예시: PDF 70~74쪽](MedBuddy_User_Guide_ko.pdf#page=70)

#### 1. 앱에서 추가 요청

‘환경설정 → 복약 및 알림’에서 ‘홈 화면 복약 위젯 추가’를 누르면 Android의 위젯 추가 창이 열립니다. 기기나 홈 화면 앱에 따라 모양과 버튼 문구가 다를 수 있습니다.

#### 2. 홈 화면 추가 확정

추가 창에서 ‘홈 화면에 추가’를 누르세요. 사진의 ‘Add to home screen’이 추가 버튼이며 ‘Cancel’은 취소합니다. 미리보기의 내용 대신 실제 일정은 추가한 뒤 표시됩니다.

#### 3. 추가된 복약 위젯

홈 화면에 추가된 위젯에서 날짜·진행률과 현재 시간대의 약·기록 버튼을 확인하세요. 예시의 진행률은 0/5입니다. 공간이 부족해 추가하지 못했다면 홈 화면에 빈자리를 먼저 확보하세요.

#### 4. 시간대 선택

위젯의 화살표나 점을 누르면 선택된 점·시간대와 해당 약의 미복용·완료 기록이 표시됩니다. 사진은 아침 두 건을 완료로 기록한 2/5 예시이며, 점을 누르는 동작은 복용 기록을 바꾸지 않습니다.

#### 5. 다른 시간대의 약 확인

선택한 시간대의 약과 기록 상태를 확인하세요. 예시의 점심은 미복용으로 표시되며 전체 진행률은 2/5입니다. 약이 있는 시간대만 표시되고 작은 위젯은 목록 일부가 생략될 수 있습니다.

#### 6. 시간대 전체 기록

현재 시간대의 약을 실제로 모두 복용했다면 ‘복용했어요’를 누르세요. 예시는 아침 두 건을 기기에 기록해 2/5가 된 뒤 서버로 전송합니다. 다음 미완료 시간대인 점심으로 바뀌므로 이름을 다시 확인하세요.

#### 7. 같은 아침 기록 취소

잘못 남긴 아침 기록을 취소하려면 아침 시간대로 돌아와 ‘복용 취소’를 누르세요. 완료한 시간대는 버튼이 ‘복용 취소’로 바뀌며, 사진은 취소 전 아침 두 건이 완료로 기록된 2/5 상태입니다.

#### 8. 취소 기록과 전송 상태

취소한 뒤 미복용 표시와 줄어든 진행률을 확인하세요. 예시는 아침 두 건의 기록을 취소해 0/5가 되었으며, 기기에는 저장됐지만 서버 전송은 1건 대기 중입니다.

1. 취소 후 진행률 0/5
2. 다시 미복용으로 표시
3. 기기 저장·전송 1건 대기

#### 9. 기기에 남은 대기 기록

‘기기 저장 완료 · 전송 대기 1건’이 보이면 아직 서버에 보내지 못한 기록이 있다는 뜻입니다. 같은 기록을 다시 입력하지 말고 인터넷 연결을 확인하세요.

#### 10. 서버 저장 완료

연결이 돌아오면 앱에서 전송 대기를 확인하고 위젯으로 돌아오세요. ‘서버 저장 완료’는 이 기기에 전송 대기가 없다는 표시이며 취소 후 0/5는 유지됩니다. 보호자 화면은 별도로 새로고침하세요.

**참고**

위젯만 제거해도 앱의 약과 복용 기록은 삭제되지 않습니다. 위젯을 오래 누르면 홈 화면에서 위치나 크기를 조절할 수 있습니다. 크기에 따라 표시되는 약 목록과 여백은 달라질 수 있습니다. 위젯의 페이지 점은 복용 체크가 아닙니다. 약을 완료로 기록하는 동작은 아래쪽 복용했어요 버튼으로 합니다. 저장 중 표시가 오래 남으면 같은 버튼을 반복해서 누르지 말고 앱을 다시 실행해 기록을 확인하세요. 한 약만 기록하거나 취소하려면 앱의 일정에서 개별 체크하세요.

### 6.2 보호자 위젯에서 환자 일정 보기

[화면 예시: PDF 75~78쪽](MedBuddy_User_Guide_ko.pdf#page=75)

#### 1. 환자 이름 확인

홈 화면에 MedBuddy 복약 위젯을 추가해 환자 일정이 표시되도록 설정한 뒤, 위쪽 이름 양옆 화살표로 환자를 고르세요. 예시는 두 번째 ‘테스트 환자 2’이며 회색 화살표 방향으로는 더 이동할 수 없습니다.

#### 2. 다음 시간대

아침 화면에서 아래쪽 다음 복약 일정 화살표를 누르면 점심 페이지로 바뀝니다. 표시된 시간대와 약 목록을 확인하세요.

1. 선택한 점심 시간대
2. 다음 복약 시간대로

#### 3. 점으로 바로 이동

홈 화면에 추가해 환자 일정이 표시되도록 설정한 MedBuddy 위젯에서 원하는 시간대의 점을 누르세요. 해당 페이지로 바로 바뀌고 점이 진해집니다. 예시처럼 취침 전 약을 확인할 수 있습니다.

1. 취침 전으로 바로 이동
2. 취침 전 약·기록 상태

#### 4. 앞 시간대로 돌아오기

아래쪽 이전 복약 일정 화살표로 저녁에 돌아온 뒤 ‘일정 열기’를 누르세요. 같은 환자의 읽기 전용 상세 일정이 앱에서 열리며, 저녁 위치로 자동 이동하지는 않습니다.

1. 이전 복약 시간대로
2. 같은 환자 상세 일정

#### 5. 앱의 환자 이름 확인

위쪽 이름이 위젯에서 고른 환자와 같은지 확인하고 필요한 시간대까지 직접 내려 보세요. 예시는 테스트 환자 2의 읽기 전용 일정과 진행률 0/4이며, 알림 문구는 보호자가 받는 알림입니다.

1. 위젯에서 선택한 환자
2. 오늘 완료 기록 0/4
3. 읽기 전용 약·보호자 알림

#### 6. 모두 표시일 때

‘환경설정 → 복약 및 알림 → 알림 내용’을 ‘모두 표시’로 저장하고 위젯을 확인하세요. 환자 이름 아래 시간대와 함께 해당 약 이름이 표시됩니다.

#### 7. 종류만 표시일 때

알림 내용을 ‘종류만 표시’로 저장하면 같은 환자의 저녁 약 이름 대신 ‘복용 완료 0개 · 미복용 1개’가 보입니다. 진행률 0/4는 유지되며 환자 이름까지 숨겨지는 것은 아닙니다.

1. 계속 표시되는 환자 이름
2. 약 이름 대신 기록 건수

**참고**

위쪽 화살표는 환자를, 아래쪽 화살표와 점은 시간대를 바꿉니다. 약이 있는 시간대만 페이지로 표시됩니다. 보호자 위젯에는 환자의 ‘복용했어요’나 ‘복용 취소’ 버튼이 없습니다. 위젯에서 고른 시간대로 상세 화면이 자동으로 내려가지는 않습니다. 내용이 오래된 것 같으면 위쪽 새로고침 아이콘을 누르세요. 연결 상태를 확인할 수 없거나 요약이 예상과 다르면 앱의 상세 일정에서 다시 확인합니다.

### 6.3 로그아웃된 위젯에서 다시 로그인하기

[화면 예시: PDF 79쪽](MedBuddy_User_Guide_ko.pdf#page=79)

#### 1. 위젯에서 로그인 열기

로그아웃해 위젯의 복약 일정 대신 ‘로그인이 필요해요’가 보이면 아래 ‘로그인하기’를 누르세요. MedBuddy 로그인 화면이 열리며, 이 버튼으로 복용 기록이 남지는 않습니다.

1. 로그아웃 상태 안내
2. 앱 로그인 화면 열기

#### 2. 같은 계정으로 로그인

사용하던 계정의 이메일과 비밀번호를 입력하고 ‘로그인’을 누르세요. 이메일 인증이 완료된 계정으로 로그인하면 해당 계정의 복약 일정을 다시 볼 수 있습니다.

1. 가입한 계정 이메일
2. 같은 계정의 비밀번호
3. 인증한 계정으로 로그인

**참고**

로그아웃된 위젯에는 복약 진행률과 새로고침 버튼이 표시되지 않습니다. ‘로그인하기’는 앱을 여는 버튼이며 복용을 기록하지 않습니다.

## 7 복약함과 건강 정보

### 7.1 저장한 약 찾아보기

[화면 예시: PDF 80쪽](MedBuddy_User_Guide_ko.pdf#page=80)

#### 1. 복약함 선택

아래 메뉴에서 ‘복약함’을 누르면 저장된 약 목록이 열리고 선택한 메뉴가 초록색으로 표시됩니다.

#### 2. 약 이름 검색

위쪽 검색창에 약 이름의 일부를 입력해 찾으세요. 화면은 ‘Sample’을 입력한 예시입니다.

#### 3. 검색 결과가 없을 때

‘검색한 약이 없습니다.’가 나오면 검색어를 확인하거나 ‘전체 보기’를 눌러 목록을 넓혀 보세요.

1. 검색 결과 없음
2. 전체 목록 보기

**참고**

검색어와 조회 조건에 따라 보이는 약이 달라집니다.

### 7.2 조회 조건과 정렬 바꾸기

[화면 예시: PDF 81~83쪽](MedBuddy_User_Guide_ko.pdf#page=81)

#### 1. 조회 조건 열기

복약함 검색창 아래의 ‘조회 조건’을 누르면 복용 상태·날짜 기준·표시 순서를 고르는 창이 열립니다.

#### 2. 복용 상태 선택

‘복용 상태’에서 복용 중·복용 종료·전체 중 원하는 항목을 고르세요. 화면은 ‘복용 중’이 선택된 예시입니다.

#### 3. 날짜 기준 선택

‘날짜 기준’에서 등록일자순 또는 복용날짜순을 고르세요. 이 예시에서는 ‘복용날짜순’을 선택합니다.

#### 4. 표시 순서 선택

‘표시 순서’에서 최신순 또는 오래된순을 고르세요. 현재 선택된 순서는 초록색으로 표시됩니다.

#### 5. 조건 적용

조회 조건에서 선택값을 확인하고 아래의 ‘적용’을 눌러 목록에 반영하세요. 화면은 ‘복용날짜순’을 선택한 예시입니다.

1. 선택한 날짜 기준
2. 조회 조건 적용

#### 6. 현재 기준 확인

목록 위의 조회 조건에서 ‘복용날짜순·최신순’이 적용되었는지 확인하세요.

#### 7. 날짜 묶음 확인

약이 복용 시작일별로 묶였는지 확인하세요. 예시에서 9월 21일에 시작하는 약은 9월 21일 묶음에 표시됩니다.

1. 복용 시작일 묶음
2. 해당 날짜의 약

#### 8. 전체 보기 누르기

복용 중 목록이 비어 있어도 약이 모두 삭제된 것은 아닙니다. ‘전체 보기’를 눌러 복용 상태에 관계없이 저장된 약을 다시 조회하세요.

1. 복용 중인 약 없음
2. 전체 목록 조회

#### 9. 기간이 지난 약 확인

조회 조건이 ‘전체’인지 보고 각 약의 복용 기간을 확인하세요. 예시는 기간이 지난 약만 남은 경우입니다. 새 약은 ‘약 등록·식별’로 등록하세요.

1. 전체 조회 조건
2. 약의 복용 기간

**참고**

조회 조건은 목록 표시만 바꾸며, 약의 복용 정보를 수정하지 않습니다. 닫기 버튼으로 나가면 아직 적용하지 않은 변경은 반영되지 않습니다. 정렬을 바꾸어도 약의 복용 시작일이나 기간 자체는 바뀌지 않습니다. 검색어가 남아 있거나 조회 조건이 다르면 약이 숨겨질 수 있습니다. 약이 보이지 않는다고 곧바로 다시 등록하지 말고 검색어와 조건을 먼저 확인하세요.

### 7.3 복용이 끝난 약 확인하기

[화면 예시: PDF 84쪽](MedBuddy_User_Guide_ko.pdf#page=84)

#### 1. 복용 종료 적용

조회 조건의 복용 상태를 ‘복용 종료’로 선택하고 ‘적용’을 눌러 기간이 끝난 약을 조회하세요.

1. 복용 종료 선택
2. 선택한 조건 적용

#### 2. 복용 기간 확인

복용 종료 목록에서 약 이름 아래의 복용 기간을 확인하세요. 예시에는 종료 날짜가 지난 약들이 표시됩니다.

1. 복용 종료 조회 조건
2. 지난 복용 기간

**참고**

복용 종료 목록은 기간 기준입니다. 실제로 매번 복용했는지를 보여 주는 기록 화면은 아닙니다.

### 7.4 약 상세정보와 사진 보기

[화면 예시: PDF 85~86쪽](MedBuddy_User_Guide_ko.pdf#page=85)

#### 1. 가이드 열기

복약함에서 확인할 약의 이름이나 옆의 ‘가이드’를 누르면 해당 약의 상세정보가 열립니다.

#### 2. 제품과 효능 안내

상세정보에 표시된 제품 이름과 사진을 확인하고, ‘이 약은 어디가 좋아지나요?’ 아래의 효능 안내를 읽으세요.

1. 조회한 제품 이름
2. 효능 안내 항목

#### 3. 등록 일정과 가이드

화면을 아래로 내려 ‘등록된 복용 정보’의 복용량·횟수·기간을 확인하고, 제품의 일반 안내인 ‘상세 복용 가이드’와 구분해 읽으세요.

1. 내가 등록한 복용 정보
2. 제품의 일반 복용 안내

#### 4. 주의사항 끝까지 읽기

‘주요 주의사항 및 부작용’을 읽으세요. 한 화면보다 길게 이어질 수 있으므로 아래로 더 내려 끝까지 확인하세요.

#### 5. 상세 사진 누르기

제품 사진이 있는 약은 상세정보 위쪽의 사진을 누르면 확인 중인 제품을 크게 볼 수 있습니다.

#### 6. 확대 사진 닫기

확대 화면에서 제품 이름과 사진을 확인한 뒤 왼쪽 위 닫기 버튼을 누르세요.

1. 확대 화면 닫기
2. 확대한 약 사진

**참고**

약마다 제공되는 정보가 다를 수 있습니다. 실제 복용 지시는 처방과 복약지도를 확인하세요. ‘정보 없음’은 해당 안내가 제공되지 않았다는 뜻입니다. 임의로 효능이나 복용법을 채우지 마세요. 사진과 각인은 확인을 돕는 자료입니다. 사진만으로 복용할 약을 확정하지 마세요.

### 7.5 약 안내를 음성으로 듣기

[화면 예시: PDF 87쪽](MedBuddy_User_Guide_ko.pdf#page=87)

#### 1. 음성 안내 시작

복약함의 ‘가이드’로 약 상세정보를 연 뒤, 화면 아래에서 스피커 아이콘이 있는 ‘큰 소리로 읽어주세요’를 눌러 음성 안내를 들으세요.

#### 2. 읽기 중지

음성 안내를 요청하면 버튼이 ‘읽기 중지’로 바뀝니다. 안내를 멈추려면 이 버튼을 누르세요.

**참고**

다시 시작하면 처음부터 읽습니다. 일시정지 후 이어 듣기 버튼은 없습니다.

### 7.6 약 삭제하기

[화면 예시: PDF 88~89쪽](MedBuddy_User_Guide_ko.pdf#page=88)

#### 1. 복약 선택 모드

목록의 약 이름과 현재 조회 조건을 확인하고 오른쪽 위 체크 목록 아이콘을 누르세요. 삭제할 약을 고르는 모드로 바뀝니다.

#### 2. 선택 개수 확인

약별 체크 상자를 누르거나 ‘전체 선택’을 켜고 선택 개수를 확인하세요. 예시는 전체 선택으로 6개를 고른 상태입니다.

#### 3. 선택 삭제 누르기

선택한 약을 다시 확인하고 아래의 ‘선택 삭제’를 누르세요. 삭제 확인 창이 열리며 아직 삭제되지는 않습니다.

#### 4. 삭제 경고 확인

확인 창을 연 상태는 삭제 전입니다. ‘되돌릴 수 없습니다.’ 안내와 대상을 확인하고 맞을 때만 아래의 ‘예’를 눌러 삭제하세요. ‘아니오’는 취소합니다.

1. 되돌릴 수 없는 삭제
2. 예: 삭제 진행

#### 5. 삭제 취소

삭제하지 않으려면 ‘아니오’ 또는 왼쪽 위 닫기 버튼을 눌러 삭제를 취소하세요.

1. 아니오: 삭제 취소
2. 닫아서 취소

#### 6. 묶음 삭제하기

일반 목록에서 삭제할 날짜 묶음의 약을 확인하고 묶음 아래의 ‘삭제하기’를 누르세요. 화면은 약 한 개가 든 묶음의 예시입니다.

#### 7. 최종 확인

묶음 삭제 확인 창에서 대상이 맞으면 ‘예’를 눌러 삭제하고, 취소하려면 ‘아니오’를 누르세요.

1. 예: 묶음 삭제
2. 아니오: 삭제 취소

#### 8. 삭제 결과 확인

‘삭제되었습니다.’ 안내가 나오면 대상이 목록에서 사라졌는지 확인하세요. 예시에서는 ‘SampleTablet’이 삭제되었습니다.

**참고**

전체 선택은 현재 목록의 대상에 적용됩니다. 삭제한 약과 연결된 복용 완료 기록은 되돌릴 수 없습니다. 실제로 삭제할 대상이 맞는 경우에만 ‘예’를 누르세요. 묶음에 여러 약이 있으면 모두 확인하세요. 부분 실패는 성공한 약만 없어질 수 있으므로 남은 목록을 확인해야 합니다.

### 7.7 건강 관리 추천 보기

[화면 예시: PDF 90쪽](MedBuddy_User_Guide_ko.pdf#page=90)

#### 1. 추천 생성 기다리기

홈에서 ‘건강 관리 추천’을 누르세요. ‘추천 생성중’이라는 대기 안내가 표시되면 추천 내용이 나올 때까지 잠시 기다리세요.

#### 2. 식사 추천 확인

추천이 나타나면 첫 항목인 ‘식사 추천’에서 제공하는 식사 안내를 읽으세요.

#### 3. 운동 추천 확인

추천 화면을 아래로 내려 식사 추천 아래의 ‘운동 추천’에서 제공하는 활동 안내를 읽으세요.

#### 4. 주의사항 확인

더 아래로 내려 ‘주의사항’을 모두 읽으세요. 예시는 네 항목이며, 확인을 마치면 왼쪽 위 뒤로가기를 눌러 돌아가세요.

**참고**

추천은 등록된 복용 중인 약을 바탕으로 합니다. 개인의 진료·복약지도를 대신하지 않습니다. 추천 문구는 약 구성과 상황에 따라 달라질 수 있습니다. 화면의 내용은 촬영 당시의 예시입니다.

### 7.8 건강 관리 추천이 나오지 않을 때

[화면 예시: PDF 91쪽](MedBuddy_User_Guide_ko.pdf#page=91)

#### 1. 등록 안내 확인

건강 관리 추천은 현재 복용 중인 약을 기준으로 합니다. ‘현재 복용 중인 약이 없어요’가 보이면 ‘약 등록·식별’을 눌러 처방전 분석·낱알약 식별·직접 등록 메뉴를 여세요.

1. 추천 대상 약 없음
2. 약 등록 시작

#### 2. 등록 방법 고르기

처방전 분석·낱알약 식별·직접 등록 중 필요한 방법을 골라 등록을 마친 뒤 건강 관리 추천을 다시 여세요. 메뉴를 닫기만 하면 약은 등록되지 않습니다.

1. 처방전으로 등록
2. 알약 사진으로 식별
3. 약과 일정 직접 입력

#### 3. 연결 확인 후 재시도

대상 약이 없는 안내와 조회 실패를 구분하세요. 추천을 불러오지 못하면 인터넷 연결을 확인하고 ‘다시 불러오기’를 눌러 현재 계정의 약과 추천 정보를 다시 요청하세요.

1. 추천 조회 실패
2. 다시 불러오기

#### 4. 다시 조회한 결과 확인

오류 대신 정상 안내나 추천이 나타났는지 확인하세요. 예시는 복용 중인 약이 없는 상태입니다. 복용 중인 약이 있고 조회가 정상 완료되면 추천이 표시됩니다.

1. 재조회 후 대상 약 없음
2. 필요한 약 등록

**참고**

앞으로 복용을 시작할 약이나 이미 기간이 끝난 약만 있으면 오늘의 추천 대상이 없을 수 있습니다. 복약함에서 복용 기간을 확인하세요. 이미 약을 등록했다면 다시 불러오기로 최신 정보를 확인할 수 있습니다. 계속 불러오지 못하면 잠시 후 다시 시도하세요. 오류를 해결하려고 기존 약이나 계정을 삭제할 필요는 없습니다.

## 8 근처 약국 찾기

### 8.1 주변 약국 조회하기

[화면 예시: PDF 92쪽](MedBuddy_User_Guide_ko.pdf#page=92)

#### 1. 홈에서 약국 찾기

인터넷과 위치 기능을 켜고 홈의 ‘근처 운영 약국’을 눌러 현재 위치 주변을 조회하세요. 처음 위치 권한을 물으면 ‘사용 중 허용’을 선택하세요. 조회 시점의 정보이므로 방문 전 전화로 확인하세요.

#### 2. 지도와 목록 확인

인터넷·위치를 켜고 지도 표시나 아래 ‘약국 목록 보기’를 누르세요. 지도에 보이지 않는 약국도 목록에서 볼 수 있고 괄호 안 숫자는 조회된 약국 수입니다. 조회 시점의 정보이므로 방문 전 전화로 확인하세요.

#### 3. 원하는 지역으로 이동

지도를 움직인 뒤 ‘이 지역에서 검색’을 누르면 옮긴 지도 중심을 기준으로 다시 조회합니다. 지도를 움직이기만 하면 이전 결과가 남아 있을 수 있습니다.

#### 4. 거리 기준 확인

새 검색 결과와 거리 안내를 확인하세요. 거리는 검색한 지도 중심부터의 거리이며, 안내 문구는 잠시 뒤 사라집니다.

1. 지도 중심 기준 거리
2. 새 검색 결과 목록

**참고**

위치를 가져오지 못하면 휴대전화의 위치 기능과 MedBuddy 위치 권한을 확인한 뒤 다시 조회하세요. 화면 속 약국과 운영시간은 사용 예시이며 현재 영업을 보장하지 않습니다. 십자 모양 위치 버튼은 내 위치로 돌아갈 때 사용합니다. 왼쪽 확대·축소 버튼으로 지도 크기를 바꿀 수 있습니다. 오른쪽 i는 지도 제공자 안내를 엽니다.

### 8.2 조회 조건과 날짜 바꾸기

[화면 예시: PDF 93~94쪽](MedBuddy_User_Guide_ko.pdf#page=93)

#### 1. 조건 열기

지도 위의 ‘조회 조건’을 누르면 현재 영업 중·늦게까지 영업·주말·공휴일 영업·전체 약국 중 하나를 고를 수 있습니다.

#### 2. 조건 고르기

원하는 조건을 누르면 메뉴가 닫히고 지도와 목록에 함께 적용해 다시 조회합니다. 운영시간과 관계없이 찾으려면 ‘전체 약국’을 고르세요.

1. 현재 영업 중 조건
2. 운영시간 무관 조회

#### 3. 주말 조건 선택

‘주말·공휴일 영업’을 선택하세요. 방문일이 오늘이 아니라면 조건과 ‘조회 날짜’를 함께 확인하고 방문 예정 날짜로 바꾸세요.

#### 4. 날짜 항목 열기

목록 위의 ‘조회 날짜’를 누르면 날짜를 고르는 달력이 열립니다. 화면은 9월 26일 토요일을 조회한 예시입니다.

#### 5. 달력에서 날짜 선택

방문할 날짜를 누르고 달력 위쪽에 선택한 날짜가 표시되면 ‘확인’을 눌러 적용하세요. ‘취소’를 누르면 기존 날짜를 유지합니다.

1. 선택한 날짜 표시
2. 방문 날짜 선택
3. 날짜 적용

#### 6. 조회 날짜와 영업 표시 확인

목록의 적용 날짜·시각, 주소와 운영시간을 확인하세요. ‘조회 시각 영업’은 선택한 조회 시각 기준의 자료이며 현재 영업을 보장하지 않습니다.

1. 적용된 날짜와 시각
2. 조회 시각 기준 영업

**참고**

늦게까지 영업에는 공공심야약국과 늦은 시간까지 운영하는 약국이 포함됩니다. 목록에 있는 약국이 모두 지금 열려 있다는 뜻은 아닙니다. 선택한 날짜의 조회 결과와 지금 영업 중인지는 다릅니다. 날짜 옆의 시각과 각 약국의 영업 표시도 함께 보세요. 주말 조건에서 평일을 선택했거나 주변에 자료가 없으면 결과가 없을 수 있습니다. 날짜나 조건을 바꾸거나 다른 지역을 검색하세요.

### 8.3 목록과 상세 정보 보기

[화면 예시: PDF 95~96쪽](MedBuddy_User_Guide_ko.pdf#page=95)

#### 1. 목록 읽기

지도 표시가 겹치거나 이름을 찾기 어려우면 목록을 위아래로 움직여 약국 이름·영업 표시·거리·운영시간·주소를 확인하세요. 약국 이름이 있는 영역을 누르면 지도에서 해당 위치로 이동합니다.

#### 2. 지도에서 선택 위치 확인

지도에 표시된 약국 이름과 위치, 아래 상세정보를 확인하세요. 선택한 약국의 전화·길찾기 버튼도 함께 표시됩니다.

1. 선택한 약국 위치
2. 선택한 약국 상세정보

#### 3. 상세 정보 접기

상세 영역 위의 아래 화살표를 누르면 선택한 약국을 유지하며 지도가 넓어집니다. 운영시간·주소는 접히고 약국 이름·영업 표시·전화·길찾기는 남습니다.

#### 4. 다시 펼치거나 닫기

위 화살표를 눌러 상세정보를 다시 펼치거나 X를 눌러 선택 정보를 닫으세요. 접힌 상태에서도 전화와 길찾기는 사용할 수 있습니다.

1. 상세정보 펼치기
2. 선택 정보 닫기

#### 5. 목록을 아래로 내리기

목록 맨 위 손잡이를 아래로 끌어내리면 목록이 내려가고 지도가 크게 보입니다. 아래의 ‘지도 크게 보기’를 눌러도 같습니다.

1. 아래로 끌어내릴 손잡이
2. 버튼으로 지도 펼치기

#### 6. 검색 결과 유지

‘약국 목록 보기’를 누르면 같은 검색 결과를 다시 볼 수 있습니다. 지도와 목록을 오가도 검색 조건은 초기화되지 않습니다.

**참고**

거리만 보고 방문하지 말고 주소를 확인하세요. 운영 정보 재확인 필요가 표시되면 특히 전화 확인이 필요합니다.

### 8.4 약국 즐겨찾기

[화면 예시: PDF 97쪽](MedBuddy_User_Guide_ko.pdf#page=97)

#### 1. 빈 별 누르기

목록이나 지도 상세정보에서 약국 이름 오른쪽 빈 별을 누르면 색이 채워지고 저장합니다. 불러오기·저장 중에는 별을 누를 수 없습니다. 저장 실패 시 안내가 나오고 이전 상태로 돌아갑니다.

#### 2. 즐겨찾기 표시 확인

저장 후 채워진 별이 유지되는지 확인하세요. 다시 누르면 즐겨찾기가 해제되며, 즐겨찾기 약국도 조회 조건에 맞는 목록 안에서 확인할 수 있습니다.

#### 3. 즐겨찾기 지도 표시

지도에서 황금색 별 표시와 약국 이름을 확인하세요. 같은 약국의 상세정보에도 채워진 별이 표시됩니다.

#### 4. 해제 후 기본 표시

즐겨찾기를 해제한 뒤 같은 약국의 지도 표시가 황금색 별에서 초록색 십자로 바뀌었는지 확인하세요.

**참고**

즐겨찾기는 이 기기에 계정별로 저장되며 다른 휴대전화에 자동으로 같은 목록이 생기지는 않습니다. 불러오지 못했다는 안내가 나오면 약국 화면을 나갔다가 다시 여세요. 저장 실패 후에는 별이 원래 상태로 돌아온 것을 확인하고 다시 시도하세요. 즐겨찾기를 설정하거나 해제하려면 8.4절 ‘약국 즐겨찾기’를 보세요.

### 8.5 전화와 길찾기

[화면 예시: PDF 98~99쪽](MedBuddy_User_Guide_ko.pdf#page=98)

#### 1. 전화 버튼 누르기

표시된 운영시간과 실제 운영은 다를 수 있으니 출발 전에 전화로 확인하세요. 선택한 약국의 ‘전화’를 누르면 해당 번호가 휴대전화의 전화 앱으로 전달됩니다.

#### 2. 전화번호 확인

전화 앱에서 번호를 확인하고 통화 버튼을 직접 눌러 운영 여부를 물어보세요. MedBuddy의 ‘전화’만 눌러서는 확인되지 않으며, 예시는 번호 확인까지만 진행했습니다.

1. 전달된 약국 번호
2. 직접 눌러 통화

#### 3. 길찾기 열기

선택한 약국의 ‘길찾기’를 누르면 설치된 지도 앱 선택·Google 지도·주소 복사 메뉴가 열립니다.

#### 4. 방법 선택

사용할 지도 앱을 고르세요. ‘주소 복사’를 누르면 주소가 복사되고 메뉴가 닫히며, 원하는 지도나 메모 입력칸에 붙여넣을 수 있습니다.

1. 설치된 지도 앱 선택
2. Google 지도로 열기
3. 약국 주소 복사

#### 5. 목적지와 이동 방법 확인

예시는 Google 지도입니다. 약국 이름·주소로 요청된 목적지가 맞는지 확인하고 이동 방법을 고르세요. 언어·화면 구성은 기기마다 다르며 이용 가능한 교통수단·경로는 외부 지도에서 결정합니다.

1. 목적지 약국 확인
2. 대중교통 경로 선택

#### 6. MedBuddy로 돌아오기

휴대전화 뒤로가기로 돌아오면 선택한 약국 정보가 남아 있습니다. 지도 앱 내부 화면이 먼저 닫히면 뒤로가기를 한 번 더 누르세요.

**참고**

통화 요금은 휴대전화 요금제에 따릅니다. 돌아올 때는 휴대전화 뒤로가기를 사용하세요. 전화 앱 내부 화면을 먼저 닫아야 할 수도 있습니다. 휴대전화에 설치된 앱에 따라 선택 화면이 다를 수 있습니다. 지도 앱이 없으면 Google 지도 또는 웹 브라우저를 이용할 수 있습니다. Google 지도는 처음 사용할 때 로그인 또는 위치 권한을 물을 수 있습니다. 외부 지도에서 검색된 목적지 주소가 맞는지 다시 확인하세요.

## 9 환경설정과 계정 관리

### 9.1 설정 저장과 변경 취소하기

[화면 예시: PDF 100~101쪽](MedBuddy_User_Guide_ko.pdf#page=100)

#### 1. 설정 분류 선택

‘내 정보’ → ‘환경설정’에서 ‘복약 및 알림’ 또는 ‘화면 및 음성’을 눌러 원하는 설정을 바꾸세요. 선택만으로는 저장되지 않습니다.

1. 복약 시간과 알림 설정
2. 화면과 음성 설정

#### 2. 설정 저장 완료

설정을 바꾼 뒤 아래의 ‘저장하기’를 누르고 ‘설정이 저장되었습니다.’ 안내가 나오면 저장이 완료된 것입니다.

#### 3. 변경 후 뒤로가기

설정을 바꾼 뒤 위쪽 뒤로가기 화살표를 누르면 ‘변경한 설정을 저장할까요?’ 창이 열립니다. 아직 저장 전입니다.

1. 변경 후 뒤로가기
2. 변경한 시간 표시

#### 4. 저장하고 나가기

확인 창에서 ‘저장’을 누르면 변경한 설정을 저장하고 이전 화면으로 돌아갑니다.

1. 변경 설정 저장 여부
2. 저장하고 나가기

#### 5. 취소하거나 계속 편집

설정 변경 후 위쪽 뒤로가기로 연 창에서 ‘변경 취소’를 누르면 변경을 버리고 마지막 저장값을 유지합니다. 더 고치려면 ‘계속 편집’을 눌러 바꾼 값을 편집 화면에 남기세요.

1. 바꾼 값 계속 편집
2. 변경 버리고 나가기

**참고**

‘계속 편집’은 설정 화면에 남습니다. ‘기기에만 저장했습니다. 서버 연결 후 다시 저장해주세요.’는 연결 후 재저장하세요. 저장 실패 때는 선택값을 확인하고 다시 시도합니다. 설정 전체 초기화 버튼은 없으며 계정 삭제로 대신하면 안 됩니다. 뒤로가기 화살표만 누른 상태에서는 변경값이 아직 저장되지 않았습니다.

### 9.2 글씨크기 바꾸기

[화면 예시: PDF 102쪽](MedBuddy_User_Guide_ko.pdf#page=102)

#### 1. 글씨크기 선택

‘환경설정’ → ‘화면 및 음성’ → ‘글씨크기’에서 작게·중간·크게 중 편한 크기를 누르세요. 설정 화면에 미리 반영되지만 아직 저장 전입니다.

1. 작은 글씨
2. 중간 글씨
3. 큰 글씨

#### 2. 글씨크기 저장

글자가 읽기 편한지 확인하고 ‘저장하기’를 눌러 선택한 크기를 저장하세요. 실제 글씨크기에는 기기 설정도 영향을 줍니다.

**참고**

선택하지 않고 창을 닫으면 기존 크기가 유지됩니다. 큰 글씨를 선택한 후 저장하지 않으려면 뒤로가기의 ‘변경 취소’를 이용하세요.

### 9.3 읽기속도와 음성 미리보기

[화면 예시: PDF 103쪽](MedBuddy_User_Guide_ko.pdf#page=103)

#### 1. 읽기속도 선택

‘환경설정’ → ‘화면 및 음성’에서 ‘읽기속도’를 누르고 느리게·중간·빠르게 중 원하는 속도를 고르세요.

1. 느리게 읽기
2. 중간 속도로 읽기
3. 빠르게 읽기

#### 2. 음성 미리보기

‘음성으로 들어보기’를 누르면 예시 문장을 읽습니다. 멈추려면 ‘듣기 중지’를 누르세요.

#### 3. 읽기속도 저장

원하는 속도를 정한 뒤 ‘저장하기’를 눌러 읽기속도를 저장하세요. 뒤로 나가면 미리보기 재생이 중지됩니다.

**참고**

미리보기 문장은 예시이며 내 처방이 아닙니다. 재생하지 못하면 기기의 음량과 음성 재생 상태를 확인한 뒤 다시 시도하세요. 앱에는 목소리나 음량을 바꾸는 별도 설정이 없습니다.

### 9.4 언어와 시간 표시 바꾸기

[화면 예시: PDF 104쪽](MedBuddy_User_Guide_ko.pdf#page=104)

#### 1. 언어 선택

‘환경설정’ → ‘화면 및 음성’에서 필요한 항목만 바꾸세요. ‘언어’를 누르고 기기 설정 따르기·한국어·English 중 사용할 언어를 고르세요.

1. 기기 언어 따르기
2. 한국어 사용
3. 영어 사용

#### 2. 시간 표시 선택

‘시간 표시’에서 오전/오후 또는 24시간제를 고르세요. 표시 방식만 바뀌고 알림 시각은 바뀌지 않습니다.

1. 오전·오후로 표시
2. 24시간제로 표시

#### 3. 언어와 시간 표시 저장

‘저장하기’를 눌러 선택한 언어와 시간 표시 방식을 저장하세요. 영어 화면에서는 ‘Save’를 누르세요.

**참고**

선택한 언어는 설정 화면에 먼저 반영됩니다. ‘기기 설정 따르기’는 기기 언어가 영어일 때 영어, 그 외에는 한국어를 사용합니다. 로그인·가입·이메일 인증 안내도 선택한 언어로 표시됩니다. 시간 선택 창은 계속 24시간제입니다. 미저장 취소는 ‘변경 취소’ 또는 ‘Discard changes’입니다.

### 9.5 홈에 표시할 일정 선택하기

[화면 예시: PDF 105쪽](MedBuddy_User_Guide_ko.pdf#page=105)

#### 1. 일정 대상 선택

‘환경설정’ → ‘화면 및 음성’ → ‘홈 복약 일정’에서 홈·위젯에 표시할 ‘내 일정’ 또는 ‘연결된 환자’를 고르세요. 환자 연동은 먼저 마쳐야 하며 이 선택으로 새 연동이 생기지는 않습니다.

1. 내 일정 표시
2. 연결된 환자 일정 표시

#### 2. 일정 대상 저장

‘저장하기’를 누른 뒤 홈으로 돌아가 선택한 대상의 일정을 확인하세요. 내 일정은 삭제되지 않으며 나중에 다시 선택할 수 있습니다.

**참고**

‘연결된 환자가 없습니다.’가 나오면 ‘환자 연결’을 이용하거나 ‘내 일정’으로 바꾸세요. 여러 환자는 홈의 이름 옆 화살표로 바꾸고 조회 오류는 새로고침을 이용합니다. 연결된 환자의 위젯은 조회용입니다.

### 9.6 받을 알림 고르기

[화면 예시: PDF 106쪽](MedBuddy_User_Guide_ko.pdf#page=106)

#### 1. 알림 수신 스위치

‘환경설정’ → ‘복약 및 알림’ → ‘알림 수신’에서 내 복약·보호자·채팅 알림 중 받을 알림은 켜고 받지 않을 알림은 각각 끄세요.

1. 내 복용 시간 알림
2. 연결된 환자의 복약 알림
3. 가족의 새 메시지 알림

#### 2. 알림 수신 저장

아래의 ‘저장하기’를 눌러 알림 수신 설정을 저장하세요. 알림을 꺼도 복약 일정은 삭제되지 않습니다.

**참고**

첫 설정 화면에서 켜진 알림 종류 수를 확인할 수 있습니다. 보호자 알림은 전체 수신 여부이며 환자별 조건은 별도로 확인하세요. 알림이 오지 않으면 휴대폰 권한, 등록 일정, 시간대별 알림, 연동 상태를 확인합니다.

### 9.7 기본 복약 시간 바꾸기

[화면 예시: PDF 107~108쪽](MedBuddy_User_Guide_ko.pdf#page=107)

#### 1. 시간대 선택

‘환경설정’ → ‘복약 및 알림’의 ‘기본 복약 시간’에서 바꿀 시간대를 누르세요. 새 일정 등록에 쓸 아침·점심·저녁·취침 전 시각을 각각 정할 수 있습니다.

1. 아침 기본 시각
2. 점심 기본 시각
3. 저녁 기본 시각
4. 취침 전 기본 시각

#### 2. 시간 선택

시·분을 돌려 맞추고 체크 모양 ‘확인’을 누르면 설정 화면에 반영됩니다. X 모양 ‘닫기’를 누르면 이번 변경을 취소합니다.

1. 시·분을 돌려 선택
2. 선택한 시간 반영

#### 3. 기본 시간 저장

‘환경설정’ → ‘복약 및 알림’의 기본 시간은 알림을 따로 저장하지 않은 시간대에 쓰입니다. 다른 시간대도 확인하고 ‘저장하기’를 누르세요. 기존 알림의 시각·켜짐·꺼짐은 유지되며 자동으로 켜지지 않습니다.

#### 4. 숫자 입력 열기

시간을 돌려 고르기 어려우면 창 가운데의 선택된 숫자를 누르세요. 시 숫자는 ‘시간 입력’, 분 숫자는 ‘분 입력’ 창이 열려 직접 입력할 수 있습니다.

1. 선택된 시 눌러 입력
2. 선택된 분 눌러 입력

#### 5. 숫자 적용

시는 0~23, 분은 0~59로 입력하고 ‘적용’을 누르세요. ‘취소’를 누르면 이번 입력을 버립니다.

1. 시 입력: 0~23
2. 입력한 숫자 적용
3. 이번 입력 취소

#### 6. 시간 확인과 최종 저장

체크 모양 ‘확인’을 누른 뒤 설정 화면의 ‘저장하기’까지 눌러야 최종 저장됩니다. 숫자 입력의 ‘적용’과 시간 선택의 ‘확인’만으로는 저장되지 않습니다.

**참고**

기본 시간은 알림을 따로 저장하지 않은 시간대에 사용합니다. 이미 알림을 저장했다면 새 약을 추가해도 기존 시각을 유지합니다. 기존 일정의 알림은 ‘시간대별 세부 설정’을 눌러 ‘오늘의 복약 일정’에서 확인하세요. 이동하기 전에 환경설정 변경을 저장하세요. 처음 표시되는 시각은 개인별 복용 지시가 아닙니다. 화면의 시간 표시를 ‘오전/오후’로 정했더라도 이 입력 창의 시는 0~23으로 입력합니다. 숫자는 최대 두 자리까지 입력할 수 있습니다.

### 9.8 알림 내용 공개 범위 정하기

[화면 예시: PDF 109쪽](MedBuddy_User_Guide_ko.pdf#page=109)

#### 1. 알림 내용 공개 범위

‘환경설정’ → ‘복약 및 알림’에서 아래로 내려 ‘알림 내용’을 누르세요. ‘약 이름과 메시지 모두 표시’ 또는 ‘알림 종류만 표시’를 골라 약 이름·채팅 내용을 보여 줄지 정하세요.

1. 약 이름과 메시지 공개
2. 알림 종류만 공개

#### 2. 공개 범위 저장

선택 창이 닫히면 ‘저장하기’를 누르세요. 저장한 공개 범위는 위젯의 약 이름 표시에도 적용됩니다.

**참고**

‘알림 종류만 표시’일 때 위젯은 약 이름 대신 복용 완료·미복용 개수를 보여 줍니다. 표시 이름·개수·상태를 전부 숨기지는 않습니다. 잠금 화면의 노출 방식은 휴대폰 설정도 확인하세요. 기존 알림이 모두 즉시 바뀌는 것은 아닙니다.

### 9.9 휴대폰 알림 설정과 위젯 추가 열기

[화면 예시: PDF 110쪽](MedBuddy_User_Guide_ko.pdf#page=110)

#### 1. 휴대폰 알림 설정 열기

Android의 MedBuddy에서 ‘환경설정’ → ‘복약 및 알림’ 아래쪽 ‘휴대폰 알림 설정’을 누르면 휴대전화의 MedBuddy 알림 권한 화면이 열립니다.

#### 2. 휴대폰에서 알림 허용

‘All MedBuddy notifications’ 스위치를 켜 알림을 허용한 뒤 뒤로가기로 앱에 돌아오세요. 항목 이름은 기기에 따라 다를 수 있습니다.

1. MedBuddy 전체 알림
2. 알림 허용 스위치

#### 3. 위젯 추가 열기

Android의 MedBuddy에서 ‘환경설정’ → ‘복약 및 알림’ 아래쪽 ‘홈 화면 복약 위젯 추가’를 누르세요. 휴대전화의 추가 안내를 마친 뒤 홈 화면에 위젯이 생겼는지 확인하세요.

**참고**

항목 이름은 휴대폰마다 다를 수 있으며 앱의 저장만으로 휴대폰 권한이 허용되지는 않습니다. 설정을 열지 못하면 휴대폰 설정 앱을 이용하세요. 위젯 자동 추가가 안 되면 홈 화면의 위젯 목록에서 MedBuddy를 찾습니다. 추가 창의 취소는 위젯을 추가하지 않습니다.

### 9.10 로그아웃하기

[화면 예시: PDF 111~112쪽](MedBuddy_User_Guide_ko.pdf#page=111)

#### 1. 일반 계정 로그아웃

‘내 정보’ → ‘환경설정’ → ‘계정’에서 현재 계정을 확인하고 ‘로그아웃’을 누르세요. 일반 계정은 별도 확인 창 없이 바로 로그아웃됩니다.

1. 현재 로그인 계정
2. 바로 로그아웃

#### 2. 로그아웃 완료

로그인 화면으로 돌아왔는지 확인하세요. 다시 이용하려면 같은 계정으로 로그인하세요.

1. 돌아온 로그인 화면
2. 같은 계정으로 로그인

#### 3. 게스트 상태 확인

게스트는 로그아웃 시 데이터가 영구 삭제됩니다. ‘내 정보’ → ‘환경설정’ → ‘계정’에서 게스트 상태를 확인하고 ‘로그아웃’을 눌러 삭제 확인 창을 여세요.

1. 게스트 계정 상태
2. 삭제 확인 창 열기

#### 4. 삭제 여부 선택

자료를 유지하려면 ‘취소’, 지우고 로그아웃하려면 ‘삭제’를 누르세요. 삭제한 복약정보·일정·연동·설정은 되돌릴 수 없습니다.

1. 게스트 삭제 후 로그아웃
2. 데이터 영구 삭제 안내
3. 취소하여 자료 유지
4. 삭제하고 로그아웃

#### 5. 로그아웃 완료

게스트 로그아웃으로 영구 삭제한 자료는 복구할 수 없습니다. 로그인 화면으로 돌아왔는지 확인하세요. 다시 ‘회원가입 없이 계속하기’로 게스트를 시작하면 새 계정이 만들어집니다.

1. 이메일 로그인 버튼
2. 새 게스트 계정 시작

**참고**

일반 로그아웃은 계정 데이터 삭제와 다릅니다. 실패 안내가 나오면 연결 상태를 확인하고 다시 시도하세요. 홈 화면의 위젯도 로그인 안내로 바뀝니다. 위젯에서 다시 로그인하는 방법은 6.3절을 참고하세요. 사진은 로그아웃 후 표시되는 로그인 화면의 구성 예시입니다.

### 9.11 계정 데이터 삭제하기

[화면 예시: PDF 113쪽](MedBuddy_User_Guide_ko.pdf#page=113)

#### 1. 삭제 확인 창 열기

‘내 정보’ → ‘환경설정’ → ‘계정’에서 ‘계정 데이터 삭제’를 눌러 삭제 범위를 읽으세요. 되돌릴 수 없는 작업이지만 확인 창을 여는 것만으로 삭제되지는 않습니다.

#### 2. 영구 삭제 또는 취소

삭제 범위를 읽고 지우려면 ‘삭제’, 유지하려면 ‘취소’를 누르세요. 영구 삭제한 자료는 복구할 수 없습니다.

1. 계정 데이터 삭제 확인
2. 영구 삭제·복구 불가
3. 취소하여 자료 유지
4. 계정 데이터 삭제

#### 3. 계정 삭제 완료

삭제 후 로그인 화면으로 돌아왔는지 확인하세요. 삭제한 계정과 데이터는 복구할 수 없습니다.

1. 작업 후 로그인 화면
2. 로그인 버튼 위치

**참고**

복약정보·일정·보호자 연동·설정과 MedBuddy 로그인 계정이 삭제됩니다. 보안상 다시 로그인하라는 안내가 나오면 로그아웃 후 다시 로그인하여 진행하세요. Google 계정 자체를 삭제하는 기능은 아닙니다. 마지막 사진은 작업 후 표시되는 로그인 화면의 구성 예시입니다.

## 10 문제 해결

### 10.1 로그인 입력과 연결 오류 확인하기

[화면 예시: PDF 114~115쪽](MedBuddy_User_Guide_ko.pdf#page=114)

#### 1. 가입 정보 확인

잘못 입력한 칸의 안내를 읽고 이메일 형식과 6자 이상의 비밀번호를 확인하세요. 입력을 고친 뒤 ‘회원가입’을 다시 누르세요.

1. 이메일 형식 안내
2. 비밀번호 6자 이상
3. 고친 정보로 회원가입

#### 2. 로그인 다시 시도

‘이메일 또는 비밀번호가 올바르지 않습니다.’가 나오면 입력을 고쳐 ‘로그인’을 다시 누르세요. 비밀번호가 기억나지 않으면 ‘비밀번호 찾기’를 이용하세요.

1. 로그인 입력 오류
2. 로그인 다시 시도
3. 비밀번호 찾기

#### 3. 연결 오류 확인

로그인 후 서버 연결이 실패하면 계정을 새로 만들지 말고 인터넷 연결을 확인한 뒤 잠시 기다리세요. 연결이 복구되면 자동으로 홈이 열릴 수 있습니다.

#### 4. 필요하면 다시 연결

자동 재시도 중에는 ‘보안 세션 다시 연결’ 버튼이 잠시 비활성화될 수 있습니다. 버튼이 활성화되면 눌러 다시 연결하세요.

#### 5. 연결 복구 확인

연결이 복구되어 홈으로 돌아왔는지 확인하세요. 계정을 새로 만들거나 앱 데이터를 지울 필요는 없습니다.

**참고**

가입 폼의 빨간 안내를 먼저 확인하세요. 로그인에 실패했다면 비밀번호를 새로 설정할 수 있습니다. 일시 연결 실패와 이메일 미인증은 다른 상태입니다. 계정이나 앱 데이터를 지워 복구하지 마세요.

### 10.2 처방전 촬영과 분석 문제 해결하기

[화면 예시: PDF 116쪽](MedBuddy_User_Guide_ko.pdf#page=116)

#### 1. 오류 내용 확인

‘분석 실패’ 화면의 실제 오류 안내를 먼저 읽으세요. 예시는 서버가 일시적으로 응답하지 않아 잠시 후 다시 시도하라는 안내입니다.

#### 2. 다시 시도할 방법 선택

오류 화면 아래에서 새 사진은 ‘다른 사진 촬영하기’, 저장된 사진은 ‘이미지 다시 선택하기’를 누르세요. 그만하려면 ‘홈으로 돌아가기’를 누르세요.

1. 새 사진 촬영
2. 저장된 사진 다시 선택
3. 홈으로 돌아가기

**참고**

이 화면은 서버가 일시적으로 응답하지 않은 예시입니다. 사진 불량이 원인이라고 단정하지 마세요.

### 10.3 알약 후보가 없거나 분석에 실패했을 때

[화면 예시: PDF 117쪽](MedBuddy_User_Guide_ko.pdf#page=117)

#### 1. 해당 알약 다시 확인

후보가 없을 때 ‘이 알약 다시 비교’가 보이면 누르세요. 번호가 남은 결과를 확신하기 어렵다면 ‘영역 다시 분석’을 이용하세요. 사진은 재분석 버튼 위치를 보여 주는 참고 화면입니다.

#### 2. 사진 재분석 또는 변경

전체 분석 실패 시 ‘이 사진 다시 분석’이 보이면 누르세요. 사진이 흐리거나 읽히지 않으면 ‘사진 변경’으로 바꾸세요. 사진은 변경 버튼 위치를 보여 줍니다.

**참고**

사진은 재분석·사진 변경 버튼의 위치를 보여 주는 관련 화면이며 오류 화면은 아닙니다. 반복 실패 시 연결을 확인하고, 확인되지 않은 후보는 저장하지 마세요.

### 10.4 알림이 오지 않을 때

[화면 예시: PDF 118쪽](MedBuddy_User_Guide_ko.pdf#page=118)

#### 1. 받을 알림 켜기

일정이 보여도 알림 준비가 끝난 것은 아닙니다. 환경설정의 ‘복약 및 알림’에서 내 복약·보호자·채팅 알림 중 필요한 항목을 각각 켜고 저장하세요. 일정 화면의 시간대별 알림도 켜졌는지 확인하세요.

1. 내 복약 알림 수신
2. 보호자 알림 수신
3. 채팅 알림 수신

#### 2. 휴대전화 권한 확인

‘휴대폰 알림 설정’에서 MedBuddy 알림이 허용됐는지 확인하세요. 항목 이름·위치는 기기마다 다르며 잠금 화면·방해 금지·배터리 제한도 알림 표시에 영향을 줄 수 있습니다.

**참고**

보호자 알림은 환자와 연결된 상태에서 받습니다. 알림이 없더라도 앱의 환자 일정에서 기록을 직접 확인할 수 있습니다. 알림만으로 실제 복용 여부를 단정하지 마세요.

### 10.5 기록이나 위젯이 늦게 바뀔 때

[화면 예시: PDF 119쪽](MedBuddy_User_Guide_ko.pdf#page=119)

#### 1. 대기 기록 확인

완료를 반복해 누르지 말고 전송 대기 안내를 눌러 기기에만 저장된 기록을 확인하세요. 인터넷 연결을 복구한 뒤 오른쪽 ‘다시 전송’을 누르세요. 같은 기록을 다시 입력할 필요는 없습니다.

1. 기기에 저장된 대기 기록
2. 연결 복구 후 다시 전송

#### 2. 위젯 새로고침

보호자는 환자 이름부터 확인하세요. 위젯을 새로고침해 ‘서버 저장 완료’가 나오는지 보고, 변화가 없으면 앱에서 같은 계정의 일정과 전송 대기를 확인하세요.

1. 위젯 새로고침
2. 서버 저장 완료 상태

**참고**

전송 대기가 남아 있을 때 앱 삭제나 데이터 초기화로 해결하려고 하지 마세요. 기기에만 있는 기록을 잃을 수 있습니다. 날짜가 바뀌어도 이전 날짜 기록을 오늘 복용으로 다시 입력하지 마세요.

### 10.6 약국 결과가 없거나 다시 확인할 때

[화면 예시: PDF 120쪽](MedBuddy_User_Guide_ko.pdf#page=120)

#### 1. 결과 없음 확인

결과가 없어도 주변 약국의 폐업을 뜻하지 않습니다. 조건·날짜·시각을 확인하고 바꿔 재조회하세요. 날짜가 잘리면 위 조건 줄을 왼쪽으로 미세요. 예시는 주말·공휴일 조건에 2026-09-22(화) 12:00을 적용했습니다.

1. 현재 조회 조건
2. 조건에 맞는 약국 없음
3. 조회된 약국 0개

#### 2. 다시 조회한 목록 확인

결과가 없어도 주변 약국의 폐업을 뜻하지 않습니다. 지도나 조건을 바꿔 재검색한 뒤 목록에서 최근 조회 시각을 확인하세요. 필요하면 오른쪽 위 새로고침을 누르고, 결과가 있어도 방문 전 전화로 확인하세요.

1. 약국 목록 새로고침
2. 최근 조회·방문 전 전화
3. 재조회된 약국 정보

**참고**

지도나 목록을 불러오지 못하면 인터넷 연결을 확인하고 다시 시도하세요. 전화번호나 길찾기를 열 수 없을 때는 주소 복사로 다른 지도 앱에서 찾아볼 수 있습니다.
