# MedBuddy 사용설명서

환자와 보호자를 위한 Android 앱 사용 안내입니다. 약 등록과 복약 기록부터 환자·보호자 연결, 가족 채팅, 위젯, 병원·약국 찾기와 환경설정까지 이용 순서대로 설명합니다.

앱 버전: 1.0.0 개발 브랜치 (2026-11-07 기준)

본문은 84개 절·327개 단계로 구성되어 있습니다. 기존 321단계에 직접 입력의 약 검색 3단계, 채팅 검색약 첨부 2단계, 채팅에서 기록 공유 시작 1단계를 추가했습니다.

[캡처가 포함된 사용설명서 PDF](MedBuddy_User_Guide_ko.pdf)

본문은 GitHub에서 바로 읽을 수 있습니다. 각 소섹션의 PDF 링크에서 화면을 확인하고 단계 번호 순서대로 진행하세요. 사진 안의 빨간 번호는 단계 아래 번호 목록과 대응합니다.

PDF 오른쪽 아래에는 현재 소섹션 번호와 제목이 표시됩니다. 참고는 각 대섹션 끝에 모았으며, 소섹션 번호·페이지·사진 번호 링크를 누르면 관련 화면으로 이동합니다. 사진 번호는 본문의 단계 번호입니다.

**안내:** 설명서의 약과 용량은 조작 예시입니다. 실제 복용은 처방과 복약지도에 따르세요. 완료 표시는 사용자가 남긴 기록입니다.

**화면 출처:** 2026-11-07에 보완한 화면은 현재 앱 위젯을 가상 자료·모의 응답으로 실행한 캡처입니다. 실제 서버 저장·AI 분석·알림 수신의 증거가 아닙니다. 재사용한 앱·에뮬레이터 캡처와 휴대폰 설정 화면의 출처·예시는 해당 절의 참고에 구분했습니다. Android 알림의 직접 완료 버튼은 코드로 확인했으며 별도 실기기 캡처는 포함하지 않았습니다. 표시된 약·날짜·횟수는 조작 예시이지 권장 복용법이 아닙니다.

**2026-11-07 반영:** 여러 약 직접 등록·일수 간격, 독립 약 검색과 미등록 검색약 채팅 첨부, 채팅에서 기록 공유, 환자의 확인 요청 알림 직접 완료, 빈 일정 재조회 중 로딩을 반영했습니다. 개발 작업본 설명이며 출시·배포 완료를 뜻하지 않습니다.

### 1.3 가입하고 이메일 인증하기

[소섹션: PDF 9쪽](MedBuddy_User_Guide_ko.pdf#page=9)

<a id="manual_page_10"></a>

[화면 예시: PDF 10쪽](MedBuddy_User_Guide_ko.pdf#page=10)

#### 1. 회원가입 열기

‘MedBuddy가 처음이신가요? 회원가입’을 누르세요. 환자와 보호자는 같은 절차로 각자 가입하며 가입 중 역할을 고르지 않습니다.

#### 2. 가입 정보 입력

사용할 이메일과 6자 이상의 비밀번호를 입력하고 ‘회원가입’을 누르세요. 입력 오류 안내가 있으면 먼저 고칩니다. 환자와 보호자는 각자 다른 계정으로 가입합니다.

#### 3. 받는 주소와 인증 메일 확인

화면에 표시된 이메일 주소의 메일함에서 인증 메일을 여세요. 메일이 없으면 주소·스팸함을 확인한 뒤 ‘인증 메일 다시 보내기’를 누릅니다.

#### 4. 인증 후 앱으로 돌아오기

인증 메일의 링크를 누른 뒤 앱으로 돌아오세요. 인증이 확인되면 홈으로 이동합니다. 화면에 머물면 다음 단계에서 상태를 다시 확인하세요.

<a id="manual_page_11"></a>

[화면 예시: PDF 11쪽](MedBuddy_User_Guide_ko.pdf#page=11)

#### 5. 인증 상태 다시 확인

메일 인증을 마쳤는데 자동으로 넘어가지 않으면 ‘인증 상태 다시 확인’을 누르세요. 다른 계정을 쓰려면 왼쪽 위 뒤로가기로 로그인 화면에 돌아갑니다.

#### 6. 인증한 계정으로 시작

로그인 후 홈이 열립니다. 처음에는 일정이 없을 수 있으므로 ‘약 등록·관리 → 약 등록’에서 본인 약을 등록하세요.

### 1.4 다른 방법으로 시작하기

[소섹션: PDF 12쪽](MedBuddy_User_Guide_ko.pdf#page=12)

<a id="manual_page_13"></a>

[화면 예시: PDF 13쪽](MedBuddy_User_Guide_ko.pdf#page=13)

#### 1. Google 로그인 시작

인터넷 연결을 확인하고 로그인 화면의 ‘Google로 계속하기’를 누르세요. MedBuddy의 이메일 로그인 칸에는 Google 비밀번호를 입력하지 마세요.

#### 2. Google 계정 선택과 인증

Google 안내에서 계정을 선택하고 인증하세요. 취소하면 로그인되지 않습니다. 오류가 나면 연결을 확인해 다시 시도하세요. 사진은 MedBuddy의 진입 버튼입니다.

#### 3. 게스트 시작

로그인 화면에서 ‘회원가입 없이 계속하기’를 눌러 게스트 이용 안내를 여세요.

#### 4. 게스트 이용 전 확인

임시 계정의 제한을 읽고 ‘계속’을 누르세요. 취소하면 로그인 화면에 남습니다. 게스트 자료를 다른 계정으로 자동 이전하는 절차는 제공되지 않습니다.

<a id="manual_page_14"></a>

[화면 예시: PDF 14쪽](MedBuddy_User_Guide_ko.pdf#page=14)

#### 5. 게스트 계정 확인

환경설정 → 계정에서 게스트 계정으로 사용 중인지 확인하세요. 게스트 로그아웃은 자료를 삭제하므로 계속 사용할 정보가 있으면 주의하세요.

### 1.5 비밀번호 다시 설정하기

[소섹션: PDF 15쪽](MedBuddy_User_Guide_ko.pdf#page=15)

<a id="manual_page_16"></a>

[화면 예시: PDF 16쪽](MedBuddy_User_Guide_ko.pdf#page=16)

#### 1. 재설정 메일 요청

이메일·비밀번호로 가입한 계정의 이메일을 입력하고 ‘비밀번호 찾기’를 누르세요. 현재 비밀번호는 필요 없지만 해당 메일함을 열 수 있어야 합니다.

#### 2. 재설정 안내 확인

화면 아래 발송 안내를 확인한 뒤 메일함의 재설정 링크를 여세요. 앱 안에 별도 재설정 페이지는 없습니다. 시연 사진은 실제 메일 발송 결과가 아닙니다.

#### 3. 새 비밀번호로 로그인

기능 찾기는 입력한 말을 기기 안의 메뉴 이름·동의어와 비교하며 검색어를 저장하거나 외부 AI로 보내지 않습니다. 한국어 화면의 ‘send records’도 복약 기록 공유로 이동합니다. 반면 별도의 ‘약 검색’은 인터넷으로 제품 정보를 조회합니다. 결과 없음과 조회 실패를 구분하고, 검색 중 안내가 나오면 기다렸다가 다시 요청하세요. 제품 정보는 복용 지시나 의료 상담이 아니며 한 후보만 나와도 이름·함량·제형·제조사를 확인해야 합니다.

이 절의 보완 화면은 현재 기능 찾기와 약 검색 위젯을 가상 자료로 실행한 예시입니다. 검색 결과는 실제 제품 조회 성공이나 약 저장 사례가 아닙니다. 약 검색 결과 화면으로 바뀐 3번 사진과 기능 찾기 화면을 구분하세요.

### 2.2 인식한 내용을 확인하고 수정하기

<a id="manual_page_27"></a>

#### 1. 분석 진행 기다리기

사진을 가져오면 인식과 약품 조회가 이어집니다. 단계·조회 개수를 확인하며 기다리세요. 끝나면 조회 결과가 열리고, 뒤로가기는 분석을 멈추고 처음으로 돌아갑니다.

#### 2. 조회 결과 요약 확인

고정 요약에서 확인됨·후보 확인 필요·찾지 못함·조회 실패 수를 보세요. 약명 보정이나 OCR 제외 안내가 있으면 원본과 대조해 누락된 약을 확인합니다.

번호별 약 카드의 이름·상태·1회량·기간·시작일·시간대를 대조하세요. 화살표로 접고 펼치며 ‘매일 아님’·‘복용 일정 확인 필요’ 표시도 확인합니다. 아직 저장 전입니다.

#### 4. 원본 사진 확인

원본 사진을 눌러 확대하세요. 초록색 인식 영역과 회색 마스킹 영역을 확인하고, 민감한 정보가 남아 있지 않은지도 확인합니다.

#### 5. 복용 정보 수정

값이나 연필을 눌러 이름·조제일자·1회량·유형·횟수·기간을 원본과 대조하세요. 정기/필요시도 확인합니다. 복용 시간대와 복용하는 날은 다른 설정입니다.

#### 6. 매일이 아닌 복용 지시 확인

#### 7. 조제일자 달력 선택

2. 수정창으로 확인

#### 8. 수정 내용 적용 또는 취소

값·시간대·복용일을 확인하고 ‘적용’을 누르세요. 바뀐 약은 ‘미확인 약 다시 조회’로 확인합니다. 취소는 변경을 버리며 적용만으로 저장되지 않습니다.

### 2.3 미확인 약과 후보 확인하기

#### 1. 확인이 필요한 약 찾기

#### 2. 미확인 약 다시 조회

#### 4. 이름·함량·제형 대조

원본과 후보의 전체 이름·함량·제형·제조사를 대조하세요. 선택해야 ‘이 약으로 확인’이 켜집니다. 후보가 하나여도 확실하지 않으면 취소하세요.

2. 후보의 전체 이름과 제조사

1. 고른 후보
2. 이 약으로 확인

미확인 약을 제외하려면 ‘확인된 약만으로 계속’을 누르세요. 확인창에서 제외 대상을 대조한 뒤 계속합니다. 필요한 약을 확인 없이 제외하지 마세요.

한 약만 저장하려면 해당 카드의 이름·일정을 확인하고 화살표 왼쪽 저장 아이콘을 누르세요. 카드를 펼치지 않아도 저장할 수 있습니다.

### 2.6 약 정보 직접 입력하기

#### 1. 약 이름과 수량 입력

‘약 등록·관리 → 약 등록 → 직접 등록’의 ‘약 1’에 이름·1회량을 입력하세요. 이름 옆 돋보기로 제품을 골라도 복용법은 처방·복약 안내대로 확인합니다.

#### 2. 복용량 단위 선택

해당 약 상자의 ‘알약 사진’ 옆 추가 아이콘을 누르세요. 사진은 선택 사항이며 직접 붙인 사진은 이 기기의 앱 내부에만 저장됩니다.

#### 4. 복용 기간 지정

약별 시작일·종료일과 총 기간을 확인하세요. 다른 약은 아래 ‘약 추가’로 별도 상자에 입력합니다. 최대 10개이며, 여러 상자일 때 불필요한 미저장 상자는 X로 지웁니다.

#### 5. 종료 날짜 선택

시작일 또는 종료일의 달력에서 날짜를 고르고 ‘확인’을 누르세요. 종료일은 시작일보다 앞설 수 없으며 ‘취소’는 이번 선택을 버립니다.

#### 6. 복용 기간 재확인

각 약의 기간과 복용 유형을 확인하세요. 정해진 일정이면 ‘정기 복용’, 처방에서 필요할 때만 복용하도록 안내한 약이면 ‘필요시 복용’을 고릅니다.

#### 7. 복용 주기 선택

매일·격일·주 1회·월 1회 또는 기타를 고르세요. 기타는 1~90일 간격으로 시작일부터 반복합니다. 월 1회는 30일 간격이므로 처방과 대조하세요.

#### 8. 복용 시간대 선택

아침·점심·저녁·취침 전 중 처방에 맞는 시간대를 모두 고르세요. 비매일 약은 복용일에만 일정이 생깁니다. 필요시 복용에는 정기 주기·시간대를 설정하지 않습니다.

각 약의 이름·1회량·기간·유형·주기·시간대를 대조하고 저장을 누르세요. 여러 약은 ‘전체 복약 정보 저장’입니다. 일부 실패 시 완료·미완료를 구분합니다.

#### 10. 빠진 약 이름 입력

오류가 표시된 상자의 이름·수량·간격·시간대를 고치세요. 일부만 저장됐다면 ‘저장 완료’ 상자는 유지하고 남은 약을 다시 저장합니다. 화면을 나갔다면 복약함부터 확인하세요.

#### 11. 약 이름 검색 열기

저장 전에 해당 약 상자의 이름 옆 돋보기를 누르세요. ‘약 검색’에서 약 이름을 입력하고 검색 버튼이나 키보드 검색을 누릅니다.

#### 12. 검색 결과에서 제품 확인

검색 결과의 전체 이름·함량·제형·제조사를 가지고 있는 약과 대조하고 제품을 누르세요. 결과가 없으면 이름을 바꿔 다시 검색합니다.

### 2.8 알약마다 앞뒷면 사진 넣기

모든 앞면을 준비하고 ‘알약 N개 후보 찾기’를 누르세요. 결과의 후보를 각각 확인합니다. 사진 추가·분석 완료만으로 저장되지는 않습니다.

#### 4. 제품 정보를 비교

전체 이름·제조사·각인을 비교하세요. 숫자나 이름이 비슷하다는 이유만으로 고르지 마세요. 이 목록은 식별 후보이며 복용할 약의 추천이 아닙니다.

#### 6. 사진 출처 선택

사진 선택창에서 ‘카메라로 촬영’ 또는 ‘갤러리에서 선택’을 고르세요. 앞면·뒷면 중 어느 사진칸에서 열었는지 확인하고 해당 면의 사진을 넣습니다.

### 2.10 선택한 알약 저장하기

각 약의 시작일·1회량·횟수·주기·기간·시간대를 다시 읽고 필요하면 연필로 고치세요. 임시 기본값은 복용 지시가 아니므로 확인 없이 저장하지 마세요.

모든 정보가 처방·복약 안내와 일치할 때만 ‘확인하고 저장하기’를 누르세요. 처리 결과의 저장·기존 정보·실패 항목을 확인하고, 복약함에서 등록 내용을 다시 확인합니다.

처리 후 ‘저장 완료’ 표시와 복약함의 약·일정을 확인하세요. 시연 사진은 실제 AI 식별이나 서버 저장 성공을 증명하지 않습니다.

저장한 약은 홈의 약 등록·관리 → 약 관리에서 찾을 수 있습니다. 검색어·복용 상태·날짜 기준 때문에 약이 숨겨질 수 있으므로 목록 조건도 확인하세요. 등록된 복용 정보는 제품의 일반 복용 안내와 구분해 읽으세요. 빈 입력폼과 목록은 각각 조작 위치의 예시이며 같은 약을 연속 등록한 결과를 뜻하지 않습니다. 직접 등록에서는 약마다 매일·격일·주 1회·월 1회 또는 기타의 1~90일 간격을 고릅니다. 시작일·종료일의 총 기간과 실제 복용하는 날은 다르므로 저장 전에 주기를 대조하세요. 월 1회는 30일 간격입니다. 목록의 선택지로 처방의 실제 지시를 표현할 수 없다면 임의로 가까운 주기를 고르지 마세요. 저장된 약이 오늘 일정에 없으면 복약함에서 다음 복용일과 복용 기간을 먼저 확인합니다. 필요시 복용은 정기 복약 일정·미복약 알림에서 제외됩니다. 복용 판단과 간격·최대량은 처방·복약지도에 따르며, 앱이 복용을 권하거나 정하지 않습니다. 필요시 약의 새 복용은 일정 아래쪽 필요시 복용의 동그라미로 기록하고, 이미 남긴 기록의 정정은 복약 기록에서 합니다. 직접 등록은 여러 약 상자에 각각 입력하지만 처방 교체는 한 약의 변경입니다. 이름·수량·단위·기간·복용 유형·주기·시간대는 공통으로 확인합니다. 처방 교체에는 직접 등록의 약 추가·제품 검색·기기 사진 추가·기타 간격 입력이 없습니다.

약 이름 옆 돋보기로 검색해 제품 확인창의 ‘선택’을 누르면 해당 상자에 이름과 제품 정보가 연결됩니다. 용량·기간·주기·시간대는 직접 확인해야 하며 제품 선택만으로 저장되지 않습니다. 선택 후 이름을 바꾸면 그 제품 연결은 해제됩니다. 약 검색 결과가 없어도 이름으로 직접 입력할 수 있지만, 정보 조회 실패를 제품 일치나 안전성 확인으로 받아들이지 마세요.

사진만으로 복용량과 기간을 알 수 없습니다. 임시 기본값을 처방전·약 봉투와 대조해 수정하세요. 여러 사진에서 같은 제품을 고르면 중복 처리 안내가 나타날 수 있습니다. 별도로 유지하거나 같은 일정만 묶는 방식을 검토하며, 복용량·날짜·기간이 다르면 별도로 유지됩니다. 이 선택만으로 저장되지는 않습니다. 저장 후 성공·기존 정보·실패 항목을 확인하고 복약함에서 등록 내용을 확인하세요. 알약 사진만으로 복용하는 날도 알 수 없습니다. 수정창의 복용 주기를 처방·복약 안내에 맞게 고르세요. 주기와 별개로 복용하는 날의 횟수·시간대를 정하고, 총 기간 안의 복용일 수를 확인합니다. 월 1회는 30일 간격입니다. 복용 유형도 처방·복약 안내와 대조하세요. 필요시 복용은 정기 주기·시간대 대신 별도로 기록합니다. 검토·수정창 사진은 현재 제품 화면을 네트워크가 차단된 가상 자료 환경에서 연 예시이며, 실제 AI 식별이나 서버 저장 완료 화면이 아닙니다.

**[2.11 - 54페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=54)**

이 기능은 처방에서 필요할 때 복용하도록 안내한 약을 기록하는 용도입니다. 앱은 복용 여부·간격·최대량을 판단하지 않습니다. 사진은 미저장 입력폼이며 실제 복용이나 등록 완료를 뜻하지 않습니다.

### 3.10 복약 기록을 채팅 또는 다른 앱으로 공유하기

#### 1. 공유 열기

복약 기록 위쪽 공유 아이콘 또는 채팅 ‘+ → 복약 기록 공유’를 누르세요. 공유 창에서 조회 화면과 별도로 기간을 정합니다. 채팅에서 열면 현재 관계의 환자 기록이 대상입니다.

#### 2. 시작일과 종료일 각각 선택

최근 90일 중 시작·종료일을 고르세요. 다른 앱은 최대 90일, 채팅은 31일입니다. 넘으면 채팅 버튼만 꺼집니다. 건강정보 안내를 읽고 공유 방법을 고릅니다.

1. 공유 기간과 최대 일수
2. 채팅 또는 다른 앱 선택

#### 3. 앱 안의 채팅으로 공유

‘채팅으로 공유’에서 기간·상대를 확인한 뒤 ‘전송’을 누르세요. 채팅에서 시작하면 현재 대화만 대상으로 표시됩니다. 창을 열거나 상대를 고르기만 해서는 전송되지 않습니다.

#### 4. 공유한 카드의 건수 확인

카드는 공유 당시 기간과 정기 복용함·건너뜀·미기록, 필요시 건수를 보여 줍니다. 정정·삭제해도 카드 요약은 바뀌지 않으며 최신 기록은 따로 엽니다.

#### 5. 같은 기간의 최신 기록 보기

‘최신 기록 보기’를 누르면 같은 기간의 현재 기록을 읽기 전용으로 엽니다. 본인도 이 화면에서는 수정하지 못합니다. 연동 해제나 최근 90일 범위 초과 시 조회가 제한됩니다.

#### 6. 다른 앱에 글로 공유

‘다른 방법으로 공유’는 기록을 날짜별 글로 보내며 파일은 첨부하지 않습니다. Android 공유창에서 받을 앱·상대를 확인하세요. 창 열기는 전송 완료가 아닙니다.

#### 7. 보호자도 기간과 상대 확인

보호자도 읽기 전용 기록을 공유할 수 있습니다. 환자·기간·상대를 확인하세요. 앱 채팅은 그 환자와 본인이 참여하는 관계만 선택하며, 다른 앱의 사본 이용까지 제한하지는 못합니다.

#### 8. 채팅의 더하기 메뉴에서 공유

현재 채팅에서 ‘+ → 복약 기록 공유’를 누르세요. 대상은 이 관계의 환자와 현재 대화입니다. 2~4단계처럼 기간·상대를 확인한 뒤 전송하세요.

채팅에는 선택 기간의 요약과 최신 기록을 여는 카드가 전송되며 기록 글이나 파일이 첨부되는 것은 아닙니다. 다른 앱으로 보내는 글에는 약 이름·복용 시각·건너뛴 이유 등 건강정보가 들어갑니다. 내부 계정 식별값을 제외해도 익명 자료가 되는 것은 아닙니다. 상대방과 보관 위치를 확인하세요. 외부에 저장한 사본은 MedBuddy에서 회수할 수 없습니다. 공유창을 지원하지 않는 기기에서는 별도 확인을 받은 경우에만 같은 글을 클립보드에 복사합니다. 복사한 내용은 다른 앱이 읽을 수 있습니다. 공유 창 사진은 전송 전 화면이며, 연락처가 보이는 Android 공유창은 싣지 않았습니다. 채팅 전송 결과를 확인하지 못했다면 연결·연동 상태를 확인하고 같은 창의 ‘다시 전송’을 이용하세요. 같은 기간·상대에 대한 미확인 전송은 중복 메시지가 생기지 않도록 재시도합니다. 창을 닫거나 앱을 재시작한 뒤에는 새 전송 전에 채팅에 이미 카드가 있는지 확인하세요.

채팅의 +에서 시작하면 현재 대화의 환자 기록과 상대가 고정됩니다. 보호자가 자기 기록이나 다른 환자의 기록을 그 대화로 바꾸어 보내는 기능이 아닙니다. 기록 조회와 전송 시 현재 계정·연동 권한을 다시 확인하며 해제된 관계는 공유할 수 없습니다. 채팅 전송을 마치면 대화로 돌아옵니다.

다른 앱 공유 글에는 기간·상태별 건수·날짜와 시간대·약 이름·복용 시각·건너뛴 이유·자가 기록 안내·한국 시간 기준이 포함됩니다. 기록이 너무 많다는 안내이면 기간을 줄이세요. 공유 기간 변경은 원래 조회 화면을 바꾸지 않으며 취소해도 기록은 유지됩니다.

### 참고

**[5.1 - 101페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=101)**

채팅 목록의 숫자는 대화별 안 읽은 메시지 수입니다. 대화를 열어 최신 메시지를 읽으면 갱신됩니다. 목록만 보는 것은 메시지를 읽는 동작이 아닙니다. 내가 보낸 말풍선 옆 1은 상대가 아직 읽지 않았다는 뜻이며 읽으면 사라지고 시각은 남습니다. 실시간 연결됨은 읽음 확인이 아니며 알림함의 읽음 상태와도 별개입니다. 이전 대화 보기로 과거 내용을 확인할 수 있습니다. 과거 내용을 읽는 중에는 새 메시지가 와도 읽던 위치가 유지됩니다. 채팅 알림으로 다시 열면 최신 위치로 이동할 수 있습니다. 상대가 연동을 해제한 대화는 연동이 종료되었다는 안내로 바뀌고 입력을 사용할 수 없습니다. 예전 알림으로 열어도 같은 연동의 대화를 계속할 수 없으며, 제공되는 연동 관리로 이동해 상태를 확인하세요. 단순 연결 끊김 안내와 구분합니다. 일반 채팅의 묶인 알림은 상대·안 읽은 수와 최근 메시지 최대 3줄을 보여 줍니다. 직접 완료를 지원하는 복약 확인 요청은 메시지별 알림으로 따로 표시될 수 있습니다. 환경설정의 알림 내용을 ‘알림 종류만 표시’로 정했다면 상대 이름과 메시지 대신 ‘새 가족 메시지’와 안 읽은 수만 나옵니다. 알림을 지워도 메시지는 남으며, 대화에서 읽으면 같은 대화의 알림이 정리됩니다.

**[5.2 - 103페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=103)**

등록 약은 ‘대화할 약 선택’에서 원이나 전체 선택으로 고릅니다. 선택만으로 전송·복용 기록이 되지는 않으며 등록 약 카드의 이름·화살표는 상세를 엽니다. X는 첨부를 해제합니다.

등록 약이 없어도 ‘약 검색’으로 제품을 확인·선택할 수 있습니다. ‘검색약 · 미등록’은 이름·제조사·제공되는 사진을 담은 참고 정보이며 내 약으로 저장되거나 일정·알림·복용 기록을 만들지 않습니다. 참고 카드에는 복용 기록·상세 열기 동작이 없습니다. 일반 메시지는 등록 약과 검색약을 합해 최대 10개이며, 글을 입력하고 보내기까지 눌러야 전송됩니다. 검색약이 하나라도 첨부되면 빠른 답장이 숨겨집니다.

환자는 지원되는 Android의 오늘 복약 확인 요청 알림에서 ‘복용 완료’를 눌러 해당 시간대의 정기 약을 함께 완료로 기록할 수 있습니다. 약·날짜·시간대를 확인하고 실제로 모두 복용했을 때만 사용하세요. 일부만 복용했다면 알림 본문으로 대화를 열고 일정에서 개별 기록합니다. 이 버튼은 보호자 대신 기록하기나 필요시 복용 횟수 추가가 아닙니다.

알림 본문은 대화만 열며 기록을 바꾸지 않습니다. 로그아웃·계정 전환·지난 날짜·일정 확인 불가 상태에서는 완료가 처리되지 않을 수 있습니다. 기기에 기록돼도 서버 전송 대기일 수 있으므로 앱에서 기록·전송 상태를 확인하고 중복 입력하지 마세요. 연동 해제나 일정 변경으로 전송이 거절되면 확인이 필요합니다. 버튼이 없으면 대화·일정에서 확인하세요. 이 네이티브 버튼의 실기기 캡처는 현재 설명서에 포함하지 않았습니다.

‘검색약 · 미등록’이 있으면 먼저 해당 참고 첨부를 제거해야 등록 약의 빠른 답장을 쓸 수 있습니다. 여러 시간대 중 일부만 처리되거나 전송 대기가 남았다면 각 상태를 확인하세요. 기기 저장만으로 보호자에게 즉시 확인 메시지가 전달된다고 보장하지 않습니다.

**[5.5 - 109페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=109)**

약이 부족해요를 누르면 부족 메시지를 보냅니다. 장소 검색은 메시지의 찾기 버튼이나 대화 입력칸 왼쪽의 + 버튼에서 여세요. 병원·약국을 대화에서 찾은 경우 상세의 채팅에 공유를 통해 장소 공유 확인창을 엽니다. 받는 사람·장소·첨부 약·날짜를 확인하고 메시지 보내기로 전송합니다. 홈에서 연 검색에는 공유 버튼이 없을 수 있습니다. 공유 카드의 운영 상태는 보낸 시점 정보이며 예약이나 현재 운영을 보장하지 않습니다. 카드를 다시 열면 받는 사람 위치 기준으로 다시 조회하므로 거리와 운영 정보가 보낸 사람 화면과 다를 수 있습니다. 방문 전 전화로 확인하세요. 약국에 전화 확인 항목이 보이더라도 실제 통화해 운영 여부를 확인한 경우에만 체크하세요. 병원에는 이 체크 항목이 없습니다. 공유 카드의 전화·길찾기는 전화 앱이나 외부 지도를 여는 기능입니다. 검색·공유 취소는 이미 보낸 부족·불편함 메시지를 회수하지 않습니다.

**[5.6 - 112페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=112)**

휴지통으로 선택 모드를 연 뒤 메시지 자체나 체크상자를 눌러 고릅니다. 전체 선택은 없으며 최대 50개를 선택할 수 있습니다. 기본값인 나에게서만 삭제는 상대 기록을 유지합니다. 모두에게서 삭제하려면 선택한 메시지가 모두 본인이 보낸 지 24시간이 지나지 않았고 삭제되지 않은 상태여야 합니다. 이미 전달된 알림 미리보기는 회수되지 않으며 약·복용 기록도 삭제되지 않습니다. 지운 메시지의 복구 버튼은 없습니다. 모두에게서 삭제한 자리에는 ‘삭제된 메시지입니다.’가 남습니다. 선택을 취소하려면 왼쪽 위 X를 누르세요. 복사한 메시지는 다른 앱이 클립보드에서 읽을 수 있으므로 건강정보가 담긴 글은 필요할 때만 복사하세요. 메시지 화면 사진은 에뮬레이터와 테스트 기기의 테스트 대화입니다.

<a id="manual_page_120"></a>

**[5.7 - 114페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=114)**

정해진 시각까지 미복용 시 알림을 선택하면 확인 시각을 정할 수 있습니다. 시·분을 확인한 뒤 원래 설정창에서 저장하기를 눌러야 합니다. 이 시각은 보호자의 확인 기준이며 환자의 복약 알림 시각을 바꾸지 않습니다. 미복용 알림의 10분 후 다시 알림은 요청 접수 후 조건이 유지될 때 다시 알려주는 기능입니다. 채팅으로 알림은 환자에게 확인 요청을 보낼 뿐 복용을 대신 완료하지 않습니다. 미복용 확인 시각은 설정창에 표시된 복약 알림 기준 시각보다 이르게 고를 수 없습니다. 보호자가 환자의 변경된 시각을 받지 못한 경우에는 시간대의 기본 시각이 기준으로 보일 수 있습니다. 실제 알림 전송에는 환자의 복약 알림 이후 최소 30분의 유예와 설정한 확인 시각이 함께 적용됩니다. 비매일 약은 복용하는 날에만 확인하며, 다시 알림 전에 모두 완료되면 보내지 않을 수 있습니다. 이 절의 미복용 확인 시각과 다시 알림은 정기 복용에만 해당합니다. 필요시 복용은 정해진 복용 시각이 없으므로 보호자에게 미복용 마감·반복 경고를 제공하지 않습니다. 환자의 확인 알림과 보호자의 완료 알림은 서로 독립된 설정입니다.

**[5.8 - 116페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=116)**

모두 읽음은 알림의 읽음 상태만 바꾸며 목록을 삭제하지 않습니다. 알림 오른쪽 점 세 개에서 삭제를 선택하거나 알림 선택 모드에서 여러 건을 고를 수 있습니다. 전체 선택 후 표시된 개수와 대상을 확인하세요. 삭제 확인에서 취소하면 그대로 남고, 삭제하면 알림만 지워집니다. 채팅과 복용 기록은 유지됩니다. 선택 화면의 X로 선택 모드를 끝낼 수 있습니다. 최신 알림은 목록을 아래로 당겨 확인하세요. 읽음·미읽음 전용 필터는 없습니다. 모두 읽음이 비활성화됐거나 안 읽음 표시가 없어졌는지 확인하되 대화의 읽음 상태와 구분하세요.

내 복약 일정에 연결되는 정형 알림은 현재 앱 언어로 표시합니다. 채팅은 원문을 유지하고 보호자 알림의 저장된 상세는 이전 언어로 남을 수 있습니다. 휴대폰 알림의 ‘복용 완료’와 앱 알림함의 ‘모두 읽음’은 다릅니다. 직접 완료의 조건·주의사항은 5.3 참고를 확인하세요.

날짜 묶음 삭제도 대상 확인 후 진행하세요. 삭제한 약과 연결된 복용 기록은 되돌릴 수 없습니다. 취소하면 약은 남습니다. 처리 후 목록을 다시 확인하고, 일부만 실패한 경우 남은 약을 확인한 뒤 진행하세요. 선택 모드에서 휴대폰의 뒤로가기를 누르면 약을 삭제하지 않고 선택 모드만 끝납니다. 일반 복약함에서 다시 뒤로가기를 누르면 홈으로 돌아갑니다. 선택 모드에서는 체크상자뿐 아니라 약 행을 눌러 선택할 수 있습니다. 삭제 확인 창은 선택한 약 개수와 복용 기록도 함께 삭제된다는 안내를 보여 주며, 왼쪽이 취소, 오른쪽이 삭제입니다. 삭제는 실행 취소할 수 없으므로 개수와 대상을 확인하세요. 약 복용만 중단하고 이전 기록을 보관하려면 삭제 대신 약 관리의 처방에 따른 복용 중단을 확인하세요. 처방 변경 없이 임의로 약을 중단하지 마세요.

**[7.7 - 145페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=145)**

추천은 등록된 복용 중인 약을 바탕으로 합니다. 개인의 진료·복약지도를 대신하지 않습니다. 서버에 약품 설명이 없는 약은 AI가 임의로 추천 근거로 사용하지 않으며 주의 안내에 이름이 표시될 수 있습니다. 추천에서 빠졌다고 복용을 중단하거나 안전한 약이라고 판단하지 마세요. 무료 Gemini 환경에서는 실제 환자의 복약 정보로 건강 추천을 요청하지 마세요. 무료 API의 개인정보·민감정보 전송 제한은 동의 문구나 계정 해시만으로 해결되지 않습니다. 데이터 이용 안내에서 처리 범위를 확인하세요.

**[7.7 - 145페이지 - 2~4번 사진](MedBuddy_User_Guide_ko.pdf#page=145)**

화면의 추천은 해당 계정의 예시입니다. 개인별 진료나 복약지도를 대신하는 안내로 받아들이지 마세요.

**[7.8 - 147페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=147)**

건강 관리 추천은 현재 복용 중인 약을 기준으로 합니다. 대상 약이 없다는 안내이면 화면의 ‘약 등록·식별’ 또는 홈의 약 등록·관리 → 약 등록을 이용하세요. 등록 뒤 ‘다시 불러오기’로 확인합니다. 조회 실패는 대상 없음과 다른 상태입니다. 연결을 확인하고 다시 불러오기를 이용하세요. 계속 실패하면 잠시 후 다시 시도하며 기존 약이나 계정을 삭제하지 마세요.

**[7.9 - 149페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=149)**

변경은 처방·복약지도에 따라 입력하며 앱이 치료 변경을 권하는 것은 아닙니다. 적용일은 과거로 선택할 수 없고, 이미 기록된 날짜의 수정·교체는 더 이후 날짜가 필요할 수 있습니다. 미래 날짜의 변경은 적용일 전까지 이전 일정을 유지합니다. 이전 약의 복용 기록은 그대로 남습니다. 통신 실패로 ‘같은 내용으로 다시 시도’가 나오면 연결을 확인하고 보관된 변경 요청을 그대로 재시도하세요. 그동안 입력은 잠길 수 있습니다. 다른 곳에서 수정됨·권한 없음·약을 찾을 수 없음 안내이면 목록으로 돌아가 현재 상태를 확인합니다.

처방 교체는 한 약만 바꾸는 화면입니다. 직접 등록의 여러 약 상자·약 추가·제품 검색·사진 추가·기타 간격 입력과는 다릅니다. 선택지로 지시를 표현할 수 없다면 임의로 가까운 주기로 바꾸지 마세요.

<a id="manual_page_155"></a>

**[7.10 - 152페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=152)**

의료진·약사의 지시에 따른 중단을 기록하는 기능입니다. 스스로 약을 끊도록 권하는 기능이 아닙니다. 기존 복용 기록은 유지하고 적용일부터 해당 약을 이후 일정·알림에서 제외합니다. 과거 기록을 없애려는 용도로 사용하지 마세요. 사진은 확인창까지만 연 예시이며 중단을 실제 적용하지 않았습니다.

중단 요청도 통신 실패 시 ‘같은 내용으로 다시 시도’를 이용합니다. 결과가 불확실한 채 새로운 중단 요청을 반복하지 마세요. 목록 재확인이 필요한 오류와 구분합니다(7.9 참고).

### 8.1 병원과 약국 선택하기

[소섹션: PDF 156쪽](MedBuddy_User_Guide_ko.pdf#page=156)

<a id="manual_page_157"></a>

[화면 예시: PDF 157쪽](MedBuddy_User_Guide_ko.pdf#page=157)

#### 1. 홈에서 검색 열기

홈의 ‘근처 운영 병원·약국’을 누르세요. 찾을 곳을 고르는 창이 열립니다. 인터넷 연결과 위치 권한·위치 기능도 확인하세요.

#### 2. 찾을 곳 선택

‘근처 병원’은 병원·의원, ‘근처 약국’은 약국을 찾습니다. 위치 권한 요청이 나오면 현재 위치 사용 여부를 선택하세요.

#### 3. 진료과목 먼저 선택

병원은 지도를 열기 전에 진료과목을 먼저 고릅니다. 원하는 과목이나 ‘전체’를 누르세요. 선택 전에는 병원 조회를 시작하지 않습니다.

#### 4. 약국 지도 확인

약국 지도 표시나 ‘약국 목록 보기’를 눌러 상세를 여세요. 결과 수는 이번 조회 건수이며 주변 모든 기관을 뜻하지 않습니다.

### 8.2 진료과목으로 병원 찾기

[소섹션: PDF 158쪽](MedBuddy_User_Guide_ko.pdf#page=158)

<a id="manual_page_159"></a>

#### 1. 진료과목 목록 살펴보기

진료과목이나 ‘기침’·‘감기’ 등의 표현으로 과목을 찾고 선택하세요. 제한 없이 보려면 ‘전체’를 누릅니다. 검색은 진단이 아니므로 방문 과목이 불확실하면 의료기관에 문의하세요.

#### 2. 초성으로 바로 이동

오른쪽 초성을 누르면 해당 글자로 시작하는 과목 위치로 이동합니다. 예를 들어 치과를 찾으려면 ‘ㅊ’을 누르세요. 아직 과목이 선택된 것은 아닙니다.

#### 3. 가까운 결과 확인

선택한 진료과목이 왼쪽에 표시됩니다. 지도 표시와 ‘병원 목록 보기’로 결과를 확인하세요. 처음에는 현재 위치 가까운 범위부터 찾습니다.

1. 선택한 진료과목
2. 이번에 찾은 병원 목록

#### 4. 현재 위치에서 다시 찾기

현재 위치 버튼으로 기기 주변을 다시 찾으세요. 가까운 결과가 없으면 범위를 순서대로 넓힐 수 있으며 확대 안내가 표시됩니다.

#### 5. 진료과목 바꾸기

지도 왼쪽 과목 버튼을 눌러 목록을 다시 여세요. 다른 과목을 고르면 즉시 조회합니다. ‘전체’로 과목 제한을 해제할 수 있습니다.

### 8.3 병원 조회 조건과 날짜 바꾸기

#### 2. 날짜와 진료 상태 구분

위쪽은 조회할 날짜, 아래쪽은 진료 상태입니다. ‘현재 진료 중’은 현재 기준입니다. 다른 날짜를 보려면 다른 진료 상태를 먼저 고르세요.

#### 4. 주말·공휴일 또는 전체 선택

주말·공휴일 진료는 방문할 날짜도 함께 고르세요. 시간 조건 없이 찾으려면 ‘전체 병원’을 선택합니다.

1. 주말·공휴일 시간표
2. 진료시간 조건 없이 검색

#### 6. 적용한 조건 다시 확인

결과를 보고 ‘조회 조건’을 다시 열면 현재 적용된 날짜와 진료 상태를 확인할 수 있습니다. 실제 진료 여부는 방문 전에 전화로 확인하세요.

### 8.6 주변 약국 조회하기

### 8.7 약국 조회 조건과 날짜 바꾸기

[소섹션: PDF 170쪽](MedBuddy_User_Guide_ko.pdf#page=170)

#### 2. 영업 상태 선택

현재 영업 중·늦게까지 영업·주말·공휴일 영업·전체 약국 중 고르세요. ‘적용’을 눌러야 반영됩니다.

‘주말·공휴일 영업’을 고르고 방문 날짜도 확인하세요. 평일로 분류된 날짜에는 다른 날짜를 고르라는 안내가 나올 수 있습니다.

#### 4. 같은 창에서 날짜 열기

날짜를 바꿀 수 있는 영업 상태에서 ‘날짜’를 눌러 달력을 여세요. ‘현재 영업 중’에서는 날짜를 바꿀 수 없습니다.

#### 5. 방문일 고르기

달력에서 날짜를 고르고 ‘확인’을 누르세요. 조회 조건으로 돌아가 ‘적용’까지 눌러야 반영됩니다.

1. 선택한 조회 날짜

#### 4. 취소하거나 계속 편집

1. 계속 수정하기
2. 마지막 저장값으로 돌아가기

#### 2. 휴대폰에서 알림 허용

#### 4. 휴대폰 권한에서 허용

휴대폰에서 알람 및 리마인더를 허용한 뒤 돌아와 실제 상태를 확인하세요. 영문 표기는 Alarms & reminders이며 일반 알림 허용도 따로 필요합니다.

### 9.10 로그아웃하기

#### 1. 일반 계정 로그아웃

‘내 정보 → 환경설정 → 계정’에서 계정을 확인하고 ‘로그아웃’을 누르세요. 일반 계정은 별도 확인창 없이 로그아웃됩니다.

#### 2. 로그인 화면 확인

로그아웃하면 로그인 화면으로 돌아갑니다. 다시 이용하려면 사용하던 계정으로 로그인하세요. 일반 계정의 로그아웃은 계정 데이터 삭제와 다릅니다.

#### 3. 게스트 로그아웃 열기

계정 화면에서 게스트 계정으로 사용 중임을 확인하세요. 로그아웃을 누르면 자료 삭제 경고가 열립니다. 일반 계정의 로그아웃과 다르게 취급해야 합니다.

#### 4. 영구 삭제 경고 읽기

게스트 복약정보·일정·연동·설정의 영구 삭제 경고를 읽으세요. 삭제하고 로그아웃할 때만 진행하며 계속 사용할 자료가 있다면 취소하세요.

#### 5. 게스트 로그아웃 뒤 확인

게스트 로그아웃으로 영구 삭제한 자료는 복구할 수 없습니다. 로그인 화면에서 게스트를 다시 시작하면 새 계정이 만들어집니다.

입력 오류는 이메일·비밀번호를 확인하고 로그인 버튼으로 다시 시도하세요. 연결 오류는 인터넷을 확인하고 보안 세션 다시 연결이 제공되면 이용합니다. 이메일 미인증 안내는 메일 인증을 마친 뒤 돌아와야 합니다. 비밀번호가 기억나지 않으면 재설정 메일을 요청하세요. 계정 삭제나 앱 데이터 초기화로 해결하려고 하지 마세요. 로그인 만료, 접근할 수 없는 연동, 일일 사용 한도는 서로 다른 안내입니다. 만료 안내일 때만 다시 로그인하고, 연동 종료이면 연동 상태를 확인하세요. 하루 한도 소진은 한국 시각 자정 이후 다시 시도합니다. 접속 실패만으로 계정을 삭제하거나 다시 만들지 마세요.

**[10.2 - 217페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=217)**

처방전 분석을 진행하지 못하면 오류 내용을 먼저 읽으세요. 서버 응답 실패가 항상 사진 불량을 뜻하지는 않습니다. 연결을 확인하고 재시도하거나, 글자와 표가 선명한 다른 사진을 선택하세요. 개인정보가 보이지 않도록 확인하고, 조회 결과 화면에서 누락·오인식 내용을 원본과 대조합니다. 약품 조회에 실패한 약은 같은 화면에 ‘조회 실패’로 남으므로 연결을 확인한 뒤 ‘미확인 약 다시 조회’를 누르세요. 카메라 권한을 계속 거부한 상태이면 휴대폰 설정으로 이동해 MedBuddy 카메라 권한을 확인하세요. 사진 선택을 취소하거나 다른 사진으로 바꾸면 이전 분석 결과를 현재 사진의 결과로 보지 마세요. 하루 분석 횟수 소진 안내와 일시적인 응답 실패를 구분합니다.

**[10.3 - 219페이지 - 1~2번 사진](MedBuddy_User_Guide_ko.pdf#page=219)**

사진은 재분석·사진 변경 버튼의 위치를 보여 주는 관련 화면이며 오류 화면은 아닙니다. 반복 실패 시 연결을 확인하고, 확인되지 않은 후보는 저장하지 마세요.

**[10.4 - 221페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=221)**

보호자 알림은 환자와 연결된 상태에서 받습니다. 알림이 없더라도 앱의 환자 일정에서 기록을 직접 확인할 수 있습니다. 알림만으로 실제 복용 여부를 단정하지 마세요. Android 14 이상에서는 알람 및 리마인더가 기본으로 꺼져 정한 분보다 늦을 수 있습니다. ‘정확한 시간에 알림’에서 권한을 허용한 뒤 앱으로 돌아오세요. 강제 종료 후에는 앱을 다시 열어 예약을 갱신합니다. 완료한 시간대나 비매일 약의 쉬는 날에는 알림이 없는 것이 정상일 수 있습니다. 환경설정 → 복약 및 알림에서 앱의 수신 스위치를 확인하고, 휴대폰 설정 구역의 알림 허용과 정확한 시간에 알림을 확인하세요. 복약 알림만 차단됐다면 ‘복약 알림 꺼짐’으로 표시됩니다. 테스트 알림은 실제 복약 기록을 바꾸지 않습니다. 한 번 표시되었다고 이후 예약 알림이나 서버 푸시가 보장되는 것은 아닙니다.

보호자의 확인 요청을 받는 환자는 ‘채팅 알림’ 수신도 확인하세요. 직접 완료 버튼은 지원 기기의 오늘 요청에만 제공되며 일반 글 메시지·과거 요청에는 없을 수 있습니다. 버튼을 누른 뒤 상태가 불확실하면 앱의 일정과 전송 대기를 먼저 확인합니다.

**[10.5 - 223페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=223)**

기기에 전송 대기 기록이 남으면 인터넷 연결을 확인하고 기존 기록의 전송 상태를 확인하세요. 보호자 위젯의 환자 이름과 조회 상태도 확인하고 새로고침하거나 앱의 환자 일정을 다시 여세요. 보호자 기기의 서버 저장 완료는 환자의 조회 완료를 뜻하지 않습니다.

빈 일정의 재조회 중 로딩과 조회 완료 후 약 없음은 다릅니다. 특히 필요시 복용은 이전 결과가 비어 있어도 재조회가 끝날 때까지 기다리세요. 알림의 직접 완료도 서버 전송 대기로 남을 수 있습니다.

**[10.6 - 225페이지 - 1번 사진](MedBuddy_User_Guide_ko.pdf#page=225)**

결과가 없으면 검색 지역·날짜·진료과목·운영 조건을 확인하고 조건을 넓혀 다시 조회하세요. 조회 실패나 정보 미확인을 실제 휴진·폐업과 혼동하지 마세요. 위치 권한이 없으면 대체 검색 지역이 사용될 수 있습니다. 홍익대학교 서울캠퍼스 등 안내된 지역을 내 현재 위치라고 단정하지 마세요. 오늘 병원 정보 조회 가능 횟수를 모두 사용했다는 안내이면 검색 결과 없음이나 휴진으로 해석하지 마세요. 다음 날에 다시 조회하며, 지금 확인이 필요한 경우 이미 알고 있는 기관 연락처 등으로 직접 확인합니다.
