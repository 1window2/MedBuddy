# 처방전 분석 대기 중 복약 팁

## 표시 위치

홈의 고정 복약 팁을 제거하고, 처방전 OCR 인식과 API 약 정보 분석의 공통 진행
화면의 분석 카드 위에 팁을 표시하며, 제목과 내용은 중앙 정렬한다.
진행 상태·뒤로가기 기능은 유지하며 팁을 읽기 위한 인위적인
분석 지연은 추가하지 않는다. 오류·검토·완료 화면으로 이동하면 순환을 종료한다.

## 표시 방식

- 한국어·영어 팁 8개를 무작위로 섞어 10초마다 표시한다.
- 한 순환 안에서는 중복하지 않고, 다시 섞을 때도 같은 문구가 연속되지 않게 한다.
- 다음 팁 버튼으로 즉시 넘길 수 있으며 문구 길이가 달라도 영역 높이는 유지한다.
- 앱이 비활성화되면 자동 전환을 중지한다. 화면 읽기·움직임 감소 설정에서도
  자동 전환은 멈추고 수동 전환은 유지한다. 현재 팁만 접근성 읽기 대상으로 제공한다.
- 글씨 배율과 언어를 반영하고 작은 화면에서는 진행 화면을 스크롤할 수 있게 한다.

## 구조와 문구 범위

`PrescriptionAnalysisProgressUI`에서 공용 표시 위젯 `MedicationLoadingTip`을 사용한다.
타이머는 화면 내부 상태이며 OCR·API 요청, 사용자 설정 및 복약 데이터 계약은
변경하지 않는다. 별도 API 호출이나 개인정보 수집 없이 기기에서 문구를 선택한다.

복용량·시각과 포장 안내 확인, 복용 약·건강기능식품 목록 공유, 약사에게 문의하기,
보관 방법·유효기간·주의사항 확인은 일반적인 안전 안내로 제공한다. 개인별 처방이나
약물 상호작용에 대한 판단은 하지 않는다. 근거: [FDA Use Medicines Wisely](https://www.fda.gov/consumers/womens-health/use-medicines-wisely),
[FDA Use Medicines Safely](https://www.fda.gov/consumers/consumer-updates/fda-pharmacists-help-you-use-medicines-safely).

나머지 문구는 MedBuddy의 인식 결과 검토, 실제 복용 후 기록, 사진 식별 후보의
확인 절차를 안내한다. 사진 인식 결과를 약품 확정이나 복용 지시로 표현하지 않는다.

## 검증

무작위 순환·수동 전환·부모 재빌드·앱 생명주기·타이머 해제·접근성 읽기와
OCR/API 두 단계의 한국어·영어, 작은 화면·큰 글씨·가로 화면 회귀 테스트를 유지한다.

## 실패 시 복구 화면

실패 화면은 좌우 여백과 아이콘 간격을 줄여 재촬영·이미지 재선택 명령을 읽기 쉽게
표시한다. 큰 글씨에서도 버튼 높이를 고정하지 않아 문구가 버튼 밖으로 잘리지 않는다.
인식 과정의 오류 종류를 그대로 공통 오류 안내에 전달하여 응답 파싱·서버 버전 등의
문제를 모두 연결 실패로 오인하지 않게 한다. 진단 로그에는 실패 단계만 추가하며,
처방전 내용이나 인증 정보를 추가로 기록하지 않는다.
