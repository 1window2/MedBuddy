## Scope

v0.2.5 makes existing features easier to find and use rather than adding many
new ones: the bottom tab opens the medication history with weekly, monthly and
custom views, the medication cabinet moves under the schedule's top-right
button and home > 약 등록·관리 > 약 관리, registration is one page, feature search
is grouped by category, and hospital search accepts symptoms.

## Review corrections (2026-10-31)

All ten collaborator commits were reviewed. Each bug fix has a test that fails
without it.

- **Department search:** "배가 많이 아파요", "가슴이 아파요" and "아이가 아파요"
  reached dentistry, and "손목 아파요" reached ENT, because a word ending in 이 or 목
  matched a tooth or throat term. These terms now match only at the start of a
  word. Common emergency wording that found nothing now shows emergency medicine
  and the 119 notice, an empty result shows the 119 notice too, and everyday
  phrases such as "머리가 아파요" and "toothache" find a department.
- **As-needed doses in chat:** "taken" with an as-needed medicine selected
  recorded only the scheduled ones, or failed with a misleading message. Nothing
  is recorded now, and the message says where to record the dose.
- **Old chat schedule cards:** a card older than the 90-day history opened an
  error screen; it no longer opens, like the history card.
- **History tab:**
  - a tab left open overnight moves to today on return;
  - a saved correction shows progress instead of a blank body;
  - a hidden tab no longer reloads on every return to the app;
  - a failed external share over 31 days is no longer hidden by the chat notice;
  - calendar days and period tabs work with screen readers.
- **Prescription result:** leaving after everything was saved no longer warns
  that unsaved results will be lost.
- **Touch feedback:** feature search, department and data-use rows show their
  ripple again; a decorated box was painting over it.
- **Feature search:** follows a language change made on top of it.
- **Privacy notice:** the data use page says that a hospital or pharmacy card in
  chat sends the shared place to the map provider.
- **Overhead removed:** a repeated saved-medication request on the history tab, 30
  text layouts per navigation bar build (now 5), regular expressions recompiled
  on every search keystroke, one chunked history reader instead of two, and code
  left over from the cabinet tab (back handling, month navigation, chart
  variants, per-sender card colours, test-only paths).
- **Security:** Pillow 13.0.0 and pypdf 6.21.4 for the user guide tools, which
  close all open Dependabot alerts. Backend and Flutter dependencies have no known
  advisories, and the commits contain no secrets; new screenshots show test accounts only.
